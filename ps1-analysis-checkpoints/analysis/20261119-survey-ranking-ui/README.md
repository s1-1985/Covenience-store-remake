## 確定した表示規則

［確実］原関数`800470E4..800478F8`は、左右それぞれ独立した27個の実績カウンターから上位8商品を選ぶ。

| 項目 | 買った商品（左） | 欲しかった物（右） |
|---|---|---|
| 実績位置 | 店舗+1198+商品ID×12 | 店舗+119C+商品ID×12 |
| 商品名X | 32 | 164 |
| 数字X | 120 | 252 |
| 行Y | 80から16刻み、最大8行 | 同左 |
| 商品名 | MSG71+商品ID | 同左 |
| 数字の書式メッセージ | MSG369（0x171） | 同左 |

座標は原ゲーム内の論理座標。提示スクリーンショットやスマホの画素座標へ直接代入しない。商品名の元メッセージ対応は既存成果を再利用する。

- 比較は**符号なし32bitの降順**。厳密な大小比較で更新するため、同数なら商品番号が小さいものが先になる。
- 左右は別々に順位を作る。右列を左列と同じ商品順に並べる仕様ではない。
- 選ばれた値が0の行は、商品名も数字も描かない。全0なら両列とも空欄。0やダミー項目で8行埋めない。
- 9件以上が正でも表示は8件まで。同数の9件目は商品ID順で落ちる。
- `+11A0`の第3カウンターは、この表示関数から読まない。売上額・構成比・全期間累計を代用しない。
