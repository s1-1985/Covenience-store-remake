原37/40もレジ系マスターに存在するが、この4択のID表にはない。表の費用・容量そのものは既知マスターからの値であり、新たな会計仕様や宅配業務仕様を解明した件数へ含めない。今回の新しい対応は**この画面の欄名と読取フィールド**である。

## 控え室2択の表示

原4594Cは什器48/49を対象にする。対応テーブル800CD760を、原配置側76BD4–76D1Cの読取とも照合した。価格は3,000/7,000、表示維持費は1,200/2,400である。

| 控え室画面要素 | 原の論理座標・仕様 |
|---|---|
| ウィンドウ | (64,48)、192×112 |
| 価格 | Y80、MSG28。Xは128＋8×(6−原65820(価格)) |
| 維持費 | Y96、MSG296。同じ右寄せ式 |
| アイコンのX | 112・152、各32×32 |
| アイコンのY | 未選択112、選択中110 |
| 元のUV | (96,192)・(128,192)、kind25、CLUT(0,491) |

選択で変わるのはアイコンの画面Y座標。元画像のUVを2画素ずらすものではない。原45AA4で最初の選択を上へ2画素移し、変更時は45CD4以降で旧選択を戻し、新選択を上へ移す。右入力1サンプルを与えた限定実行で、この差を最終レコードのXY/UVへ接続した。

このヘルパー45EECはRGB値を明示指定せず、41630の既定色分岐を使う。今回は控え室の原41630自体を実行し、RGB128を得た。未初期化の引数領域を読んで「黒いアイコン」と判断してはならない。実GPU合成やスクリーンショットの画素測定は行っていない。
