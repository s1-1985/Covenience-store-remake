# 内装編集の什器売買・商品入替・標準配置費用のデータ解析

2026-11-14。原ディスクの什器53件、商品27件、配置30件の什器原点852件を、購入・撤去・商品入替・移動の原処理へ接続した。営業シミュレーションやCPU実行は追加していない。

## 今回整理した規則

| 操作 | 原処理の精算 |
|---|---|
| 新規什器を配置 | マスター購入価格＋付属在庫の仕入原価を引き落とす |
| 通常撤去 | 購入価格を全額戻し、残在庫を仕入原価で精算する |
| 商品入替 | 旧商品残数の仕入原価を戻し、新商品を什器容量いっぱいまで購入する |
| 通常の移動 | 持ち上げ時・置き直し時とも金額を変えない |
| 保存配置を読込 | 既存の商品を容量まで補充してから、什器・在庫の全体額を計算する |

購入価格と仕入単価は原プログラムの数値を使用する。什器の原価格に「現実的な価格へ直す」ための倍率を勝手に付けない。金額計算は符号付き32bitの積・加減算を経由し、単価は`trunc(base*cost_percent/100)`でゼロ方向へ丸める。店で設定した販売価格は、これらの在庫精算に使わない。

## レジ・控え室は撤去と変更を区別する

通常撤去を拒否するのは、原区分4のレジ6種（ID37～42）と原区分6の**控え室2種（ID48・49）**である。控え室をトイレと呼ぶのは誤りであり、名称はMSG435・436の原文字データに従う。

変更操作では、控え室は戻り値2、レジは3を返し、上位75514がそれぞれ別の選択状態4・5へ渡す。このとき既存の什器価格を戻すが、773BCのこの分岐には通常撤去時の在庫原価返金処理がない。通常撤去の拒否と、交換用の取り外しを一つの処理へまとめない。

## 通常移動は上位メニューから確定した

原メニューの値1はCD924=1を設定して既存什器操作77DE4へ入る。773BCは向きに応じた什器全体を退避して元のセルを消す。置き直し76474は**CD924=1のとき金額処理を飛ばす**ため、通常移動で再購入は発生しない。

取消しでは退避した元セルを戻し、在庫画像を更新する。移動は撤去して買い直す操作ではない。

既存の単独検証にはCD924=4で持ち上げる人工入力もある。しかし、通常の上位メニューで値4は終了前検査788C8へ入り、移動画面へ進まない。単独関数に渡せた値を、そのまま通常プレイの操作対応表にしてはいけない。今回、上位75514の76164～762C4と結び付けて、この違いを整理した。

## 商品入替は差額・満杯購入

什器ID0～21と29～32の26種は、変更操作から商品選択68978へ渡る。その元マスターの全対応商品について、旧在庫量0・半量・満杯の4,197組を計算した。

```
仕入単価 = trunc(i32(商品基準価格 × 原価率) / 100)
差額 = i32(新商品の仕入単価 × 什器容量 − 旧商品の仕入単価 × 旧在庫量)
```

差額が負なら現金が戻る。同じ商品を選んでも、減っている分は満杯まで買い足す。原商品の画像・数量を保持したまま商品IDだけ差し替える仕様ではない。

選択可能商品とタバコ・酒・医薬品の許可判定は別条件である。また、選択後にマスター+192の既定選択indexを書き換えるため、元ディスクの既定値0を以後も固定してはならない。

## 配置30件から実際の標準選択6件へ接続

全30配置の852原点について、什器価格とその直下の在庫画像・数量を集計した。商品がある原点の数量は、元配置ではすべて容量に達している。保存後に商品が減ったカスタム配置の読込時は、原1D1ACで満杯に戻すので、保存時数量をそのまま費用に使うと差が出る。

新規出店の「組み込み配置を使う」選択は`tier*5+1`の6件を読む。30件すべてがこの選択肢から選べるという意味ではない。

| tier（0始まり） | 配置ID | 什器額 | 在庫原価 | 内装合計 | 最安用地＋建築＋内装の合計 |
|---|---|---:|---:|---:|---:|
| 0 | 1 | 34,550 | 198,015 | 232,565 | 26,232,565 |
| 1 | 6 | 21,610 | 140,990 | 162,600 | 26,162,600 |
| 2 | 11 | 27,360 | 296,840 | 324,200 | 32,324,200 |
| 3 | 16 | 57,480 | 318,050 | 375,530 | 32,375,530 |
| 4 | 21 | 26,320 | 299,115 | 325,435 | 38,325,435 |
| 5 | 26 | 62,760 | 408,765 | 471,525 | 38,471,525 |

数値は原現金値。最安用地は前回集計の空き地2×2（20,000,000）、建築費は6,000,000／12,000,000／18,000,000を加算した。この6配置自体が要求する販売許可は0種類である。追加の任意許可、内装変更、サイズ解禁、最終配置検査は別条件となる。

標準内装の一括購入では「合計 **<** 残現金」が必要で、同額なら拒否する。したがって上表の合計は支出の算術値であり、資金判定を通るにはさらに原現金1単位が必要である。個別配置76474・商品入替68978には同じ比較が存在しないため、一括購入の資金比較を全操作にあるものとして扱わない。これだけを根拠に、負の現金で営業開始できるとは結論していない。

## 仮引落しと確定記帳

内装中はCD978が什器額、CD8E0が在庫原価を持ち、CD9F8の現金が仮に増減する。新規開始の呼出元5DD04以降は編集前の現金・台帳を保存し、編集後に戻して、成功時に在庫原価を1CA7C、什器額を1CBC4で確定する。仮引落しと確定引落しを両方残すと二重計上になる。

既存店の編集は別の呼出元・差額処理を持つ。新規開始時の全額記帳をそのまま流用する部分は未接続であり、全編集経路の費用解読完了とはしていない。
