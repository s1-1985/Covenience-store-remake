## 営業時間外の補充と日付境界

営業時間外の仕入は19伝票・10,200円。翌日0時以降の仕入4,380円は、現在日台帳 `[0, 0, 0, 4380, 0]` と一致した。

時計24,480（0時）の同じ更新内で、決算処理80029334が新店舗の従業員処理80036AC0より先に呼ばれる。原呼出し記録と原EXEのJAL命令2箇所で確認した。この更新で発生する180円の仕入は、決算で締めた前日ではなく、新しい日の台帳へ計上される。

## 制限

原子関数を共有する親処理間比較と、自然到達した状態での独立モデル照合である。SDK/BIOS・GPU/SPU/IRQは既存モデルであり、実画面の画素・実音声・実時間速度を証明しない。従業員移動の回数は論理座標の変化である。

実行器の命令数制限を外す診断2条件はSIGSEGVで終了したため採用していない。完成区間は原実行器の命令数制限を維持している。失敗診断は主系列の更新回数へ加算しない。
