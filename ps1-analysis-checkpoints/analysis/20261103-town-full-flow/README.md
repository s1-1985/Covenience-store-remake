## 道路の影響は非対称

元の地図では道路ID14/15/16から計255回、この影響処理へ入った。
道路の位置を(x,y)とすると、対象は概ね次の集合で、地図境界で切り詰める。

- (x-3..x+3, y) の横一列。
- (x, max(0,y-3)) の1区画。
- 対象の区画が道路カテゴリ1なら除外する。
- 各対象へ+10、上限100。その後の符号付き8bit扱いも保持する。

縦7区画や正方形へ直すと原処理とは異なる。
これは原コードを一般的な都市モデルへ置き換えないための注意点であり、
開発者が意図した仕様か、元プログラムの不具合かを断定したものではない。

## 駅の影響

実在する線路に駅ID20を1つ配置した制御条件でも検査した。
駅の先頭タイルから、半径8の正方形（境界で切り詰め）へ+30、上限100を適用する部分がモデルと一致した。
駅の配置は試験準備であり、原の自然生成やプレイヤーの誘致UIを通した証明ではない。
準備時に乱数も消費するため、基本条件との変化区画数の差を、そのまま駅の因果効果と解釈しない。
