## 音源選択とSEの適用範囲

原625C4–62698は設定ワードを読み、SEと報告フラグを反転して保存し、BGM選択に1を足す。80099864の4整数は[-1,2,3,4]であり、通常選択1～3が音源要求2～4を選ぶ。BGM3を音量3へ置き換えない。この設定画面には、BGM音量調整やBGM OFFを追加したという根拠はない。

原64E4CのSE要求1はCD834=1で音声バックエンド8EA7Cへ進み、0では進まない。一方、要求28はSE OFFでも別の64740呼出しへ進む。**SE OFFを全音声処理の一律停止として実装すると、この呼出し分岐と異なる。** 要求28の音の内容や聞こえ方は今回確認していない。音源状態CD990=6では要求処理自体を早期復帰する別の入口条件もある。

月次側29E44ではCD835=0だと売上条件に応じた通知判定区間を飛ばす。これは月次決算計算そのものを停止するフラグだと解釈する根拠にはならない。通知種別・金額条件の全体解析や既知の決算式の再検証は行っていない。
