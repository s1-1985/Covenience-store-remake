## 費用・建設・完成の接続

総額は `基本費用 + trunc((土地総額 + 全額の撤去費)/10)`。通常出店の「土地＋撤去費半額」とは別の式である。基本費用分を画面内で一時的に引き、土地側の加算を残額と比較する。地点確定は加算額が残額より**小さい**場合に限るため、今回の正の実データでは**所持金が総額と同額だと確定できない**。

例えばTOWN0001の交番を(46,2)に置くと、基本400,000＋(土地20,000,000＋撤去30,000,000)/10＝5,400,000。最低必要資金は5,400,001となる。選択範囲(46,2)～(47,3)にかかる住宅を全体撤去するため、範囲外(46,4)も空き地になる。[具体例](whole-building-removal-examples.json)を参照。

同時進行は1件。開始時に全額を資本支出として一度計上し、予定区画を建物71「誘致用地」に置き換える。カウントは `RNG%5+4`。時刻が0:00の更新で1ずつ減り、0になった更新で空き地化してから完成建物を配置する。月初限定ではなく、完成時の追加支払もない。開始時刻を考慮せず固定の経過時間に置き換えない。

完成建物の客構成はセルごとの5択で、同じ客構成IDが複数回並ぶ場合もその重みを維持する。完成は後続の日次/月次処理より先である。地価係数字段は空き地化・誘致用地化・完成配置で保持される。
