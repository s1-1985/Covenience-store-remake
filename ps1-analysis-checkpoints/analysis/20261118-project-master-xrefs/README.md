## 調査方法と限界

- 原EXEのロード対象ペイロード全体から、LUIと、その後8命令以内の下位即値を使う定型参照を検索した。検索対象にはコードとデータの両方が含まれる。抽出した4か所・17か所は原逆アセンブルとも照合した。
- 共有変数を読む15命令から、レジスタコピーと即値加算を最大64命令まで追う。制御移動で追跡を止めるため、完全な制御フロー・別名解析ではない。
