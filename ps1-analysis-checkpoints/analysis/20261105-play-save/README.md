## 範囲と継続課題

今回の操作経路は通知非アクティブ・町表示の実保存状態、既存ファイルへの上書きと同ファイルの読込み。
通知アクティブ時・別ビュー・空カードの新規作成まで実営業入力で検証したとは扱わない。
物理カード通信、BIOS命令、実コントローラ、GPU/SPU/IRQの完全再現も対象外。
既存の論理BIOS・SDK境界は明示したモデルのままである。
次は同じ実営業入力経路で空カード時の新規作成・エラー回復を接続し、通常営業を次の決算へ進める。
