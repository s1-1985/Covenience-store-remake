# 宣伝UI：カーソル位置・複数選択・費用2欄・アイコン明暗

2026-11-19 JST。［確実］宣伝画面では、**カーソルが指す項目と、実施対象として選択した項目を独立して表示する**。未選択のTVへカーソルを移した場合でも、選択したDM＋新聞の費用合計は60万円のまま。上段はTVの500万円/月を表示する。この原表示側と、選択アイコンの描画要求・位置を接続した。

既存未解決6件は保留。今回、Android本体・APKを変更していない。

## 今回の追加と既知仕様

11月14日に、宣伝5種類の費用・実施時刻・継続フラグ・5倍資金条件・1回分の支払い・編集確定/取消は解読済みだった。11月17日には、通知用アイコンのPS_CM1.TIM実画素と6A304のUV/CLUTを接続済みである。これらは再解読として数えない。

今回の追加は、原69D30–6A110の表示側を限定実行し、**選択状態の明暗、独立したカーソル先費用、選択済み合計、原の配置**を同じフレームへ接続したこと。金額式そのものの新発見や、宣伝の営業効果の新検証ではない。

| 指定した編集状態 | カーソル先 | 上段の費用/月 | 費用合計/月 | 明るいアイコン |
|---|---|---:|---:|---|
| 全て未選択 | DM | 100,000 | 0 | なし |
| DM＋新聞のみ選択 | TV | 5,000,000 | 600,000 | DM・新聞 |
| 全5種を選択 | 飛行船 | 1,000,000 | 9,600,000 | 全5種 |

原の選択状態は編集用ローカル5バイト。カーソルindexは別変数で、名前・単価・カーソル位置だけを決める。選択済み費用の集計は値が厳密に1の項目だけを足す。今回の指定値は0/1の通常範囲に限る。

## 原の描画位置と明暗

以下は320×224の論理座標で、Android端末の物理画素ではない。

| 要素 | 原位置・仕様 |
|---|---|
| ウィンドウ | (40,24)、16×9セル＝256×144 |
| 見出し | (56,40)「宣伝方法を選択して下さい(複数選択可)」 |
| カーソル先の名前 | (72,56)、原インライン文字列。TVは「TV」表記 |
| カーソル先の費用 | Y56、金額メッセージ272。後ろの「/月」は(240,56) |
| 費用合計 | (72,72)、金額のY72。「/月」は(240,72) |
| 5アイコン | X68＋40×index、Y88、32×32 |
| カーソル要求座標 | X95＋40×index、Y117（原5FDD4の+3補正後） |
| 終了案内 | MSG22、(124,132) |

金額のX座標は固定ではなく `152+8×(11−原65820(金額))`。原の金額幅計算をそのまま使用している。今回、65820を代用品へ置換していない。

アイコンは原6A304を実行し、41630へ渡すレコードを捕捉した。kind29、UV(224,96＋32×index)、CLUT(0,495)、サイズ32×32。元画像の切出し(224,32×index,32,32)は既知のPS_CM1対応を再利用する。

- 選択値1：RGB変調要求(128,128,128)。
- その他：RGB変調要求(64,64,64)。

**カーソルが指しているだけでは明るくならない。** 未選択TVにカーソルがある2番目の条件でもTVの変調要求は64である。最終GPU合成後の色やスクリーンショットの明るさ比を実測したものではない。カーソル座標も描画ヘルパーへの要求値であり、カーソル画像全体の矩形とは区別する。

## 現Android版へ渡す差分

アプリcommit `22ba479999c4e025727806454b9858364ca145cc`、`game/scripts/ps1_ui.gd::_advertising` を照合した。現版はタップで `try_purchase_promotion` を呼び、今月の選択履歴から合計を表示する。`vertical_slice_simulation.gd` の同関数は予約を追加し、実施時刻を過ぎた申請や同月の再選択を拒否する。**その場で広告費を引く関数ではない**。

通常の原UIへ合わせるには、タップで編集用5フラグを切り替え、カーソル先と選択状態を分ける。表示合計は編集用フラグを読む。確定時に継続設定へ書き戻し、取消時は破棄する。時刻経過後に設定できることと実施時刻まで効果が発生しないことは、11月14日の既知仕様へ従う。

配置にも差があり、現版はウィンドウ(51,45,230,120)、アイコンY96。原の配置と明暗は[Android接続表](android-bridge.json)へ保存した。予約処理の変更やAPKへの反映は今回実施していない。

## 最小限の確認と限界

原アイコン生成6A304、カーソル補正5FDD4、金額幅65820は実行した。文字・枠・カーソル・レコード受付等7子関数は引数捕捉後に復帰させた。実画面操作、GPU、音声、営業更新、宣伝の支払いは0回。全32選択組合せの再試験は行わない。準備時に描画ABIの座標引数を取り違え、1条件目で停止した試行が1回あり、訂正後の最終3条件と別に数える。
