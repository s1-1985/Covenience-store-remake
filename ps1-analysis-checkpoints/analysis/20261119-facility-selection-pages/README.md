## ページをまたぐ入力

原の左右入力は端でページを切り替え、上段/下段を維持する。

| 操作前 | 入力 | 操作後 |
|---|---|---|
| page0・slot4（体育館） | 右 | page1・slot0（中学校） |
| page0・slot9（小学校） | 右 | page1・slot4（公園） |
| page1・slot0（中学校） | 左 | page0・slot4（体育館） |
| page1・slot4（公園） | 左 | page0・slot9（小学校） |

page1の右端からさらに次ページを作る分岐はない。上下移動もそのページの列数を加減する。上記4つのページ遷移だけを限定実行し、全方向・全セルの入力試験はしていない。Androidではタップ操作を維持しつつ、ページ別の配列とヒット領域をこの配置へ合わせる。
