## 再現

復元にはPython標準ライブラリ、実行には `unicorn==2.1.4`、`capstone==5.0.7`、`Pillow==12.3.0` を使用した。

```sh
python ps1-analysis-checkpoints/restore-latest.py --destination /absolute/empty/work
```

今回の600更新自体を再実行する場合は、復元した `algorithm-analysis` に前回 main-17を追加してから、このフォルダーで実行する。

```sh
python prepare_inputs.py ALGO
python continue-main.py ALGO
```

`continue-main.py` は200更新ごとに原比較・台帳監査・CPU再開点を保存する。3区間すべて通過するまで `all_passed` はfalseとなる。原比較は従来の検証器を再使用し、今回の区間では600更新で不一致なし。日次決算までの自然到達と資金突合が今回追加された検証であり、日次決算式を初めて解読したという意味ではない。

復元した別フォルダーから追加2更新を実行する再開試験は `restore-check/` に保存する。この診断2更新は通常営業600更新へ加算しない。
