## 演出本体で分かった範囲

原0x80052270の引数2の枝が0x80052A88を呼ぶ。初期待機は120回の**描画待機呼出し**であり、実秒数や営業更新120回とは扱わない。

終了判定の0x800645ACは既知の音声状態判定である。式は `word[800B8CB4]==0 && word[800B8CAC]!=0`。これが0なら入力なしで戻り、1の間は描画と入力確認を続ける。入力マスク0x60は決定／取消の両方を受ける。入力で終了する場合は0x80064550で既存音声を停止する。単に「何秒か待つと必ず終わる」とは断定しない。

0x80052A88～0x80052CFCの関数本体の直接書込みは、スタック上の描画引数・カウンターと入力変数800CD7E0のクリアであり、客を消去する直接書込みはない。**呼出し先全体の書込みまで調べた結果ではない**ため、「演出中も客が必ず保持される」とは結論しない。GPU・音声・割込みを含む演出全体は今回実行していない。
