# 0171: 客がいる間も許可・広告・価格・チェーン拡大を使えるようにする(タスク#100)

## 背景

販売許可・広告・価格方針・チェーン拡大は、店内の客が全員帰るまで使えなかった
(`customers.all_settled()`)。営業時間中は店がほぼ空にならないので、実際には使えなかった。
決定書0168で「対象外」として残していた項目。

## 決定

- 許可・広告・価格方針・チェーン拡大は、客がいても使えるようにした。どれも什器・客の経路・買い物かごを変えない。
  - 価格は、客が商品を手に取った時点の方針で決まる。これは従来どおり。
- 什器の購入・移動・回転・売却・入れ替え・見本レイアウト・商品の品揃え・雇用は、今までどおり客が帰るまで待つ。経路や、作業中の店員の状態を変えるため。
- 画面の「客が帰るまで待って」というメッセージを、この4つの操作では出さないようにした。失敗の理由は「お金が足りない」など、本当の理由を出す。

## テスト

- `headless_smoke.gd`: 客がいる状態で、許可・広告・価格・チェーン拡大が成功する。什器の移動は今までどおり断られる。
- 契約テスト: 4つの関数に客の条件が無いこと。什器編集の条件は残っていること。
- 結果: Python 761件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 原作で、メニューを開いている間に時間が止まるかどうか(未確認)。
- 雇用・品揃え・什器編集を営業中に行うこと。
