# 0166: 出店場所を町マップの好きな所から選び、場所ごとの地価で買う(タスク#95)

## 背景

ユーザーの指摘:「自分の店の土地、広すぎだろ？ 初代ザ・コンビニにおいては、土地は好きな所を
自由に選べた。人口密集度や将来の発展性により地価が異なり、将来性を読んで青田買いするセンスも
必要だった。現状では建てられる所が決まっている」。

事実として、タスク#90〜#93の町マップは、攻略本p.11の開始画面にあるオレンジの5×5の区画を
「自分の店の敷地」として固定し、その上に本店マークを描いていた。新しいゲームは、土地を
選ばずにこの区画に店がある状態で始まっていた。

確認した証拠:

土地を買った後の値と一致する(推論。同じプレイの画面である確証は無い)。

## 決定

### 1. 町マップのデータ(`tools/build_guide_town_map.py`、`tools/guide_store_site.py`)

- 5×5の区画を消し、そのマスは草地にした(カーソルの下が見えないため。REMAKE_BALANCED_DEFAULT)。
- `store_site`: 出店のルールと地価の元になる数値。
- `building_catalog`: 地図上の建物スプライトごとに、DATA4の名前と価格。

### 2. 地価(`game/scripts/domain/store_site.gd`)

- 敷地は2×2。道路・線路・地図の外には建てられない。他の店から5マス未満(チェビシェフ距離。
  既存のTownSpatialと同じ)には建てられない。
- 土地代(4エリア分)の決め方は、このプロジェクトの形(REMAKE_BALANCED_DEFAULT)で、数値の
  端は攻略本の実例に合わせた:
  - 下限 ¥20,000,000(攻略本の最安例・Wikiの最低地価)
  - 道路に接していれば +¥5,000,000(「大通りに面している」¥25,000,000 − 下限)
  - 周囲16×16マス(攻略本が店の周囲として使う範囲、PDF3 p.10)の建物の多さに応じて
    最大 +¥5,000,000(空地の最高額が攻略本の最高例¥30,000,000になる)
  - 100万円単位に丸める(攻略本の例がすべて100万円単位)
  - 結果: 開始時の空地は¥20,000,000〜¥30,000,000。
- 建物がある場所は、その建物をまるごと買い取り、評価額の半分を足す(CONFIRMED_OFFICIAL)。
  DATA4の建物価格は単位の無い数字(住宅(小A) 1000)なので、万円と読んだ(PROVISIONAL。
  攻略本の「建物付き¥34,000,000」が空地の例と並ぶのはこの読みだけ)。
- 時間が経つと、既存のLandValuePolicyの年率(REMAKE_BALANCED_DEFAULT)で上がる。

### 3. 場所が客数に効く

店の周辺人口(`demand.nearby_population`)を、周囲16×16マスの建物のマス数で決める:
シナリオの値(2,000)× その場所の建物マス数 ÷ 建てられる全場所の平均。地図の外は建物0と
数える(「マップの端は不利」)。REMAKE_BALANCED_DEFAULT。建物の多い場所は高いが客も多い。

### 4. ゲームの流れ(`main.gd`、`vertical_slice_simulation.gd`)

- 新しいゲームは町マップで始まり、「出店場所を選んで下さい」と表示する。土地を買うまで時間は
  進まない。
- 地図をタップすると2×2のカーソル(黄=建てられる、赤=建てられない)と、原作の表示にならった
  「空地 ¥21,000,000 たばこ○ 酒○ 薬○」を出す。建物がある場所は建物の名前と、土地代と
  建物買収費の内訳を出す。
- 「この土地を買う」で支払い、建物を取り壊し、2×2の本店マークを置き、店内の画面に切り替える。
- 所持金¥200,000,000は、スマホ版だけでなく全ての新しいゲームに適用した(土地をここから払うため)。
- セーブ形式を6に上げ、買った場所と取り壊した建物を保存する。リセット(新しいゲーム)で消える。

## テスト

- `headless_smoke.gd`: (13,21)の空地が¥21,000,000、(12,20)が土地¥27,000,000+買収費¥10,000,000、
  道路・線路・地図の外は不可、空地の値段の範囲、ライバル店から5マス未満は不可・7マス以内は
  たばこ×、所持金不足では買えない、支払い額、周辺人口、2回目は買えない、HUDの地価、
  セーブ/ロード、リセット。
- `android_preview_smoke.gd`: 新しいゲームが土地選びで始まり時間が止まっていること、
  実際のタップ入力で地図のマスを選べること、道路は不可、空地の表示、購入後の所持金、ロード後。
- 契約テスト: ルールの数値がreference_simと同じこと、建物の名前・価格がDATA4と同じこと、
  Python版とGDScript版が同じ値段を出すこと、REMAKE_BALANCED_DEFAULTの記載。
- 結果: Python 756件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外(未解決として残す)

- **店舗サイズの選択**: PS版の開始画面では小型2種だけが選べる(CONFIRMED_VISUAL)。一方、
  新しいゲームの店は攻略本p.48の12×8の大型店のまま(タスク#89)。建設費も差し引いていない。
  大型店の建設費も資料間で¥18,000,000と¥24,000,000が食い違っている。どちらに合わせるかは
  ユーザーに確認する。
- 販売許可の申請を土地選びの直後に行う手順(今は店を開いた後のメニューのまま)。
- 町の発展(新しい建物・駅が建つこと)。これが無いので「青田買い」の見返りはまだ無い。
- 「チェーン拡大」ボタンは場所を選ばない抽象的な操作のまま(2店目以降の出店場所選びは未実装)。
- ライバル店の配置(データ上0店のまま)。
