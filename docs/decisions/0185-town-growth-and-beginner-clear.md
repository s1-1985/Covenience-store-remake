# 0185: 町の人口が増え、都庁が建つと初級マップクリア(タスク#114)

## 背景

今の町の地図は、攻略本p.11の初級マップである。初級マップのクリア条件は「都庁を誘致する」。
しかしこれまでは、町の人口は2,000人のまま増えなかった。クリア条件も、中級の「10店舗」を仮に使っていた(PROVISIONAL)。

## 根拠

|---|---|---|
| 初級マップは住人2,179人から始まり、クリア条件は「都庁を誘致する」 | 攻略本 PDF2 p.86、p.11 | CONFIRMED_OFFICIAL |

仮の対応(PROVISIONAL)は次のとおり。

- 市役所は役場(村役場)2×2で、区役所は役所(県庁)5×5で表した。
- 駅は駅(小)2×1で表した。

類推(資料の数値から導いたもの)は次のとおり。

- 月の人口増加率は、攻略本の「8年(96か月)」で2,179人から20,000人になる率とした。
  - 率は2.34%。
  - 動画の序盤(+3〜7%)よりは低く、攻略本の目安とは合う。

本プロジェクト独自の決め方(REMAKE_BALANCED_DEFAULT)は次のとおり。

- 毎月同じ率で増える。
- 店の近くの客は、町の人口に比例して増える。
- 役所・駅を置く場所は、建物を巻き込む数が最も少なく、次に地図の中央に近い所とする。駅は線路の隣に置く。

## 決定

- `tools/guide_store_site.py` の `TOWN_GROWTH` を、`guide_town_map.town_growth` として書き出す。
- 本番のゲーム(`simulation.town_growth_enabled`)では、次のように動く。
  - 町の人口は2,179人から始まる。
  - 月末ごとに増加率だけ増える。
  - 節目の人口を超えると、市役所・駅・区役所・都庁が町の建物として建つ。建った建物は店の商圏の客にもなる。
- 都庁が建つと `clear_condition_met` になり、初級マップクリアになる。
  続けて遊べる。試作店のテストは、これまでどおり10店舗でクリア。
- 月末決算の記録に町人口を加えた。
  月末のお知らせは「○月の収支」に続けて「町人口 ○人(+○人)」を出す(原作の月次報告にならった)。
- 節目の建物が建った時と都庁が建った時(クリア)は、お知らせを出す。調査の窓には「目標」として都庁と今の人口を出す。
- 誘致で建てた施設と町が建てた建物は、同じ1本の記録(建てた順)に残す。
  建物の番号は建てた順で決まるため、ロード時はこの順で建て直す。
- 建物の絵は4枚(1マス32px、非可逆圧縮)を加えた。

## テスト

- `headless_smoke.gd`(`_check_town_growth`)では、次を確認する。
  - 人口2,179人から始まり、増加率どおりに増えること。増えると店の近くの客も増えること。
  - 90〜100か月で都庁が建つこと。
  - 4つの建物がPython側と同じ場所に建つこと。
  - 都庁でクリアになること。
  - JSONを通したセーブ/ロードで人口と建物が戻ること。
- 契約テストでは、次を確認する。
  - ブロックの内容、タグ、節目の人口。
  - 96か月前後で20,000人に届くこと。
  - 建物の場所がPython側でも同じになること。
  - 絵、クリアの判定、スモークテストの確認文。
- 結果: Python 775件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 月末にふつうの建物(住宅や店)が自然に増えること。人口の数は増えるが、地図にはまだ出ない。
- 地価の上がり方と建物の出現の関係。
- 中級(10店舗)・上級(オーナー評価)のマップと、マップの選択。
