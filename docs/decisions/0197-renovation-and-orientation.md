# 0197: 店の改装(大きさ・向きの変更)と、縦長/横長の表示(タスク#126)

## 背景

ユーザーから次の指摘があった。

> 既にある店舗の大きさを変更できるようにして。あと、店舗のレイアウトの向きが縦長しかない。店舗選択時に2種類あるのにどちらも縦長しかない。

### 向きについて調べたこと(事実)

- 「店舗を選んで下さい」の左下(small_bottom)を選ぶと、8×5 タイルの横長の店が建つ。画面を撮って確かめた。
- ただし、次の3点があった。
  - 2つの小型店のアイコン(`store_type_01.png` と `store_type_02.png`)は、ほぼ同じ絵。
  - ボタンには大きさも向きも書いていなかった。
  - 買収した店は、いつも小型の縦長(small_top)になる。
- 以上から、2つとも同じ縦長の店に見えたのだと考えられる(推測)。

## 根拠

- CONFIRMED_OFFICIAL(攻略本 店舗データ p.106-109):店は3つの大きさ×2つの向き。床は 5×8/8×5、7×10/10×7、8×12/12×8。建築費は600万・1200万・1800万円。
- CONFIRMED_VISUAL:12×8 の大型店の配置は、攻略本 p.48 の店そのもの。
- 開いている店の大きさを変える機能は、どの資料にもない。以下は REMAKE_BALANCED_DEFAULT。

## 決定

6種類すべての店に、開店時の配置を用意した(`guide_store_types`)。

- 大型・横長(12×8):p.48 の店。
- 中型2種と大型・縦長:この作品の通路格子の配置(REMAKE_BALANCED_DEFAULT)。
  - 入口は前の壁の中央。休憩室は右上の角。レジは入口の内側。
  - 棚は背中合わせの2列。3列ごとに通路。途中に横の通路。
  - 棚の数は p.48 の「床1タイルあたりの棚数」から(小型店と同じ類推)。ただし通路の都合で置き場の数が上限になる。
  - 生成時に、すべての棚の正面・レジ・休憩室・出口・店員の位置に入口から行けることを確かめる。

改装(`try_renovate_store`):

- 内装の画面の「改装(店舗の大きさ・向きを変える)」から行う。今の店以外の5種類を、大きさ・向き・費用つきで並べる。選んでから「改装する」を押す。
- 費用 = 新しい店の建築費 − 今の店の建築費の半分。0円より安くはならない。半分は什器の売却と同じ割合。
- 月末の×8から外す一回きりの出費として扱う(`store_renovation`)。
- 店の中の客は帰る。店員は新しい床の持ち場に立つ。雇用・能力・体力・レジ係は変わらない。
- 什器は、新しい店の棚の置き場に1つずつ置く。
  - 商品の入ったものが先。商品と在庫はそのまま付いていく。
  - 正面は、置き場の向き → 空いている辺の順で探す。
  - 入りきらない什器は倉庫に入る(0196)。中の商品は原価で戻る。
- 知名度・人気・評価・アンケート・売上は、そのまま引き継ぐ。
- 同時に入れる客の上限は、新しい店のものになる(p.48 の8人を床面積で比例配分)。

向きの表示:

- 店舗選択のボタンに「小型店・縦長 5×8」「小型店・横長 8×5」のように書く。
- 下の説明と、改装の一覧も同じ書き方にする。

## テスト

- `_check_renovation`:次を確かめる。
  - 同じ店への改装はできない。小型から中型への費用は 1200万 − 300万。
  - 改装後は床が 7×10 になる。棚14個が商品ごと全部移る。客は帰る。どの棚にも行ける。上限人数が増える。
  - 中型の空いた置き場に棚を足してから横長の小型店に改装すると、入りきらない分が倉庫に入る。什器の数は減らない。倉庫の什器には商品がない。
  - 改装した店が商売を続ける。セーブとロードで新しい店の種類と什器が戻る。
- android_preview_smoke:次を確かめる。
  - 店舗選択のボタンに「縦長 5×8」と「横長 8×5」が出る。
  - 内装 → 改装で、今の店は一覧に出ない。選ぶまで「改装する」は押せない。押すと横長の小型店になる。
- 契約テスト:次を確かめる。
  - `test_store_selection_offers_six_stores_with_only_the_small_ones_at_start` を6種類すべての配置の検査に広げた。
  - `test_store_growth_editing_and_renovation_are_tagged`。
- 手元の試験(`_probe6`、コミットしていない):6種類を8回続けて改装した。毎回、什器14個が移り、行けない棚は0。ロードも成功した。
