# 0240 — CSRM-001 APK収録の検証記録

## 背景
MuseのCSRM-001 v1が、decision0238を収録したAPK89と検証記録を要求。指示書の公開前にユーザー直接指示のLEGACY-0239で音声接続とAPK89が作成されていた。

## 決定
後継作業の既存成果物の0238収録、祖先コミット、署名v2/v3、パッケージ/versionを確認し、指定8smokeと全Python/広域headlessを実行して記録する。別作業の0239を振り直さず0240へ採番。CSRM-001でゲームロジックは変更しない。元のブランチを独断マージしない。

## 検証・ファイル
指定8本成功、全Python786成功/既存2失敗/想定1。広域headlessは既知の町表示寸法で失敗。失敗名と範囲差分はdocs/implementation/CSRM-001.md。実機/実聴未確認。変更は本決定・実装報告・PROJECT_MEMORYへの記録、ビルド記録への確認追加。

## 範囲外
CSRM-002のテスト基線修正、端末確認、原仕様の再解釈。後継成果物を使う差分はMuseレビュー待ち。
