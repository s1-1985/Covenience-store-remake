# 0203: 店員の成長と店長の学歴を原作プログラムの仕組みに(タスク#133)

## 背景

ユーザーの指摘(2026-09-27):

> 店長が部下に与える影響、つまり成長させる要素、店長の声がけ？は、社交ではなく学歴（教育）だと思うけど。

タスク#129では、店長の助言の確率に「社交性」を使っていた(REMAKE_BALANCED_DEFAULT)。店員の成長は、攻略本の「仕事と能力の関係」に、この作品が決めた「毎回+1、成長上限まで」を組み合わせたものだった。

## 根拠

CONFIRMED_BINARY(SLPS_007.82 と DAT/TOWN0001.BIN)。詳しくは `docs/research/ps1-executable-formulas-2026-09-26.md` の「店員」。

- 店長の助言と店員の成長に使う店長の値は +0x15。雇用画面の2つ目の値で、候補の値は攻略本の「学歴」と35人中29人一致。**学歴**だった。ユーザーの指摘どおり、社交性ではない。
- 成長:仕事ごとに、能力ごとに店長の学歴%で+1。上限は本人の教育・社交性・機敏さ。成長上限を超えた分は1/16。
- 客の怒り:1/3で店員全員が−1、1/10で評価−1。
- 候補35人の値(教育を含む)はディスクの町データにある。

## 決定

- `tools/ps1/extract_program_tables.py` に候補の表と成長の規則を足した(`ps1_program_tables.staff_candidates`・`staff_growth`)。
- 本番のゲームでは、候補と開店時の店員の値を原作の値にする(`_apply_program_staff_figures`)。攻略本の写し(`staff_candidates`)はそのまま残す(reference_sim との照合のため)。
- 成長は `StaffGrowth.apply_program_growth`、客の怒りでの低下は `apply_program_decline`。試作の場面はこれまでの規則のまま。
- 店長の助言の確率を学歴に変えた。REMAKE_BALANCED_DEFAULT ではなくなった。
- 客が怒ったときの評価−1の確率を、本番のゲームでは1/10にした(攻略本の1/6より、プログラムを優先)。
- 店員の窓に「教育」を出す(原作の店員画面と同じ)。

## テスト

- `_check_program_demand`:学歴100の店長でレジが本人の教育まで伸びる、学歴0なら伸びない、成長上限を超えると約1/16、怒りで−1、本番の店員が原作の値(学歴・教育)を持つ。
- pytest:成長関数・助言の根拠の記載・候補35人。

## この作業でしないこと

- 攻略本の写しそのものの訂正(reference_sim 側)。
