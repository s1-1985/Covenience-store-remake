# 0191: 棚とワゴンの差別化(タスク#119)

## 背景

ユーザーから次の依頼があった。

- 棚:取れる向きが限られるが、収納量が多い。
- ワゴン:収納量は棚より少ないが、どの向きからも取れて、注目度が高い。

これまでは、どの什器も商品を取れる場所が正面の1マスだけだった。

## 根拠

- 収納量は CONFIRMED_OFFICIAL(攻略本の設備データ、fixture_catalog)。
  - 同じ大きさなら、ワゴンは棚より少ない。例:常温 40/80/120 に対して 15/30/45。
  - この差はもともと入っていた。
- 2×2の大型ワゴンは、1マス幅のワゴンより注目度が少し高い(初代専用Wiki、CONFIRMED_COMMUNITY)。
- 注目度がついで買いに効くことは、Wiki自身も推測としている。

## 決定

本プロジェクト独自の決め方(REMAKE_BALANCED_DEFAULT、`store_rules`)は次のとおり。

- 取れる向き:
  - 棚・ケース・自販機は正面だけ。
  - ワゴン(攻略本の名前が「ワゴン」の11種)は、空いているどの辺からでも取れる。
  - 客も店員も、一番近い辺へ行く(`StoreLayout.access_cells()`、`find_path_to_any()`)。
  - ワゴンの正面が他の什器でふさがれても、空いた辺が1つあれば置ける。
- 注目度:棚1.0、ワゴン1.5、2×2のワゴン2.0。ついで買いの確率に掛ける(0190)。

## テスト

- `_check_wagon_sides`:次を確かめる。
  - 棚の注目度は1.0、ワゴンは1.5、2×2ワゴンは2.0。
  - ワゴンには2辺以上から行ける。棚は正面だけ。
  - 別の方向から来た人は、近い辺を使う。
- 契約テスト:`test_wagons_are_reached_from_any_side_and_draw_attention`。
