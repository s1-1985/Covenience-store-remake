# 0194: その他の手直し(タスク#121)

## 背景

ユーザーから「他にもブラッシュアップできるところはどんどん修整していって」という依頼があった。
今回の作業中に見つけたものを直した。

## 決定

- 帰った客を、いつまでも覚えていた。
  - 客の一覧は毎ティック全員を回るので、長く遊ぶほど重くなる(推測、計測はしていない)。
  - 帰った客は、最新の64人だけ残すようにした。
  - 来店数と会計数は数として持つ(`CustomerRoster.started_count()`)。
- ロード後に、来客記念の数え方が壊れていた。
  - 客の一覧はロードで空に戻るのに、記念の「前回の累計」はセーブの値のままだった。
  - その結果、次に客が帰ったときにアサーションエラーになった。
  - チェーン全体の累計を、別の数としてセーブするようにした。
- 客のカードが3行になると、1文字ずつ折り返して画面をふさいでいた。
  - ラベルに最低幅を付けた。
- 通知が、下に出るカード(棚・客)のボタンに重なっていた。
  - 表示中は毎回、カードの上に置き直すようにした。
- 店を切り替えると、町の地図をその店に合わせるようにした。
- 売却の通知に内部IDが出ていた。0188 で直した。
- 返品と新しい棚の仕入れを、月末の×8から外した。0188 で直した。

## テスト

- `_check_customer_roster_stays_small`:6日動かすと、帰った客は64人しか残らない。数は全員を数える。
- 客のカードと棚のカードは、xvfb で画面を撮って確認した。
