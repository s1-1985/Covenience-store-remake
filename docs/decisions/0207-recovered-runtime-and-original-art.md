# 0207 — 解析結果をAndroidゲームの町・営業・画像に接続する

## 背景

ユーザーの目的は初代PS版の忠実なAndroid再現であり、解析資料を増やすことではない。0.1.20は更新版ゲームに月末営業台帳を移しただけで、町や内装の仮仕様が大量に残っていた。基点45851ca、解析基点2c00ba53。mainとPR #270は変更しない。

## 今回の実装

- 新規ゲームはTOWN0001の60×50マス、72建物定義、人口2,179人、所持金2億円、ライバル本店(43,12)1店で開始する。元の仮マップ／2店配置を本番開始経路から外す。
- 地価は各マスの原作レベル×100万円を合計。建物全体の評価額は原作属性×面積×100万円、買う場合は半額。出店／誘致は原作マップの建物を実際に置き換える。
- 月末の町処理をGDScript化。売上による影響、道路／駅の影響、地価レベル、住宅・会社・商業施設の増減、公共施設、役場／駅の発展を実行する。定率で人口だけを増やす旧経路を本番から外す。
- 原作の客層配分を各マスの実データへ接続。原作LCGを営業・天候・作業等で共有し、2分刻みと小10／中15／大20組の店内上限を使用する。
- レジの二段階能力判定、レジ待ち忍耐と精算退店、能力低下／評価低下、補充の能力判定と1回量、清掃判定、体力消費／休憩回復、店長割増を含む賃金、什器維持費を移植。
- ライバルは別の在庫・店員・台帳で同じGodot営業処理を走らせる。仮の幾何的な圧力値を赤字と見なす処理を廃止し、実際の月損益で連続赤字を数える。6ヶ月／本店保護／9店所有時1月の条件、1/4の出店判定と原作候補地走査を移植。買収は原作の土地・店舗資産評価の2倍、調査50万円。調査は現行店舗の値を表示し、買収した什器・商品を維持する。
- 原作の町640タイル、建物画像、方向別什器、商品3段階、客／店員シートと床を実画面に使用。初期配置に使う画像だけでなく、内装で購入・回転する什器にも適用する。
- 町セル、LCG、ライバル会社資金・連番・実損益・店舗内容を保存する。

## 出典／再生成

`tools/ps1/export_recovered_runtime.py <restored algorithm-analysis>` がEXEのSHA256を固定し、必要な表と画像のみを抽出する。原EXE／BIOS／ディスク／Unicornはゲームへ含めない。

解析ブランチ `chatgpt/ps1-analysis-recovery-20261103` の復元資料から、`town_monthly.py` (8002BD54)、`town_mutation.py` (8001F1C0/8001F4B4)、`town_growth.py`、`checkout.py` (80035D58)、`staff_energy.py`、`staff_work.py`、`inventory_callers.py`、`rival_management.py` (8002A8E0)、`rival_helpers.py`、`source_acquisition_monitor_20261102.py` (80060E70)、`runtime_tables.py`、`interior_display.py` を使用。画像入力は既存の `assets/raw/ps1_disc_analysis_v1`。

## 境界 — 完全再現とは呼ばない

原作CPUを丸ごと移す構成ではなく、必要なゲーム処理をGDScriptに移す。本番に既存クライアントとの接続部分が残るため、完全なゲーム全体の乱数呼出順／軌跡の一致は主張しない。

REMAKE_BALANCED_DEFAULT: 開店時の家具配置・入口／屋外の位置・初期什器と商品の無料提供、ライバル出店時の小型店・既定配置・採用候補の選び方、客と店員の経路探索／行列の形、誘致の費用・完成日、スマホUIと音楽は既存クライアントの接続仕様を残す。原作の全30レイアウト、全シナリオ、原作そのままのメニュー・音源・人物アニメーション、特殊商品の全絵柄は未統合。客層グループにある範囲外の訪問行IDは配分ブリッジで除外する。これらを解析済み／移植完了と混同しない。スタッフ外観の性別対応も未完了である。

## 動作確認

既存786件のPythonテスト（既知expected failure 1件）、既存Godot smoke 3本、本番開始経路専用smoke 3本。旧固定座標テストは明示的なtest-only legacy metaでその入力マップを維持し、本番の原作マップは別smokeで検証する。

町の4入力について全24,000バイトSHA256・最終乱数・人口・建設判断を既存原作照合モデルと比較。実ゲームでは新規開始→出店→10日間営業（2回以上の月末）→客とライバルの売上→JSON保存／再開→誘致→買収・在庫引継ぎを通す。LCGの範囲／浮動小数の呼出しがGodotの同名グローバル関数へ流れないことも確認。
