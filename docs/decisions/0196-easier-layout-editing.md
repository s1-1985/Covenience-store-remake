# 0196: 狭い店でも内装を変えやすくする(タスク#125)

## 背景

ユーザーから次の指摘があった。

> 内装の変更時、通路塞ぐと駄目とか、狭い店舗のスペースの中でレイアウト変更しづらい。

これまでは次のとおりだった。

- 什器を動かすと、正面(客が立つ側)は元と同じ向きのまま付いてきた。そこが壁や他の什器なら置けなかった。
- 断られても、理由は「置けません」だけだった。
- 置き場所がない什器は、売るしかなかった。

## 決定

すべて REMAKE_BALANCED_DEFAULT(原作の内装は 配置・移動・入れ替え・売却 のみ)。

- 正面の自動探索(`store_rules.edit_front_search`)。
  - 移動・回転・購入・倉庫から置くとき、元の向きの正面がふさがっていれば、空いている別の辺を正面にする。
- 断った理由を出す(`edit_refusal`)。
  - 「壁か他の設備に重なる」「○○の棚に行けなくなる」「レジか出口に行けなくなる」「人がいる」を出し分ける。
  - 行けなくなる棚は、店の画面で赤枠で2.5秒示す。
- 倉庫。
  - 什器を無料でしまい、あとで無料で置ける。
  - 中の商品は、売却と同じく原価で戻す(0188)。
  - レジと休憩室はしまえない。
  - セーブに含める。
- ドラッグで移動。
  - 什器を指で押さえて引くと、置き先の影が出る。離した場所に置く。
  - タップで選んでからタップで置く操作も、今までどおり使える。
- 内部の整理。
  - 配置の可否の判定を `_accept_layout_change()` にまとめた。棚・レジ・出口に行けるか、人が取り残されないかを見て、だめなら元に戻す。
  - 6つの編集と、しまう・置くの2つが、この関数を通る。

## テスト

- `_check_layout_editing`:次を確かめる。
  - 商品の入った棚をしまえる。床から消え、商品は戻り、お金は減らない。
  - レジはしまえない。倉庫から元の場所に無料で置ける。
  - 壁際の棚を4回続けて回せる。他の什器の上への移動は「occupied」で断られる。
  - どの棚にも行ける。倉庫はセーブとロードで戻る。
- 契約テスト:`test_real_game_edits_with_customers_inside` を新しい形(`_accept_layout_change`、8か所のロック)に合わせた。
