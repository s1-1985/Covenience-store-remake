# 0219 月次損益履歴と店舗売却

0.6.9のアンケート接続版を基点に、既存解析済み・本体未反映だった60か月の
店舗/会社損益グラフと店舗売却をネイティブ本体へ接続する。
新規解析は原MIPSのグラフ軸計算5境界条件。既存解析とは件数を区別する。

売却は本店と営業中を拒否し、資産見積り、確認、実行直前の再検証を行う。
返金は営業損益から分離し、当月の売上と従業員の能力を保持する。
安定店舗UIDで配列再編後の経費/保存の所属を維持する。
不明な旧履歴は補間しない。原EXEをゲーム実行時には使用しない。

根拠・再現・制約は docs/research/graph-sale-integration-2026-11-20/README.md。
