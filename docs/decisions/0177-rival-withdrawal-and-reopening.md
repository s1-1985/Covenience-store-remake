# 0177: ライバル店の赤字・撤退・別の場所への再出店(タスク#106)

## 背景

ライバル店は町にいるが、何をしても消えなかった。原作では、近くで値下げを続けるとライバル支店が
赤字になって撤退し、ライバルは別の場所に支店を出し直す。中級の目標(ライバル込みで10店舗まで)でも、
ライバルの撤退が必要になる。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| 新しい店の商品利益率を15〜20%下げる → ライバル支店が数か月連続で赤字 → 撤退 | 攻略本 p.53の流れ図 | CONFIRMED_OFFICIAL |
| 「赤字が半年も続けば、ライバルは撤退するはずだ」 | 攻略本の2つのマップ攻略ページ | CONFIRMED_OFFICIAL |
| 1つのマップにはライバル店を含めて10店舗まで | クイックリファレンス(中級) | CONFIRMED_OFFICIAL |
| 支店がつぶれると、ライバルはすぐ別の場所に支店を出す | PS/SS長期プレイ記録 | CONFIRMED_COMMUNITY |
| 5%の値下げでは強い支店は崩れず、15%では撤退した。遠くの店での値下げは効かなかった | 同上 | CONFIRMED_COMMUNITY |
| 支店が残っている間、本店はつぶれない | 攻略者の推測 | PROVISIONAL |
| ゲームの価格方針(定価からの%)を攻略本の「商品利益率の値下げ」と同じものとして扱う | — | 推論 |

赤字になるかどうかの計算式は、どの資料にもない。そのため、次の形は本プロジェクト独自のもの
(REMAKE_BALANCED_DEFAULT)とした。数値は上の記録に合うように選んだ。

- 圧力 = (ライバルの商圏にある建物マスのうち、プレイヤーの店の商圏にも入っている割合) × min(1, 値下げ率 ÷ 20%)
- 圧力が0.5以上の月は、そのライバルが赤字になる。
  - 隣の店が20%下げると約0.88で赤字になる。
  - 5%では約0.22で赤字にならない。
  - 遠くの店では割合が0になる。
- 6か月連続で赤字になると撤退する(攻略本の「半年」)。
- 撤退した支店は、次の月末に空いている土地へ出し直す。土地は、最初の配置と同じ規則(客が最も多く残る所)で選ぶ。
  ただし、元の場所から5マス以上離れた所にする(記録では「別の場所」に出る)。
- 撤退した本店は戻らない。

## 決定

- `tools/guide_store_site.py` に `RIVAL_AI`、`rival_pressure()`、`best_open_site()` を追加した。
  `guide_town_map.rival_ai` ブロックと、ライバルの `role`(本店 `head` / 支店 `branch`)を生成する。
- `StoreSite.rival_pressure()` と `StoreSite.best_open_site()` は、Python側と同じ規則で動く。
- 月末決算の後に `_step_rivals_at_month_end()` を実行する。順番は次のとおり。
  1. 前の月末に撤退した支店を出し直す。町の店が10店未満の場合だけ。
  2. ライバルごとに赤字の月数を数える。出し直したばかりの店は数えない。
  3. 6か月連続の赤字なら撤退させる。支店が残っている間の本店は撤退しない。
- 撤退したときはイベント `rival_withdrew` を記録し、効果音(ファンファーレ)を鳴らす。
  再出店したときはイベント `rival_opened` を記録する。
- ライバルが増減したら、自分の店の商圏を計算し直す。
- 調査済みのライバルは、町の画面に「Nか月連続の赤字」を表示する。
- セーブ(形式9)に、ライバルの位置と赤字の月数、再出店を待つ支店を保存する。
- ついでに、`sound.event_sfx` の字下げの崩れを1行直し、`store_built` の効果音を加えた。

## テスト

- `headless_smoke.gd`(`_check_rival_withdrawal`)で、店を(32, 9)に建てた場合を確認する。
  - 定価のままでは、2号店は赤字にならない。
  - 5%引きでは赤字にならない。
  - 20%引きで5か月たっても、まだ撤退しない。
  - 遠くの本店は赤字にならない。
  - 6か月目に撤退する。
  - セーブ/ロードの後も、再出店を待っている。
  - 次の月末に、(13, 9)に出し直す。出し直した月は赤字に数えない。
  - 店を本店の近く(8, 4)に建てると、本店は6か月赤字でも、支店がある間は残る。
    支店を買収すると、次の月末に撤退し、戻らない。
  - REMAKE_BALANCED_DEFAULTのタグ。
- 契約テスト: Python側で、同じ圧力(15/17)、5%の場合、本店側、再出店の場所(13, 9)を確認する。
  あわせて、ブロックの内容、タグ、GDScript側の関数とスモークテストの確認文も確認する。
- 結果: Python 767件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- ライバル自身の売上・資金の計算。
- ライバルの値下げなどの反撃。
- 新しい支店の出店(撤退した枠を埋める以外)。
- 撤退した支店の土地を買えるようになること。
- プレイヤーが買収した支店の売上。
