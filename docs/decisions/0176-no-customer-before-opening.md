# 0176: 開店前の店内に客を置かない(タスク#105)

## 背景

決定0174の既知の点として、新しいゲームの開始時(00:00、閉店中)に客が1人だけ店内にいた。
シミュレーションが、開始時とロード時に必ず客を1人入れていたためである。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| ゲームは1年目1月1日 00:00に始まる | 攻略本 p.6・p.11の画面写真 | CONFIRMED_OFFICIAL |
| 最初はAM7:00〜PM11:00営業 | 攻略本 p.23 | CONFIRMED_OFFICIAL |
| 閉店中は客が来ない | 決定0174 | (同上) |

閉店中の店に客がいないことは、上の2点から直接導ける。新しい数値は使っていない。

## 決定

- 開始時・ロード時・店の建て直し時に入れる最初の客は、営業時間中の場合だけ入れる。
  処理は `_start_opening_customer()`。
- 客が1人もいないときは、状態表示の客の欄を空にする(`customer_phase` = `"none"`)。
- 営業時間を持たない試作店のテストは、これまでどおり最初の客がいる。

## テスト

- `headless_smoke.gd`: 本番のゲームは00:00に客が0人で、状態表示・セーブ・ロードが動くこと。
  体力のテストは、営業時間中に客を入れてから始めるように直した。
- 契約テスト: 上の処理と、スモークテストの確認文。
- 結果: Python 766件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 営業時間による客層の違い。
