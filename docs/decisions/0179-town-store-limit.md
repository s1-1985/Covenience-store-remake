# 0179: 町の店はライバル込みで10店舗まで(タスク#108)

## 背景

ライバルの再出店(決定0177)には、町の店が10店未満という条件をすでに入れていた。しかし、プレイヤーの
チェーン拡大には上限がなく、ライバルがいても何店でも増やせた。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| 「ひとつのマップにはライバル店を含めて10店舗までしか建設できない。よって、いかにライバルを撤退させるかが課題」 | クイックリファレンス(中級) | CONFIRMED_OFFICIAL |
| プレイヤー5店とライバル5店になった時点で、新店舗を造れなくなった | 中級の長期プレイ記録 | CONFIRMED_COMMUNITY |

## 決定

- 町の店の数を「プレイヤーの店の数 + ライバル店の数」とする(`town_store_count()`)。
- この数が `guide_town_map.rival_ai.town_store_limit`(10)に達したら、チェーン拡大はできない。
  画面には「この町にはライバル店を含めてすでに10店舗あります」と出す。
- ライバル支店の再出店も、同じ判定(`town_is_full()`)を使う。
- ライバルを買収しても数は変わらない(ライバルが1店減り、自分の店が1店増える)。

このため、ライバルが2店残っている間は、プレイヤーの店は8店までになる。10店舗の目標を達成するには、
ライバルを撤退させる必要がある。これは攻略本の説明と合っている。

## テスト

- `headless_smoke.gd`(`_check_town_store_limit`):
  - ライバル2店がいる町では、チェーン拡大は自分の店が8店になるまでしかできない。
  - 買収しても10店のままで、それ以上は拡大できない。
- 契約テスト: 上限値、数え方、スモークテストの確認文。
- 結果: Python 769件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
