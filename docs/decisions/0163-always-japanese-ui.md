# 0163: UIを常に日本語にする(タスク#92)

## 背景

ユーザーの指摘:「UIが英語なのも気に入らない。日本語にしろ」。

調べると、翻訳(`game/locale/ja.po`)自体は`tr()`を通る文字列の全件にあった。英語が出た
原因は次の2つ。

1. 言語が端末の設定に従っていた。日本語以外の環境(PCのテストを含む)では英語のまま。
2. 一部の表示が`tr()`を通っていなかった:
   - 「直近の出来事」の出来事名(例: `customer reached product`)
   - 一時停止表示の`[PAUSED]`
   - 価格欄の単位(`% change from list price`)
   - メッセージや選択肢の中の内部ID(例: `shelf-bread-1`、`customer-12`、`product-bread-1`、
     候補ID、カタログID)

## 決定

- `main_menu.gd`と`main.gd`の起動時に`TranslationServer.set_locale("ja")`を呼び、端末の
  言語に関係なく日本語にする。原作は日本語のゲームなので、他の言語は用意しない。
- 出来事名は`tr()`を通す(35種すべてを`ja.po`に追加)。
- 内部IDを表示用の名前に置き換えた(`main.gd`):
  - `_fixture_label()`: 什器の和名と、置かれた商品(例: 小型常温棚(パン))
  - `_product_label()`: 商品カテゴリの和名
  - `_customer_label()`: お客さん12
  - `_candidate_label()`: 候補の氏名
  - 販売許可・広告・見本レイアウトは、既にある和名の翻訳を使う
- `staff-3`の表示は「店長」(タスク#91)。
- フォントのサブセットを作り直し、新しい文字を追加した。

## テスト

- 契約テスト:
  - ゲームのスクリプト中の`tr("...")`すべてと、記録される出来事名すべてに日本語訳があること。
  - 両方の画面で`ja`に固定していること。
  - 出来事名と棚の選択肢が表示用の名前を通ること。
- スモーク: 英語の文字列と比較していた3件(日付・町ボタン・クリア表示)を、同じ翻訳を
  通した値との比較にした。
- 結果: Python 756件成功(期待失敗1件は既存)、Godotスモーク・Android previewスモーク成功。
  PC画面のキャプチャで、パネルを最後までスクロールして英語が残っていないことを確認した。

## 明示的に対象外

- 描画できない場合の予備ラベル(絵が読み込めない時だけ出る`SHELF`等)。
