# 0.6.6 操作・カメラ・倍速（decision0215）

## 依頼と実装
ユーザー実機報告：△切替不可、倍率が飛ぶ、店内ピンチ不可、左上固定、拡大後スワイプ不可、一覧を開けない、ボタン外観。

- 指操作を直接処理した後に届くマウス互換イベントが二度目の操作を起こす経路を遮断。レールは指操作後500msの互換マウス入力を遮断し、描画メニューはdevice=-1のマウス互換入力を無視する。メニューで受けた指の解放も、表示切替後の背後へ流さない。
- △は「店内へ／町へ／全店舗一覧」の表示切替メニュー。左レールにも常設の全店舗一覧。各店の実売上・評価・在店客数、3件ごとのページ、店舗への移動。
- 店内カメラは独立Node。敷地を含め中央配置、ピンチ中心基準の倍率変更、指1本スワイプ。小さい軸は中央固定、大きい軸は端を越えない。表示をControlのクリップ内へ入れ、操作領域の外へ描画しない。メニューの開閉ではズームを維持する。
- 倍率は1/4/8/16。既存の完全なsimulation.tick（時計→全店の人物と仕事→来店等）を丸ごと増速し、時間だけを更新する別経路を作らない。1フレームのCPU予算・32tick上限を超えた未処理時間は保持。端末性能不足では実効倍率が下がる可能性があり、実機16倍を保証するものではない。
- モバイル操作ボタンは暗色、細い枠、角丸、押下とフォーカスの配色。同梱日本語フォント。原作の描画メニューの紙・配置は維持する。
