# 0234: 雑誌掲載とコンテストを稼働店・両社の受賞へ接続

## 背景

0.8.4ではネイティブライバルも営業するが、受賞用の評価/清掃は固定値、ライバルへの賞金と能力上昇は未接続だった。自社価格判定も旧一律増減率を使っていた。子ライバルのtickから町抽選が繰り返されていた。

## 決定

原3CEACの選択を小さな関数へ移し、建設済み自社店と活動ライバルの実値を入力。価格は原サマリーに接続済みの棚価格を使用する。会社別の賞金/店長の2特性/通知へ接続し、町抽選は親だけで実行する。子の人物増分は今回上昇する2項目だけ親へ同期し、買収後も保持する。
