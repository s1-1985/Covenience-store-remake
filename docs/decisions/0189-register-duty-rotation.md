# 0189: レジ係を交代させる(タスク#118)

## 背景

ユーザーから「同じ店員ばかりがレジをしている。上手くローテーションして」という依頼があった。
これまでは、レジ係は設定で決めた1人に固定されていた(`checkout_staff_id`)。

## 根拠

初代専用FAQ(`docs/research/staff-checkout-task-arbitration-2026-09-06.md`、CONFIRMED_COMMUNITY)には次の記録がある。

- 店員2人が同時にレジへ向かうと、先に着いた方がレジを打つ。
- 体力の少ないレジ係は、すぐ休憩室へ行ってしまう。

つまり、レジ係は1人に固定されていない。

## 決定

本プロジェクト独自の決め方(REMAKE_BALANCED_DEFAULT)は次のとおり。

- 店に客がいて、レジ係がレジを離れている(休憩中・戻る途中)とき:
  - 手の空いた、疲れていない店員のうち、レジに一番近い人がレジ係になる。
  - 休憩室では全員が同じマスにいるので、同じ距離なら体力の多い人。
  - それも同じなら、会計した人数の少ない人。
- 会計と会計の間に、レジ係が疲れ切ったとき、または体力が半分を切ったとき:
  - 手の空いた、体力の最も多い店員に代わる。
  - 半分を切った場合は、相手の体力が4分の1以上多いときだけ。行ったり来たりを防ぐため。
- 交代した2人は持ち場も入れ替える(`StaffRoster.hand_over_checkout()`)。
- 実ゲームのみ(`store_rules.checkout_rotation_enabled`)。
- 誰がレジ係かはセーブに入れる(schema 10)。

## 結果

2日間動かすと、3人がそれぞれレジを打つ。4日間では31・35・31人だった。

## テスト

- `_check_checkout_rotation`:交代が起きる。全員がレジを打つ。レジ係の持ち場がレジになる。ロード後もレジ係が同じ。
- 契約テスト:`test_register_duty_rotates`。
