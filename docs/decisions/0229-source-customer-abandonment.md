# 0229: 待機断念の能力対象と会計単位

0.7.9では待機断念時に接客が下がり警備が維持される逆転が残っていた。原35D58/3AA58(mode-1)に従いレジ・補充・清掃・警備へ変更し、接客は維持する。共通R、在籍者ごとの乱数消費、評価C68のみの減算は保持し、件数を127で飽和させる。

原処理と同じく、断念時に残った商品も代金を売上へ移して未精算額を0にする。会計後の消去を共通処理内へ移し、所持金の再減算をしない。別に取得した未精算分は同一人物でも別支払とするため、訪問IDと支払キーを分離する。レジ成功も共通会計へ接続し、履歴は元の客IDを維持する。原退店の移動からは断念処理を呼ばず、未精算の商品を勝手に売上へ振り替えない。

強制指定は通常の待機値減少と明示的に分ける。支払キー・訪問中支払合計はアプリ内の表現であり、原バイト列形式を再現したとの主張ではない。旧セーブも読める。元資料・132原条件・回帰範囲は `docs/research/customer-abandonment-2026-11-20/README.md`。
