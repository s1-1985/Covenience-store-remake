# 0205: 強盗と火災を原作プログラムの仕組みで入れる(タスク#135)

## 背景

> まだ入れてないものも、データを解析して抽出して

強盗・火災・万引き・賃金の要求は、この作品にはなかった。タスク#134で、文字列だけではどこから使われているか分からなかった。

## 根拠

CONFIRMED_BINARY(SLPS_007.82 の 0x8003BF28 ほか)。詳しくは `docs/research/ps1-executable-formulas-2026-09-26.md` の「強盗・火災」「万引き・賃金の要求について」。

- 店ごと、2分ごと。プレイヤーの店だけ。
- 条件:警備 < 人気、来客の累計 ≥ 2000、前月の売上 > 999999円、今日の売上 > 99999円、什器と在庫の値段の合計 > 99999円、店内にマナー30以下の客がいる。
- 乱数 % 128 == 100 で強盗、乱数 % 256 == 100 で火災(両方なら火災)。
- 店の敷地から7マス以内に交番があれば強盗は起きない。消防署があれば火災は起きない。
- 強盗:所持金から 今日の売上 × 8 を引き、今日の売上の記録を0にする。
- 火災:レジと控え室以外の什器が中の品ごと消える。空いた床が汚れる。店内の客がいなくなる。店員全員の体力が0。人気が5。お金は動かない。表示する被害総額は 今日の売上 × 8。
- 画面の文は、場面の文言(MSG 467「〜で強盗が発生しました!」、468「〜で火災が発生しました!」、469「被害総額」)。
- 万引き(MSG 207)と賃金の要求(MSG 235)は、プログラムの中に参照が見つからなかった。

## 決定

- 数値を `ps1_program_tables.incidents` に置いた(`tools/ps1/extract_program_tables.py`)。
- `VerticalSliceSimulation`(本番のゲームのみ):
  - `_step_incidents()` を店ごとに2分ごとに呼ぶ(店長のお知らせの直後。原作と同じ順)。
  - `incident_possible()`:上の条件。警備は `_store_values()["security"]`、マナーは客の来店表の行(`customer.visit["manners"]`)。
  - `_facility_squares_near(名前)`:敷地から7マス以内の交番・消防署のマス数。
  - `_run_robbery()`:支出 `robbery` として 今日の売上 × 8 を引く。今日と今月の売上の記録から今日の分を除く(原作は今日の記録を0にし、それが今月の記録に足されるため)。
  - `_run_fire()`:レジと控え室以外の什器を消す(品は返金なしで消す)。店の外の駐車場も消す(原作では駐車場も同じ床の表にあるため)。客は帰り、店員の体力は0(休憩に入る)、人気は5。事件 `fire` に被害総額を記録する。
  - 店ごとに来客の累計(`_store_visitor_heads`)と前月の売上(`_store_sales_last_month`)を持ち、セーブの `store_sales` に入れた(古いセーブは0から)。
  - 乱数はお知らせと同じ `_report_rng`。
- 画面:`robbery`・`fire` をお知らせに出す(店名入り)。
- 「×8」は、この作品の `MONTH_MULTIPLIER`(攻略本の「1か月 = 4日 × 8」)と同じ倍率。表の `loss_day_multiple` に置いた。

### この作品の決めごと(REMAKE_BALANCED_DEFAULT)

`ps1_program_tables.evidence_note`、コード、テストの3か所に記載した。

- 火災の汚れ:原作は空いた床のタイルをすべて汚す。この作品の汚れは「汚れたマス」の一覧(上限24)なので、歩けるマスから乱数で上限まで選んで汚れにした。

### 推論であること

- 来客の累計は、原作の +0x1188 に組の人数が足されると読んだ。
- 今日の売上・前月の売上は、原作の売上の記録の並び(0時の処理と「前月の売り上げが〜」の表示)から読んだ。
- 「×8」の意味(1日が8日分を表す)は、攻略本の倍率と同じと読んだ。

## 影響

- 開店直後は、前月の売上・来客の累計・人気の条件を満たさないので起きない。
- 店の近くに交番・消防署があると、それぞれ起きない。誘致で建てた施設も数える。

## テスト

- `headless_smoke.gd` の `_check_program_demand`:
  - 条件をすべて満たすと起こりうる。人気が警備以下、来客1999人では起きない。

  - 強盗で 今日の売上10万円 → 所持金 −80万円、今日の売上 0。
