# 0167: BGMと効果音を付ける(すべて自作・実行時に合成)(タスク#96)

## 背景

ユーザーの要望:「あと効果音とかBGM付けてよ」。このクライアントには音が一つも無かった。

資料で確認できたこと:

| 内容 | 出典 | 段階 |
|---|---|---|
| 原作にはBGMがある | プレイ動画V03の題名「【作業用BGM】ザ・コンビニ 1時間」 | CONFIRMED_VISUAL(存在のみ) |
| 目標達成時に効果音が鳴り、達成メッセージ → エンディングへ | `advanced-evaluation-ending-2026-09-05.md` §4 | CONFIRMED_COMMUNITY |
| 駐車場が足りないとクラクションの効果音 | `quick-reference-guide-part1-2026-09-19.md` §2.3 | CONFIRMED_OFFICIAL |

原作の音源・楽譜・効果音の一覧は見つかっていない。原作の曲は著作物なので、仮に手に入っても
写してはいけない。したがって、音はすべてこのプロジェクトで作る(REMAKE_BALANCED_DEFAULT)。

## 決定

- 音声ファイルは同梱しない。`game/scripts/audio/sound_synth.gd`で、起動後に波形を合成する
  (矩形波・三角波・正弦波・ノイズ、22,050Hz・16bit・モノラル)。Androidの配布ファイルは
  30MiBの送付上限ぎりぎりのため、ファイルを増やさない方法を選んだ。
- BGM(`sound_themes.gd`、どちらも自作):
  - 店内: ハ長調・132bpm・16小節のループ(メロディ・ベース・ドラム)。
  - 町: 100bpm・8小節の落ち着いた曲。タイトル画面と出店場所選びで流す。
  - 合成は別スレッドで行い、画面は止めない(PCで店内曲0.75秒)。
- 効果音(自作。どの出来事にどの音を鳴らすかは`vertical_slice.json`の`sound.event_sfx`):
  - 入店 → チャイム(ピンポーン)
  - 会計完了 → レジのピッ
  - 購入(什器・商品・許可・広告・雇用・土地・チェーン拡大) → 購入音
  - 什器の移動・回転・入替・売却 → コトッ
  - レジ待ちで客が怒る → 下がるブザー
  - 月末決算 → 上がるアルペジオ
  - シナリオ達成 → ファンファーレ
  - ゲームオーバー → 下がる短調のフレーズ
  - 建てられない場所を選んだとき → エラー音
  - ボタン → 小さな選択音
  - クラクションは使わない(駐車場をまだ扱っていないため)。
- パネルに「音：オン／オフ」ボタンを置いた。設定は`user://settings.cfg`に保存する。
- 自動読み込みの`SoundManager`がBGMと効果音(同時4音)を鳴らす。

## テスト

- `headless_smoke.gd`: 使う効果音がすべて合成できること、長さと音量(聞こえて、音割れしない)、
  音名と周波数の対応、1小節の長さ、BGMがループ設定であること、REMAKE_BALANCED_DEFAULTの記載。
- `android_preview_smoke.gd`: 土地選びの間は町の曲、開店後は店の曲。入店・会計・土地購入で
  それぞれの音が鳴ること。音ボタンで切り替わること。
- 契約テスト: `event_sfx`の出来事が実際に記録される出来事であること、効果音IDが合成側に
  あること、音声ファイルが同梱されていないこと、自動読み込みの登録、タグ。
- 結果: Python 757件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 原作の曲・効果音の再現(資料が無く、著作物でもある)。
- 音量の細かい調整、曲の追加(季節・夜などで曲を変える)。
- クラクション(駐車場の仕組みができてから)。
