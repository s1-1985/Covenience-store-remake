# 0169: 初級マップにライバル本店と2号店を置く(タスク#98)

## 背景

ユーザーの指摘:「ライバル店がいない」。事実として、`town.rival_stores`は空で、町マップにライバル店は無かった。

## 根拠

- 初級マップの開始時には、ライバルの本店と2号店がある。クイックリファレンスのオールテクニックガイド(書籍頁66-83)の、マップごとのDATA欄にその値が載っている。CONFIRMED_OFFICIAL。
  - 本店: AM7:00〜PM11:00、人気20、警備89、清掃30、サービス30
  - 2号店: AM7:00〜PM11:00、人気20、警備58、清掃30、サービス31、買収46,721,490円
- 町マップ上のライバル店の見た目は赤い「本」「02」のマーク(プレイ動画から切り出した`map_red_hq`/`map_red_02`)。CONFIRMED_VISUAL。
- 店どうしは5マス以内に建てられない(攻略本p.7)。
- 2店がどこにあるかは、どの資料にも無い。

## 決定

- `tools/guide_store_site.py`の`place_rivals()`で置き場所を決め、`guide_town_map.rival_stores`に書き出す。本店、2号店の順に、建物の無い空き地のうち「そこで得られる客(先に置いた店と分け合った後)」が最も多い2×2を選ぶ。既に置いた店から5マス以上離し、同点なら左上を優先する。REMAKE_BALANCED_DEFAULT。結果は本店(8,10)、2号店(27,9)。
- 客の取り合い(REMAKE_BALANCED_DEFAULT): 店の周囲16×16マスの建物のマスを数える際、そのマスが他の店の周囲16×16にも入っていれば、店の数で割って数える。建物の客をそこに近い店で分け合う形。これで自店の周辺人口が決まる。町マップに店が置かれている場合は、これまでの「ライバル1店ごとに客を一律に減らす」計算は重ねて掛けない。
- 新しいゲームでは`GuideStartingStore.apply()`がこの2店を`town.rival_stores`に入れ、`store_count_including_rivals`を3にする。画面上部の街の表示は「競合2店」になる。
- ライバル店の近く(5マス以内)には出店できない。これは既存の判定のまま。
- 町マップには、赤い「本」「02」のマークを舗装の上に描く。
- 攻略本の商圏半径(徒歩20マス)は、手元の町マップが元のマップの見えている一部分しかないため使わず、これまでの16×16の範囲を続けて使う。

## テスト

- `headless_smoke.gd`: 実際のゲームでライバル2店と店数3、本店から3マスの場所には建てられない、本店と周囲が重なる場所は単独より周辺人口が少ない、購入後は一律の減少を掛けない。
- `android_preview_smoke.gd`: 土地を買った後にライバル2店があり、画面に「競合2店」と出る。
- 契約テスト: 2店のIDと攻略本の値、マークの画像があること、Python版の置き場所の計算がJSONと一致すること、5マス以上離れていること、タグ。
- 結果: Python 759件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- ライバル店の経営(売上・価格・広告・許可の取得・新規出店・閉店)。
- ライバル店の買収。
- ライバル店の店内画面。
- ライバル店の販売許可(資料に無いので、持っていない扱い)。
