# 0183: 町の地図で建物をタップすると内容を表示する(タスク#112)

## 背景

原作では、町の地図で建物にカーソルを合わせると、建物の名前と買い物人口が出る。これを見て出店場所を決められる。
これまでの町の地図では、建物をタップしても何も出なかった。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| 建物にカーソルを合わせると、建物名と買い物人口が出る(「役所／買い物人口250人」の画面) | docs/research/ui-menu-evidence-2026-09-05.md 6章、PS画面写真 | CONFIRMED_COMMUNITY |
| 建物ごとの欲しい品物と、深夜も客がいるかどうか | 攻略本 DATA4(p.92-95) | CONFIRMED_OFFICIAL |
| 誘致施設の一部の買い物人口(会社90、プール40、遊園地750 など) | reference_sim TOWN_FACILITIES(攻略本の表) | CONFIRMED_OFFICIAL |

住宅や店など、ふつうの建物の買い物人口は資料にない。また、運動場と公園は、PDF3 p.10の表と数値が食い違う。
PDF3は運動場100・公園30、TOWN_FACILITIESは運動場30・公園24。reference_simの値をそのまま使った。

## 決定

町の地図で建物をタップすると、画面下にカードを出す。カードの内容は次のとおり。

- 建物の名前
- 買い物人口: 資料に数がある建物だけ表示する
- 欲しい品物
- 「朝から夜だけ客がいる」か「深夜も客がいる」か
- その建物が自分の店の商圏(周囲16×16)の内か外か

ライバル店をタップした時は、これまでどおりライバルの窓が出る。

## テスト

- `android_preview_smoke.gd`: 商圏内の建物をタップすると、名前・欲しい品物・「お店の商圏内」が出ること。「閉じる」で消えること。
- 契約テスト: 買い物人口の値(会社90、遊園地750、交番は資料なし)と、処理・確認文の存在。
- 結果: Python 773件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
