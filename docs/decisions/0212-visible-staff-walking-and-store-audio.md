# 0212 — 店員表示・歩行・レジと店員の原音接続

## 背景
0.5.0の利用者から「店員がいない」「店員と客の移動アニメーションがない」「レジと店員の声がない」と指摘され、1時間の原作動画が提供された。

## 確認した資料と範囲
- 提供動画 `【作業用BGM】ザ・コンビニ　1時間【プレイ動画】_HD_60fps.mp4`（3599.93秒、1280×720、約59.94fps）。60/300/600/900/1200/1800/2400/3000秒を抽出、300.0〜301.9秒を0.1秒刻みで確認。全編を連続視聴したとはしない。
- 300/600/900秒で、店内の人物、レジ側の店員、休憩室内の店員、入口からの来退店とレジ待ちを確認。CONFIRMED_VISUAL。
- 既存解析 `interior_display.py:overlay_staff_records` は、勤務中の人物を床の人物画像から描画する処理とは別に、state0の店員を休憩室上へ描画している。CONFIRMED_BINARY。
- `staff_loop_selected.py` は休憩からレジ業務を開始すると0x80、レジ到着後に客がいなくなると0x100を立てる。`customer_queue_state.py` は会計成功で0x200を立てる。`source_actor_tables.json:sound_flags` と `program_audio.gd:main_requests` の対応は各22/23/10。CONFIRMED_BINARY。

## 実装
- 描画でstate0を除外していた条件を削除。名簿に人が存在し有効座標なら描画する。休憩中は原作の室内座標を使う。ゲームルールや採用人数を変更しない。
- 原作人物テクスチャの経路へ既存の補間/A・B切替を接続。以前は歩行のphaseを計算しても固定のMAN0画像で上書きしていた。
- **REMAKE_BALANCED_DEFAULT**：手元のMAN0には各人物の4方向しかない。追加するB姿勢は足元4ピクセル行を左右反転した補完画像で、頭と胴体は維持する。原作から回収した歩行差分だとはしない。切替時間も既存のクライアント補間を用いる。
- 原作会計成功→SE10、休憩からレジ勤務→VOS22、客がいなくなりレジを離れる判断→VOS23。既存165音源を用い、会計用の合成音を原音へ置換。フレームごとの再要求や別店舗の音の混入を防止する。
- 新しいイベント名にも日本語訳を追加。

## 検証
`people_service_ui_smoke.gd` が実際の開店・店員3人の休憩・勤務移動・客の移動・売上成立からのSE10/VOS22・原state遷移によるVOS23、消音、別店舗除外、再読みによる重複なしを確認する。12組のA/B画像について上12行が同じで画像全体が異なること、停止時Aと移動補間も確認する。Linuxの実描画で休憩・勤務・歩行A/Bを目視確認する。Android実機と実際のスピーカー音量は未確認。

## 対象外・制約
全人物状態と原作乱数列の完全一致、レジ行列の完全な幾何、全効果音生成元、物理SPUの音質差、原作と完全一致する歩行画像は未解決。既存の他の合成効果音も残る。
