# 0193: 2店舗目以降を見て、動かせるようにする(タスク#123)

## 背景

ユーザーから「ライバル店を買収して2店舗目にしたが、2店舗目の中を見られない。2店目に対して何もできない」という指摘があった。

これまでは、買収した店も「チェーンを広げる」で増えた店も、店舗数を数えるだけだった。中身がなかった。

## 根拠

- プレイヤーの店同士も客を取り合う(SS実プレイ、B、`docs/research/ss-layout-entrance-register-and-chain-cannibalization-2026-09-06.md` 4節)。
  - 2・3号店の営業時間を短くすると、本店に客が戻った。
- 新規出店は、町の地図で土地を選び、店舗を選ぶ(1店目と同じ流れ、CONFIRMED_VISUAL)。

## 決定

シミュレーションは店ごとの状態を持つ(`STORE_FIELDS`、`_stores`)。

- 店ごとに持つもの:床と什器、商品、店員、客、値段、営業時間、許可、宣伝、人気・評価、アンケート、売上。
- 全店で共通のもの:お金・暦・町・ライバル。
- 時間は全店いっしょに進む。
- 日割りの維持費と人件費、月末の評価とアンケートは店ごと。

店が増える方法は2つ。

- ライバル店の買収。
  - REMAKE_BALANCED_DEFAULT:ライバルの元の内装は分かっていないので、開店時の小型店として手に入る(商品付き)。
  - 店員は、他の店で働いていない3人。
- 販促 →「土地を選んで新しい店を出す」。
  - 1店目と同じく、土地 → 店舗を選ぶ。
  - 土地代と建築費を払う。町の10店舗までの上限を守る。

店同士の関係:

- 客は、ライバル店と自分の他の店の両方と分け合う。
- 同じ人を2つの店で雇うことはできない。
- 1万人ごとの来客記念(人気+100)は、チェーン全体の累計で数え、全店の人気を上げる。

画面:

- 下の帯の店名が「本店 ▼」ボタンになる。押すと店の一覧(評価・本日の売上・客数、「この店へ」)が開く。
- 町の地図で自分の店をタップすると、その店に入る。
- 内装・店員・営業方針・販促・調査は、表示中の店に対して働く。
- 他の店での出来事の通知には、［2号店］のように店名を付ける。

セーブ:

- schema 10。本店は今までどおり一番上に置く。他の店は "branches" に入れる。
- schema 9 のセーブも読める。買収済みの店は、店として開き直す。

## 性能

2店舗で4日間を回すと約2秒。1店舗では約0.6秒だった(1ティックあたり約0.36ms)。

## テスト

- `_check_branch_stores`:次を確かめる。
  - 買収で2店になる。表示は本店のまま。本店は2号店と客を分ける。2号店の中を見られる。
  - 2号店の店員は本店と別の人。本店の人を2号店で雇えない。値段は店ごと。両店が売る。
  - 土地を選んで3号店を出せる。セーブとロードで3店と各店の状態が戻る。schema 9 のセーブの買収店が店になる。
- android_preview_smoke:次を確かめる。
  - 販促 → 新しい店を出す → 土地 → 店舗 → その店が表示される。
  - 店名ボタン → 一覧 → この店へ/本店へ。
  - ロード後も店の数が同じ。
