# 0.6.5 メニュー選択と説明枠の修正（0214）

## 原因と変更
ユーザーの1000282727.jpgでは町の説明枠が左操作ボタンの下へ入り込む。
PhoneBuildingCardは左端8、幅1104という旧配置だったため、左端168、幅944へ修正。
PSメニューの入力処理がモーダル外の左右レールも消費していた。レール領域は通し、
touch_controls.gdでネイティブScreenTouchの押下・解放・キャンセルを扱う。
メニューの押下だけを消費するとTownViewの解放判定が背後の建物を選ぶため、解放も遮断。

## 検証
Viewport.push_inputを通す新しいps1_menu_dispatch_smokeで、直接タップ、
決定・取消・コマンド、背後の建物への入力遮断、説明枠の範囲を確認。
既存ps1_touch_audit / ps1_ui / source_audio_uiも成功。
Python786成功、既存2失敗、想定失敗1。headless_smokeは既存の旧町パネル寸法条件で失敗。
前回の引継ぎにも同じ失敗が記録されており、今回の全体テスト成功とはしない。
APK0.6.5/code65、com.conveniremake.touchfix、既存署名。Android実機未確認。

## 再開
このブランチの修正版を継続使用する。mainと未マージPR270を確認したが他ブランチは変更しない。
既存の未解決解析6件は保留。実機上で直接タップと左右ボタン、説明枠の表示を確認する。
