# 0178: 店員の成長・体力とアンケートをセーブに含める(タスク#107)

## 背景

ロードすると、次の3つが最初の値に戻っていた。

- 店員の能力の成長(レジ・サービス・清掃・セキュリティ・補充)
- 店員の体力
- 今月と先月のアンケート

セーブには、どの候補者を雇っているかしか入っていなかった。

## 根拠

新しいゲームの規則や数値は加えていない。すでにある状態を、そのまま保存するだけである。

## 決定

- セーブに `staff_state` を加えた。店員ごとに、5つの能力値、体力、疲れ切っているかどうかを保存する。
- セーブに `survey` を加えた。今月の「買った商品」と「欲しかった商品」、および先月の結果を保存する。
- ロード時は、雇っている店員を元に戻した後に、これらを戻す。
- JSONを通すと数が小数になるので、アンケートの数は整数に戻す。
- セーブ形式は9のまま。形式9はまだ配布していないため、番号は上げない。

## テスト

- `headless_smoke.gd`(`_check_saved_staff_and_survey`):
  - 能力・体力・疲れ切った状態・アンケートを変えて保存する。
  - 保存データは、実際のセーブファイルと同じくJSON文字列にしてから読み戻す。
  - 変えた値がすべて戻ることを確認する。
- 契約テスト: 保存する項目と、スモークテストの確認文。
- 結果: Python 768件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
