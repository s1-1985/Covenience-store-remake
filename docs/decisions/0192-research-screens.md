# 0192: 調査の収支とアンケートを別の画面にする(タスク#122)

## 背景

ユーザーから「収支とアンケートはそれぞれ独立した画面で表示して」という依頼があった。
これまでの「調査」は、1つの窓に全部を縦に並べていた。

## 根拠

原作の「調査」には次がある(`docs/research/menu-hierarchy-evidence-2026-09-05.md`)。

- 「全店収支グラフ」:名前は CONFIRMED_COMMUNITY。
- 各店の売上成績と売れ筋のアンケート:CONFIRMED_COMMUNITY、SS実プレイ記事。

## 決定

- 「調査」は画面の一覧にした。
  - 全店収支グラフ/店舗成績/アンケート/町と目標。
- それぞれを別の窓で開く。「← 調査にもどる」で一覧に戻る。
- 全店収支グラフ:12か月のグラフと、月ごとの売上・収支(直近6か月)。
- 店舗成績:その店の今月の売上・来店・評価・在庫・先月の収支と、今月来た客層。
- アンケート:次の2つを、商品の絵と棒で順位表にする。今月/先月を切り替えられる。
  - よく売れた商品
  - 欲しかったのに無かった商品
- 画面の作りは本プロジェクト独自(REMAKE_BALANCED_DEFAULT)。

## テスト

- android_preview_smoke:調査 → アンケート、戻る、全店収支グラフが、それぞれの窓で開く。
- 契約テスト:`test_research_screens_stand_alone`。
