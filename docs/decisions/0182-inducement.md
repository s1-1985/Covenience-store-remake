# 0182: 販促 → 誘致(タスク#111)

## 背景

原作の「販促」には、宣伝のほかに「誘致」がある。プレイヤーが選んだ場所に施設を建ててもらうコマンドで、
町の人口と店の客を増やしたり、交番・消防署で店のセキュリティを上げたりできる。これまでは未実装だった。

資料どうしの食い違いと、仮の判断は次のとおり。

- 体育館は、誘致の表では2×3、DATA4では3×3、PDF3 p.10では「3×3(?)」。DATA4の3×3を使った(PROVISIONAL)。
- マンションはDATA4に無い。住宅(大C)の絵で描いた(PROVISIONAL)。
- 表のサイズが向きだけ違うもの(消防署2×3とDATA4の3×2など)は、DATA4の向きを使った。絵がその向きで描かれているため。

本プロジェクト独自の決め方(REMAKE_BALANCED_DEFAULT)は次のとおり。

- 場所代の計算式は資料にない。その場所の店用地の地価を、施設のマス数に合わせて換算し、その1/10とした(10万円単位に丸める)。
  - 1/10は、動画の値段(交番200〜400万円、プール380万円)に合わせて決めた。
  - この計算では、店の隣の交番が210万円、プールが320万〜390万円になり、動画の範囲に入る。
- 完成までの追加日数(0〜3日)は乱数で決める。
- スマホでは、援助額と場所代を「誘致する」を押した時にまとめて払う。動画では援助額を先に払い、やめると戻るので、最終的に払う額は同じになる。

## 決定

- `tools/guide_store_site.py` に誘致施設の表と場所代の計算を置いた。`guide_town_map.inducement` ブロックとして書き出す。
  誘致できる施設の建物データも `building_catalog` に入れた。
- 施設の絵(`assets/raw/conveni_map_assets_v2`)を、1マス32pxに縮小して `game/assets/town` に加えた。
  APKの30MiBの制限に収めるため、この18枚だけ非可逆圧縮で取り込む。
- シミュレーションに次を加えた。
  - `inducement_quote`: 置けるかどうかと値段を返す。置けないのは次の場合。
    - 道路・線路・地図の外にかかる
    - コンビニにかかる
    - 誘致中の施設がある
  - `try_induce`: 援助額と場所代を払い、4〜7日後に完成する予定を立てる。
  - 日付が変わる時に完成を確認する。完成すると、その場所の建物を取り壊し、施設を町の建物として加える。
    施設は客と欲しい品物を持つので、店の商圏と来客が変わる。
  - `inducement_security_bonus`: 店のセキュリティ値に施設の効果を足す。
  - 援助額と場所代は一度きりの支出として扱い、月末の×8に含めない。
  - セーブ(形式9)に、完成した施設と工事中の施設を保存する。ロード時は町を作り直してから施設を建て直す。
- 町の地図は、シミュレーションが持つ建物の一覧(誘致で増える)を描く。工事中の場所には「工事中」と表示する。
- スマホの操作は次のとおり。
  - 販促の窓の「誘致」に、施設の絵・名前・援助額を並べた。
  - 施設を選ぶと町の地図に切り替わり、施設の大きさのカーソルで場所をタップする。
  - 「誘致可能/誘致不可能」、援助額＋場所代＝合計、巻き込む建物の数を表示する。「誘致する」で決まる。
  - 開始と完成はお知らせで表示する。

## テスト

- `headless_smoke.gd`(`_check_inducement`) で次を確認した。
  - 18施設あること。
  - 店の隣の交番が「援助額40万＋場所代210万」になること。
  - コンビニや道路の上には置けないこと。
  - 払った額、完成までが4〜7日であること、1軒ずつであること。
  - 工事中はセキュリティが上がらず、完成すると建物が増え、近くの人口が増え、セキュリティが+40になること。
  - プールが家を巻き込むこと。
  - JSONを通したセーブ/ロードで、完成済みと工事中の施設が戻ること。
- `android_preview_smoke.gd` で次を確認した。
  - 販促の窓から交番を選び、町の地図を実際にタップすると、値段が出て「誘致する」で工事が始まること。
- 契約テストで次を確認した。
  - ブロックがツールの出力と一致すること。
  - 援助額とセキュリティの数値、Python側でも場所代が同じになること。
  - 絵と取り込み設定、タグ、スモークテストの確認文。
- 結果: Python 772件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 月末に町の建物が自然に増えること(攻略本 p.45)。
- 人口による駅・役所・都庁の自動建設(PDF3 p.10)。
- 火事・強盗と、セキュリティ施設が無い時の発生率。
- 地図上の建物をタップして名前と買い物人口を見ること。
