# 0161: 町マップを攻略本p.11の初級マップ画面から再現する(タスク#90)

## 背景

ユーザーの指摘に「マップはない」があった。町の画面(`town_view.gd`)は、タスク#72で
「施設の配置データが無い以上、施設を並べるのは町の捏造になる」として、自店とライバル店の
印だけを描く作りになっていた。

攻略本 p.11「マップ」(PDF3 5ページ目)には、初級マップの開始時の画面写真
(1年目1月1日[快晴]00:00 ¥200,000,000)が載っている。スキャン元の解像度で見ると、
草地と土、道路、線路、家、橙色の5×5の区画が1マスずつ見分けられる。これで配置データの
出どころができた。

## 決定

### 1. 画面写真を1マスずつ読む

- 切り出し: `assets/raw/conveni_guide_town_v1/beginner_map_start.png`
  (スキャン元の解像度。元PDFのSHA-256と切り出し位置は`manifest.json`)。
- 格子(CONFIRMED_VISUAL、画像上の実測):
  - 縦の道路は約98.75pxごとで、これが10マス。1マスの幅は9.875px。
  - 橙色の区画(5×5)の高さは約52px、横の道路の間隔(76.5→285.5px)が20マス。
    1マスの高さは10.45px。印刷上、縦横の比が1ではない。
  - 道路と線路は、マスの中心を通る直線: 縦の道路は列12・22・32、横の道路は行6・19・26、
    線路は行12(1本の画面幅の二重線)。
- 各マスの種類(PROVISIONAL): `tools/build_guide_town_map.py`が色の割合で、草地・土・
  建物・区画に分ける。網点の印刷を色で分類しているため、個々のマスには誤りがありうる。
  区画は画面上で一続きの5×5なので、縁のノイズを外接矩形で補った。
- 結果: 41×35マス。`game/data/vertical_slice.json`の`guide_town_map`に文字列の行として
  保存(G草地/D土/R道路/T線路/B建物/O区画)。

### 2. 町の画面

`town_view.gd`は、設定に`guide_town_map`があればその町を描く。

- 描き方: 草地・土・道路(隣の道路や線路とつながる)・線路(砂利と2本のレール)・
  建物・区画。区画には「本店」と書く。
- 家の絵: REMAKE_BALANCED_DEFAULT。建物のマスには、このプロジェクトが生成した1×1の
  家の絵3種(`assets/raw/conveni_map_assets_v2`、原作の絵ではない)を、マスの位置で
  決まる順に置く。建物の種類(学校・プールなど)までは読み取っていない。
- ライバル店: これまでどおり区画からの相対位置に印を描く。
- 区画の意味: 「自店の敷地」とするのはPROVISIONAL(開店前の画面のため)。
- 画面サイズ: 町は店と同じ場所に、画面に収まるマスの大きさで描く(`main.gd`の
  `_fit_store_view()`)。スマホでは、ショートカットに「町／店内」ボタンを足した。

### 3. 開始資金の根拠を補強

同じ画面写真に1年目1月1日 00:00の¥200,000,000が写っている。初級マップの開始資金2億円は、
これまでのCONFIRMED_COMMUNITYに加えてCONFIRMED_VISUALになった
(`guide_starting_store.gd`のコメントに追記)。

## テスト

- 契約テスト(numpy/Pillow無しでも動くもの):
  - 41×35であること、凡例以外の文字が無いこと。
  - 線路と画面幅の道路2本が全列にわたること、縦の道路が全行にわたること。
  - 区画がちょうど5×5であること。
  - 切り出し画像のハッシュがmanifestと一致すること、証拠のタグがあること。
  - 家の絵3種があること、`town_view.gd`のREMAKEタグ。
- 契約テスト(numpy/Pillowがある環境のみ): 読み取りスクリプトを画像にもう一度かけた結果が、
  JSONと完全に一致すること。CIのPythonには入っていないため、CIでは飛ばされる。
- タスク#72の契約テスト「町の画面は絵を使わない」は、「使う絵は区画データの建物マスに
  置く家の絵3種だけ」に改めた。
- スモーク: UIの町の画面が41×35の町を描き、パネルの左に収まり、1マス8px以上であること。
- 結果: Python 754件成功(期待失敗1件は既存)。Godotスモーク、Android previewスモークとも成功。
  スクリーンショットで、画面写真と同じ道路・線路・家並みの町が表示されることを確認した。

## 明示的に対象外

- 建物の種類の読み取り(学校・プール・会社など)と、施設ごとの絵。
- 町の中の人や車の動き、時間とともに建物が建つこと(町の発展)。
- 店の場所を選んで出店すること。区画は1か所に固定。
- 画面外のマップの範囲(原作のマップは画面より広い)。
