# 0170: 店員の体力と休憩(タスク#99)

## 背景

タスク#97で店員が補充・清掃で動くようになった。ただし、いくら働いても疲れなかった。
原作では、店員は働くと体力が減り、0になると休憩室で休む。これは決定書0168で
「対象外」として残していた項目。

## 根拠

- 初代の店員Wiki(`behavior-rules-evidence-2026-09-05.md` §7、`first-title-wiki-parameter-extraction` §5)。CONFIRMED_COMMUNITY:
  - レジ・補充・清掃などで体力が減る。
  - 0になると休憩室へ戻り、原則として全回復まで休む。
  - 休憩中の回復は通常+1。敏捷性が高いほど+2になる確率が上がる。敏捷100でおよそ9割という観測がある(PROVISIONAL)。
  - 解雇してすぐ雇い直すと、体力が満タンで戻る。
- 各候補の体力(最大値)と敏捷性: 攻略本の店員データ(CONFIRMED_OFFICIAL、`staff_candidates`)。
- レジ係の体力が少ないと、会計の後すぐ休憩に行き、レジが無人になることがある(`first-title-wiki-parameter-extraction`)。

## 決定

- 各店員の体力の最大値 = その候補の攻略本の体力。ゲーム開始時・雇用時・ロード時は満タン。
- 会計1人・棚1つの補充・1マスの掃除を終えるたびに体力を1減らす。REMAKE_BALANCED_DEFAULT。
- 0になると「疲れた」状態になる。新しい仕事は取らず、休憩室へ行って休む。レジ係も同じで、その間レジは無人になり、客は並んで待つ。
- 休憩室にいる間は、ゲーム内の1分ごとに1回復し、確率 0.9×敏捷性/100 で2回復する。REMAKE_BALANCED_DEFAULT。敏捷100で9割という観測値を通る直線にした。満タンになると持ち場へ戻る。客のいない時間に休んでいるときも回復する。
- 店内では、各店員の足元に小さな体力ゲージを描く(表示のみ)。
- 実際のゲームだけで有効にする(`staff_work.stamina_enabled`)。試作店のテストでは疲れない。
- 体力はセーブしない。ロード後は全員満タンで始まる。店員の作業途中の状態を保存しない、これまでの扱いと同じ。

## テスト

- `headless_smoke.gd`: 開始時は攻略本の体力で満タン。体力1で仕事を終えると疲れた状態になる。疲れている間は新しい仕事を取らない。満タンになるまで休み、その後仕事に戻る。試作店では疲れない。
- 契約テスト: タグ、休憩の条件、全候補の体力が正の値であること。
- 結果: Python 760件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
- 1日動かした結果: 掃除担当の2人は1日で体力を約60使った。閉店時刻まで誰も0にはならなかった。

## 明示的に対象外

- 体力の長期的な増減(「わずかに増減する」という記述はあるが量は不明)。
- レジが無人のとき、他の店員が代わりに入ること(資料に無い)。
- 体力のセーブ。
