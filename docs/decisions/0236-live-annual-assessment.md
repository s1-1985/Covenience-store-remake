# 0236 — 前年帳簿と表示時の年次評価

## 背景
0.8.6は年次予約時の集計結果を固定していた。既存原解析では3CEACが月次→年次を予約し、3F7FCが消費時に活動自社店の前年D0C・現在評価・人口・累積入店を読む。

## 決定
店舗別に前年から3年分の売上を保持し、原の32bit加算・年次繰越を接続する。年次繰越と既存賃金/加齢の重複を年度ガードで抑止しJSONへ保持。会計と繰越の後に月次→年次を予約、表示時に既存原採点を呼び、結果をlast_owner_reviewへ残す。クリアも表示時点の評価から判定する。旧保存の店舗別過去年商は推定しない。既に待機する旧年次報告の明示集計だけ互換表示する。

## 検証
原55限定区間と新しい本体/UI回帰2本。12月→1月、先行通知、売却後除外、現在年売上の分離、人口/評価/累積入店、92点/100点のクリア境界、来客記念中断とJSON復帰を確認。関連Godot54本成功、Python786成功/既存2失敗/想定1。古いPython固定ソース形状の検査を必要な呼出し順の検査に改めた。headless全体の既存町寸法失敗は継続。
