# 0165: スマホで店内を等倍表示し、商品の絵が見えるようにする(タスク#94)

## 背景

ユーザーの指摘:「さんざんスプライトを作成したのに、なーんにも活かさないの？ chatgptが生成した
商品のスプライトはなかなかのもんだった」。

事実として、生成した商品の絵(`conveni_products_remake_v3`、25カテゴリ×在庫3段階)は、
タスク#68以降ずっと棚の上に重ねて描いている。ただしスマホでは、店(12×8マス)の右に
ショートカット列とパネルを並べていたため、店を0.81倍に縮めていた。1マスの棚に9個並ぶ
商品の絵が小さく、見えにくかった。

## 決定

画面の配置だけを変える(ゲームの中身は変えない)。

- スマホでは店を等倍(1マス72px)で、画面の左側いっぱいに描く。
- ショートカット列は画面の右端に移す。
- パネルは引き出しにする。ショートカットを押すとその節を開いて店の上に重ね、
  「閉じる」ボタンで閉じる。閉じている間は画面の外に置き、非表示にはしない
  (配置の計算が止まり、ショートカットの移動先がずれるのを防ぐため)。
- 「町／店内」を押すとパネルは閉じる。
- 店内の黄色い点(客・店員が立つ位置の目印)は、原作の画面には無い開発用の表示なので、
  内装の編集で什器を選んでいる間だけ出す(PC版も同じ)。

## テスト

- Android previewスモーク: 店の描画倍率が1.0であること、パネルが閉じた状態で始まり、
  ショートカットで開き、「閉じる」で閉じること。
- 結果: Python 756件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
  スマホ配置のキャプチャで、棚の商品の絵が判別できることを確認した。

## 明示的に対象外

- 店内の拡大縮小(ピンチ操作)。
