# 0172: ライバル支店の調査と買収(タスク#101)

## 背景

タスク#98でライバル本店と2号店を町マップに置いた。ただし、ライバル店に対してプレイヤーができることは何も無かった。
攻略本と初代Wikiには、ライバル店の調査と買収が載っている。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| ライバル店のメニュー「調査する 費用 / 買収する 費用 / 何もしない」 | 攻略本 p.53、p.65、p.72-73 の画面写真 | CONFIRMED_OFFICIAL |
| 買収すると、店も社員も土地も自分のものになる | 攻略本 p.53「相手の店や社員ごと自分のものに」、p.72「土地も店舗も一度にプレーヤーのものに」 | CONFIRMED_OFFICIAL |
| 初級マップの2号店の買収額は46,721,490円 | マップのDATA欄(クイックリファレンス書籍頁66-83) | CONFIRMED_OFFICIAL |
| 本店は買収できない | 初代Wiki(DATA欄でも買収額は2号店にしか無い) | CONFIRMED_COMMUNITY |
| 調査費 600,000円 | 2号店の46,721,490円が載っている画面写真2枚。p.53の写真では500,000円 | PROVISIONAL |
| 買収額は年数や売上とともに上がる | Wiki: 開始直後は約4,500万円、数年後は2億円超 | CONFIRMED_COMMUNITY(計算式は不明) |

## 決定

- 町マップ(土地選び以外のとき)でライバル店をタップすると、下にメニューが出る。
  - 店名と「調査する(¥600,000)」「買収する(¥…)」「何もしない」。
  - 本店の買収ボタンは「本店は買収できません」と表示して押せない。
- 調査すると、DATA欄の値が表示される(営業時間・人気・警備・清掃・サービス)。調査は1店につき1回。
- 買収額 = 46,721,490円 × 地価の年ごとの伸び率。REMAKE_BALANCED_DEFAULT。
- 買収すると代金を払い、その店はライバル店でなくなる。
  - 自分の店として店舗数に1を足す(シナリオの達成条件にも数える)。
  - 町マップには、青い「02」のマーク(プレイ動画から切り出した`map_blue_02`)を描く。
  - 本店の周辺人口を計算し直す(客を取り合う相手が1店減る)。
- 買収した支店そのものの売上や店内は計算しない。REMAKE_BALANCED_DEFAULT。これまでの「チェーン拡大」と同じ扱い。
- セーブ形式を7に上げ、買収した店と調査した店を保存する。新しいゲームでは、ライバル2店とも元に戻る。

## テスト

- `headless_smoke.gd`:
  - 本店は買収できない。
  - 2号店の開始時の買収額は46,721,490円。
  - 調査は600,000円で1回だけできる。
  - 買収すると代金を払い、店舗数が2になり、ライバルが1店減り、自店の周辺人口が減らない。
  - セーブ/ロードで買収・調査が残り、リセットで元に戻る。
- `android_preview_smoke.gd`: 実際のゲームで2号店をタップすると「買収する（¥46,721,490）」が出る。買収すると「競合1店」になる。本店は買収できない。
- 契約テスト: 値、タグ、マークの画像、セーブ形式7、効果音の対応。
- 結果: Python 762件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- ライバル店の経営AI(値下げ・広告・撤退・新規出店)。
- 買収した支店の店内画面・店員の移動・売上。
- 支店の売却。
