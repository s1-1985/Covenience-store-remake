# 0224: 宣伝を会社の継続設定へ移す

原800E3688の5フラグと800275F8の時刻処理を本体へ接続する。UIは仮選択と確定を分離し、取消は設定も資金も変えない。広告費5倍の資金条件、費用1回分の会社支払、全活動店舗への人気効果、資金不足時の設定解除を採用する。

会社単位の設定/処理済み時刻を保存し、旧店舗別広告はIDの和集合へ移行する。過去支払は精算しない。処理済み時刻で重複請求と遡及実施を防ぐ。原作の同時刻内で設定を変えた際の全入力順までは再現確認していない。

根拠と限界は `docs/research/company-advertising-2026-11-20/README.md`。APK0.7.5、Android実機未確認。
