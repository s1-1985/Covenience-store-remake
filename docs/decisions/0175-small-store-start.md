# 0175: 土地の後に店舗を選び、小型店から始める(タスク#104)

## 背景

これまで新しいゲームは、攻略本p.48の大型店(12×8、棚34台)で始まっていた。原作では土地を買った後に
「店舗を選んで下さい」の画面で店舗を選び、最初に建てられるのは小型店だけだった。ユーザーの指示
(選択肢A)により、原作どおり小型店から始める。

作業中に、既存の不具合も見つかった。月末の決算は「4日間の収支×8」で計算しているが、土地の購入費も
この×8に含まれていた。21,000,000円の土地が月末に168,000,000円の支出として扱われ、新しいゲームは
最初の月末でほぼ必ず破産していた(タスク#95以降)。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| 土地の後に「店舗を選んで下さい」。店舗は2行×3列の6種類 | PS版画面写真(docs/research/ps-store-selection-lock-visual-2026-09-05.md) | CONFIRMED_VISUAL |
| 開始時に選べるのは左列の2種類だけ。残り4種類は暗く表示される | 同上 | CONFIRMED_VISUAL |
| 左上の店舗は¥6,000,000 | 同上 | CONFIRMED_VISUAL |
| 店舗1〜6の店内寸法: 5×8、8×5、7×10、10×7、8×12、12×8。建設費は小型600万円、中型1,200万円、大型1,800万円 | 攻略本 店舗データ(p.106-109)、reference_sim STORE_VARIANTS | CONFIRMED_OFFICIAL |
| 上段=店舗1・3・5、下段=店舗2・4・6 | 攻略本の表の並び順との対応 | 推論(STORE_VARIANTSと同じ扱い) |
| 月の収支 = 4日間の収支×8 | 攻略本 クイックリファレンス | CONFIRMED_OFFICIAL |
| 土地・建物などの一度きりの購入は×8に含めない | 明記された出典はない。×8にすると最初の月末で必ず破産するため、原作の通常の遊び方と合わない | 推論 |

小型店の初期配置は資料から復元できなかった。攻略本の「小規模店作成用おすすめアイテム」はスキャンから
読めない。そのため、配置は本プロジェクト独自のもの(REMAKE_BALANCED_DEFAULT)とした。ただし、次の数値は
攻略本p.48の店から類推した。

- 棚の数: p.48は床96マスに棚34台。小型店の床40マスでは 34×40÷96 = 14.2 なので14台。
- 商品の種類: p.48の商品別の棚の割合を14台に配分した(最大剰余法)。同点のときは、町の建物が欲しがる
  量(DATA4の「主なほしい品物」×建物のマス数)が多い方を選んだ。結果は、野菜2・清涼飲料2・菓子2・パン1・
  日用品1・インスタント食品1・魚1・肉1・下着1・弁当1・アイス1。
- 棚の種類、最初の在庫(満杯)、休憩室: p.48と同じ決め方。
- 同時に店内にいられる客の数: p.48の8人を床面積で縮めて3人(REMAKE_BALANCED_DEFAULT)。

## 決定

- `tools/build_guide_store_types.py` が `vertical_slice.json` の `guide_store_types` ブロックを書く。
  - 6種類の店舗について、ID、アイコン、大きさ、建設費、開始時に選べるか、画面上の位置を持つ。
  - 小型店2種類(5×8と8×5)には初期配置を持たせる。
- 土地の「この土地を買う」を押すと「店舗を選んで下さい」の画面が出る。
  - 6種類のアイコンを2行×3列に並べる。選べない4種類は暗く表示する。
  - 選んだ店舗の大きさ・建設費と、土地との合計を表示する。
  - 「この店舗を建てる」で、土地代と建設費を払って店が建つ。「戻る」で土地選びに戻る。
- シミュレーション:
  - `try_buy_store_site(origin, type_id)` は建設費も払う(支出の種類は `store_construction`、イベントは `store_built`)。
  - 選んだ種類が今の店と違えば、店を作り直す。床、什器、棚と在庫、店員の位置が変わる。雇った店員はそのまま残る。
  - セーブ形式を9に上げ、店舗の種類を保存する。ロード時は、保存された種類の店を作り直してから読み込む。
- 新しいゲームのシナリオIDを `guide-small-store-start-v1` にした。p.48の大型店のデータは残し、テストで確認を続ける。
- 小さい店は、店内表示の領域の中央に描く。
- 月末決算の修正:
  - 一度きりの購入は×8から除く。対象は土地、建設、支店展開、買収、調査、什器の購入・売却、許可、見本レイアウト。
  - 除外する種類は `CAPITAL_EXPENSE_TYPES` にまとめた。
  - 広告・仕入れ・人件費・維持費は、これまでどおり×8にする。
  - 決算記録に `capital_yen` を加えた。

## テスト

- `headless_smoke.gd`(`_check_store_types`):
  - 6種類の建設費、選べるかどうか、画面上の位置。
  - 中型店は建てられないこと。
  - 8×5の小型店を建てると、土地代と600万円が引かれ、床が16×10サブセルになること。
  - 棚14台がすべて在庫ありで、店員全員が歩ける位置にいること。
  - セーブ/ロードで店舗の種類が戻ること。
  - 小型店2種類とも、1日のあいだ客が同時に買い物をし、10回以上来店し、8種類以上の商品が売れること。
  - 最初の月末決算で、土地と店舗の27,000,000円が×8から除かれ、破産しないこと。
  - REMAKE_BALANCED_DEFAULTのタグ。
  - p.48店の既存チェックは、店舗の種類を外した設定で続ける。
- `android_preview_smoke.gd`:
  - 土地を買うと店舗選択が出ること。
  - 6種類のうち4種類が選べないこと。
  - 「小型店(5×8) ¥6,000,000」と表示されること。
  - 建てると土地代と建設費が引かれ、5×8の店が建つこと。
- 契約テスト:
  - ブロックが生成ツールの出力と一致すること。
  - 大きさと建設費がSTORE_VARIANTSと一致すること。
  - 棚の数と品揃えが類推どおりであること。
  - 什器が重ならず、入口からすべての操作位置と店員の位置に行けること。
  - 在庫が棚の容量と同じであること。
  - タグと、月末の除外対象。
- 結果: Python 766件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外

- 中型店・大型店の解禁条件と、店の改装(増築)。
- 店外設備(駐車場など)。
- 画面写真に写っている、店舗選択の前後で2,100円差がある理由(不明のまま)。
- 広告費を×8に含めるかどうかは、今回は変えていない(根拠なし)。
