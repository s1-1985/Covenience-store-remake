# 0181: スマホの画面を作り直す(タスク#110)

## 背景

ユーザーから「UIがとにかく分かりづらいし使いづらい。原作の動画や攻略本の良いところを参考にし、スマホの操作に
合わせて改良してくれ」と指示があった。

それまでのスマホ画面の状態は次のとおり。

- 右端のボタンを押すと、長い一本のパネルが店の上に出てくる。
- パネルでは、ドロップダウンと「実行」ボタンの組み合わせが何十個も縦に並んでいる。
- 一時停止はパネルの奥にあった。
- 棚をタップした後に床をタップすると、棚が動いてしまう。
- 客をつまみだす方法、空いた棚に商品を並べる方法が、実質なかった。

## スマホ向けに変えたこと(REMAKE_BALANCED_DEFAULT)

画面の各部分は次のとおり。

- **右端の列**: コマンドを縦に並べる。内装、店員、営業方針、販促、調査、町マップ、システム の順。
  - 大きなボタンに絵を付けた。
  - 押すと、店の横に窓が開く。店は左へ寄せ、見えたままにする。
  - 窓は「×」で閉じる。
- **上の帯**: 一時停止/再開のボタンと、速さ(×1・×2・×4)のボタンを置いた。
- **下の帯**: 店名と、許可のマーク(持っていない許可は薄く表示)を置いた。
  - 最新の出来事を1行で表示する。
  - 「本日の売上」を表示する。原作の金額が何を表すかは分かっていないので、これはこのプロジェクトの判断。

各窓の中身は次のとおり。

- **内装**: 移動・入れ替えの切り替え、回転、売却、見本に戻す、を置いた。
  - 配置は、設備の絵と値段を3列に並べた表から選び、空いたマスをタップして置く。
  - 棚などを動かせるのは、この窓を開いている間だけ。それ以外の時にタップしても、中身の表示だけで何も動かない。
- **店員**: 3人の顔、役割、今の仕事、体力のゲージ、5つの能力を表示する。
  - 「交代」を押すと候補者の一覧が出る。候補者ごとに、履歴書の目安(普通/高い)と日給を表示し、「雇う」で交代する。
- **営業方針**: 値段は「－5%」「＋5%」「定価」のボタンで変える。
  - 営業時間は7種類のボタンから選ぶ。
  - 販売許可は、マーク、手数料、「申請」ボタンを並べた。
- **販促**: 宣伝5種類の絵と値段、チェーン拡大(10店舗の上限を表示)を置いた。
- **調査**: 今月の売上、来店数、評価、在庫、先月の収支、アンケート、町の情報、最近の出来事を表示する。
- **システム**: セーブ、ロード、音、タイトルへ。

カードとお知らせは次のとおり。

- **棚のカード**: 棚をタップすると、商品の絵、在庫、「補充」を表示する。
  空の棚には「商品を並べる」が出て、並べられる商品の絵から選べる。
- **客のカード**: 客をタップすると、かごの中身と「つまみだす」を表示する。
  つまみだせるのは、レジ待ちと会計中の客だけ。
- **お知らせ**: 次の出来事は、下の帯の上に数秒だけ表示する。
  - 月末の収支
  - ライバルの撤退・出店
  - 客が怒った
  - 店員が疲れた
  - 操作の結果

見た目は次のとおり。

- 窓は明るいクリーム色にした。
- 選んでいる項目は、原作の選択帯に合わせて桃色にした。
- ボタンは緑色にした。
- タイトル画面も同じ見た目にした。

デスクトップ版の右パネルはそのまま残した。スマホではこのパネルを表示しないが、窓のボタンはパネルと同じ処理を呼んでいる。

タグは、`phone_ui.gd` の冒頭、`android_preview.evidence_note`、テストの3か所にある。

## テスト

`android_preview_smoke.gd` の旧パネルの確認を、次の確認に置き換えた。

- 6つのコマンドが、それぞれ窓を開く。窓がコマンドの列に重ならない。
- 内装の窓だけが配置を変えられる。「×」で閉じる。
- 内装の外で床をタップしても、選択が外れるだけで何も動かない(実際のタップで確認)。
- 一時停止と速さのボタンが効く。
- 営業方針の「－5%」で値段が下がる。
- 営業中に棚を買って置ける。そのカードの「商品を並べる」から絵を選ぶと、商品が並ぶ。
- レジ待ちの客をタップすると、かごの中身と「つまみだす」が出る。押すと、その客は店を出る。
- システムの窓からセーブできる。

契約テストでは、次を確認する。

- `phone_ui.gd` の根拠の説明とタグ
- コマンド名
- 絵の素材のファイル
- `evidence_note`
- スモークテストの確認文

結果: Python 771件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。
Xvfb上で実際に描画し、各窓・棚のカード・タイトル画面の見た目も確認した。
