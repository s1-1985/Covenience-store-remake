# 0227: 調査状態の月初失効とライバル店舗の指操作

## 背景
原235E0の月初調査フラグ消去は解明済みだったが、本体の調査済み辞書は月をまたいで残っていた。ネイティブでも旧の下側操作パネルが表示され、他の紙枠メニューと異なる操作になっていた。

## 決定
期間1・午前0時に調査状態を失効し、月内/読込だけでは消去しない。未調査3択、調査済み詳細/既定2の原子UI分岐をネイティブへ接続する。調査50万と買収を区別し、調査は売主へ入金しない。スマホ用の費用確認/取消と対象・金額・月・UIDの再照合を加える。既存直接買収APIは維持する。

## 検証
原26区間を追加実行、関連Godot29本成功。マップ指入力、確認/取消、月内/翌月/JSON、同額資金、重複請求、古い対象/金額拒否、本店禁止、調査なしの直接買収、店員/在庫の引継ぎを検査。Python既存2失敗・想定1、headless旧町寸法失敗。研究READMEに出典と限界を残す。

## 範囲外
原の全所有権バイト・売主資本台帳・原UIのピクセル完全一致・Android実機・未解決6件。R03自体は既存解明済みで、新しい解決数へ数えない。
