# 0174: 営業時間を選べるようにし、閉店中は客が来ない(タスク#103)

## 背景

これまで店は一日中開いていて、客も24時間来ていた。一方で、人件費と維持費は「16時間営業」
(`opening_minutes_per_day=960`)として計算していた。原作の営業方針には営業時間の選択がある。

## 根拠

| 内容 | 出典 | 段階 |
|---|---|---|
| 定時営業5種類(AM10:00〜PM6:00、AM7:00〜PM11:00、10/11時〜AM2:00、PM0:00〜AM4:00、PM7:00〜AM11:00)、24時間営業、臨時休業 | 攻略本 PDF3 p.2 | CONFIRMED_OFFICIAL |
| 営業時間が長いほど売上は伸びるが、経費も増える | 同上 | CONFIRMED_OFFICIAL |
| 3つ目の開始時刻は、スキャンで11時か10時か読みにくい | — | 10時とした(印刷された「16時間営業」とPS版レビューの一覧に合う) |
| 最初はAM7:00〜PM11:00営業がおすすめ | 攻略本 p.23 | CONFIRMED_OFFICIAL |
| 人件費 = 時給 × 営業時間 | 攻略本 PDF3 p.2・p.6 | CONFIRMED_OFFICIAL |
| 閉店中・臨時休業中は、人件費などの維持費がかからない | 初代FAQ | CONFIRMED_COMMUNITY |
| ゲームは1年目1月1日 00:00から始まる | 攻略本 p.6・p.11の画面写真 | CONFIRMED_OFFICIAL |

## 決定

- 実際のゲームは00:00に始まり、営業時間はAM7:00〜PM11:00から始まる。
- パネルの価格方針の下に「営業時間」の選択肢(7種類)を置いた。営業中でも変えられる。
- 客は営業時間中にしか来ない。閉店時刻に店内にいる客は、そのまま買い物を終えて帰る。
- 人件費・維持費は既存の計算で、1日の営業分数に比例する。臨時休業は0分なので、これらはかからない。
- 閉店中は、画面上部の時計の横に「閉店中」と出す。
- セーブ形式を8に上げ、営業時間を保存する。
- 試作店のテストは、これまでどおり一日中開いている。

## テスト

- `headless_smoke.gd`: 00:00開始・AM7:00〜PM11:00であること。各プリセットの営業分数(8時間、16時間×4、24時間、0)。00:00〜06:39に客が入らないこと。8:00は営業中。AM10:00〜AM2:00は1:00に営業中で16時間。臨時休業は時間比例の費用が0で客も来ないこと。セーブ/ロード。試作店は一日中開いていること。
- `android_preview_smoke.gd`: 営業時間の選択肢がAM7:00〜PM11:00になっていること(最初の売上を待つ時間を1500ティックに延ばした)。
- 契約テスト: 7種類の表記、既定値、開始時刻、タグ。
- 結果: Python 764件成功(期待失敗1件は既存)。Godotスモーク・Android previewスモークとも成功。

## 明示的に対象外(既知の点)

- 新しいゲームの開始時(00:00)に、客が1人だけ店内にいる。シミュレーションが「最後に入った客」を常に1人持っている前提のため。
- 営業時間による客層の違い(攻略本p.23の時間帯別の客層)。
- 深夜0時の価格固定の小技。
