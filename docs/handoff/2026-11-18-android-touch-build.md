# Android 0.6.0 タッチ試作

基盤はAndroid 0.5.1（55e591682952c39f79d9d66c568fd94fb4c2eb74）。mainと未マージPR #270を確認し、以前配布した人物・音声反映版の続きとして独立ブランチで作成。解析ブランチや他の実装ブランチは変更しない。

## できること

- 中央960×720の4:3領域にゲーム画面、左右160pxの補助操作。十字キーなし。
- マップのタップ選択、ドラッグ移動、2本指の拡大縮小（8～48px/タイル）。全体が表示できる倍率では中央配置。
- 速度×1→×2→×4→×8。描画枚数に依存せず単調増加時計から時間を計算。
- UIの再生成は毎シミュレーション更新ではなく最大10Hzにまとめる。1描画フレームでは原則8ms/最大32更新で入力へ戻る。処理待ち時間は保持する。
- アプリが背景・一時停止・メニュー中の時間は進めない。復帰時に背景経過時間を一気に加算しない。
- 原版KYOU.TIMの9片を48×48へ配置したウィンドウ枠を使用。既存の原版由来の町・床・什器・人物・効果音・声を継続使用。

## 補助ボタンの割当

| ボタン | このスマホ版の動作 |
|---|---|
| □ | コマンド一覧を開閉 |
| △ | 町／店内切替 |
| ○ | 土地・建築の選択確定、またはフォーカス中の決定操作。各項目は直接タップも可能 |
| × | メニューを閉じる／取消・選択解除 |
| L1 / R1 | 内装中は左／右回転、町では縮小／拡大、店内では表示倍率 |
| L2 / R2 | 前／次の店舗。1店舗だけなら店舗一覧 |
| START | 開いたメニューを終了。通常画面では停止／再開 |
| SELECT | セーブ・ロード等のシステム |

スマホ向けの表示位置・割当は本作のUI方針（REMAKE_BALANCED_DEFAULT）であり、PSの全画面でのキー割当を完全復元したという主張ではない。元の原始関数・ルールを変えるための仮ルールは追加していない。

## ビルドと確認

Godot 4.6.3公式Linuxエディタと同版公式Android releaseテンプレートを使用。APKはデバッグ署名。テンプレートは`build/templates/android_release.apk`へ置き、Android SDKとJDKをGodotのエディタ設定へ指定する。

```sh
godot --headless --path game --editor --import --quit
godot --headless --path game --script res://scripts/touch_ui_smoke.gd -- --android-preview
godot --headless --path game --export-debug Android build/android/Conveni-Android-v0.6.0-touch.apk
```

APK出力パスは実行位置に応じて絶対パスを推奨する。テンプレート・SDK・APK・署名鍵はリポジトリに含めない。今回の署名鍵はローカル作業用で、今後同じ鍵を使える保証はない。旧APKの署名やセーブを壊さないよう別パッケージ`com.conveniremake.touch`とした。旧版セーブは自動移行されない。

通過した確認：

- 既存人物・サービスUI確認：控え室の3人、12歩行対、補間、レジSE10、声22/23、設定、売上27件。
- 既存原人事UI確認：解雇確認、10候補、採用、異動。
- タッチUI確認：4:3、出店決定、コマンド・取消、倍率上下限、1/2/4/8、描画deltaを0.001とした1秒経過の保持、停止中の時間非加算。
- Xorg/Mesaで描画し店・町・ウィンドウを確認。音声出力デバイスがないため実音の試聴はしていない。
- APK署名v2/v3とarm64、パッケージ・バージョンを確認。

描画確認用PNGはテストの`CONVENI_CAPTURE_DIR`（未指定ならuser://）へ再生成できる。配布APKにテストや検証画像を入れない。

## 制約

Android実機へのインストール・長期営業・後半多数店舗での実測は未実施。処理能力を超えた場合のゲーム速度を保証しない。単調時計と処理待ちの保持は、無限の処理能力や重い1更新の中断を実現するものではない。

PS版の全メニュー構成・文字・表示サイズの完全一致は未達。タイトル・各コマンドの項目表示等に既存試作UIが残る。解析済み全仕様を新たに全面統合したAPKとも主張しない。原EXE・BIOS・ディスクやPythonエミュレータを実行時に使わないAndroidネイティブGodotアプリである。
