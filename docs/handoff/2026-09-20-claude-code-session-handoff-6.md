## 4. 次セッションへの引き継ぎ・残っている候補

`PROJECT_MEMORY.md`第21.3/21.4節を参照。タスク#58で「町の空間モデル」の
第一歩(店舗間の点対点距離計算)を`reference_sim`側に追加したが、以下は
すべて未着手のまま残っている:

- **`game/`(Godot版)への空間モデルの配線**: ライバル店舗エンティティ
  (位置・保有許可の追跡)がGodot側にまだ存在しない。これを追加すれば
  `try_purchase_permit()`へ実際の排他距離チェックを配線できる。
- **治安施設(交番/消防署)のセキュリティボーナス**: 公式自体は確定済み
  (タスク#54)。タスク#58の距離モジュールは「点対点距離」であり、この
  ボーナスが必要とする「施設の足跡矩形と店舗の半径円との面積重なり」
  とは別の計算が必要で、未対応。
- **土地購入費公式**: エリア単位の地価という概念自体(エリアごとに
  異なる地価を持つマップ)がまだ存在しない。タスク#58は既知の店舗位置
  間の距離計算のみで、この概念は作っていない。
- **ライバル店舗の実際のスポーン・行動**: `remake_rival_policy.py`の
  判断ロジックにタスク#58で実際の幾何計算を初めて統合したが、
  「どの位置に何軒のライバル店が存在するか」「各ライバル店がどの
  販売許可を保有するか」は依然としてどの情報源にも記載がなく、誰も
  決めていない。
- **未解決のまま残る矛盾点**(前セッションから持ち越し、再検証を
  試みたが解決できなかった): 天候テーブルの列名、営業時間③の終了
  時刻、駅の買物人口、成長/怒りペナルティマトリクスの列対応。
