  あるが、それを載せる既存の仕組み(土地取得メカニクス、ライバル店
  エンティティ、雇用UI)がまだ存在しない」という共通の壁。着手するなら
  まずどの前提システムから手を付けるかをユーザーと確認すべき。

  ないため実装できない。空間モデルの構築自体を独立したタスクとして

  天候テーブルの列名(快晴/曇り/雨/台風/荒天 vs 快晴/大雨/雪/台風/荒天)、
  営業時間③の終了時刻、駅の買物人口(2,000 vs 2,240)、成長/怒りペナルティ
