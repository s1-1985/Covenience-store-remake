# Android v0.4.0：解析済みの従業員管理・床・購買ルールの追加移植

基点は v0.3.0 の復元コミット `a70c0633f454e4d60acecc91953ac920bf3cd6c7`。解析側 `2c00ba53ed5d469b406d498f3d1f9191074679a0` の r2 アーカイブと後続証拠を復元して仕様を照合した。解析アーカイブ・原EXE・RAM・検証器は本体ブランチやAPKへコピーしていない。

## 今回遊べるようになった内容

- 原候補抽選：全35人から未所属者を走査し、抽選済み枠を消さずに除外して、最大10人を提示。重複抽選による乱数消費も維持する。実際の他店・ライバル所属を除外する。
- 採用は空き枠に行う。解雇確認と店舗内／店舗間の配置交換を追加。管理画面の先頭枠欠員は変更確定後に警告し、全自店の先頭枠が埋まるまで営業に戻さない。交換前の取消は変更しない。枠1を店長の賃金130％計算に使用する。
- 床の汚れは原 `80031498` の時間ゲート・床0〜15の清潔率・前回値との比較・客の床への最大1か所の汚れへ変更。壁・屋外を分母に含めない。清掃は2×2細分マスに対応する元床値を5の倍数へ戻す。店長の汚れ報告に70％の基準を使用する。
- 補充の通常99％閾値、疲労時の作業中断とレジ待ちへの復帰を追加。
- 原プロフィールの追加購入を入店時に一括抽選せず、直前の商品を試した後に判定する。試作の独自衝動買いを原作経路で止める。滞在期限・1更新ごとの購買確率を使用する。
- 什器カテゴリ2/3/5の購入を即時会計とし、レジの会計へ重複計上しない。所持金不足とマナー／警備の条件を満たした持出しは在庫を減らし、売上にしない。
- 原町経路ではメニュー中に時計を停止。倒産・99年判定を0時へ限定。シナリオ別のクリア表示を修正。
- 追加購入候補・期限・床の比較値・欠員を含む名簿をJSONへ保存。旧JSONには新フィールドの既定値を使用する。
- UI用日本語フォントを更新。APKから全smoke・内部probeを除外。

## 全反映にはまだ残るもの

この版も「解析済みのすべてを実装済み」と呼ばない。客・店員の原メモリー状態機械を完全に移植したものではなく、ネイティブ版の位相・列・人物配置へ結合した箇所が残る。経路探索の到達先の順序は原モデルへ寄せたが、原圧縮経路の逆追跡・人物の全フレーム・全乱数列の一致までは未完。
