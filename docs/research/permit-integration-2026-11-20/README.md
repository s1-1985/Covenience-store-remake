## 未反映だった差分

原800B92D0のi32料金はたばこ300万円・酒700万円・薬品類1000万円。
ネイティブ原作モードの初期化時に置換する。旧試作専用の設定はそのまま保つ。
旧セーブの取引を再計算したり差額を精算したりしない。

原8001F8BCの再構築器自体は既に本体に存在していたが、許可申請側は
旧距離モデルを呼んでいた。今回、活動中の自社・競合全店舗で制限を再構築し、
候補敷地2×2の全セルを調べる原8001E660の照会規則へ接続した。
地図ビットはたばこ4・酒2・薬1。範囲は店舗矩形から各5・7・10セル、
端を含む。既存許可は保持し、取得済み表示を新規申請不可より優先する。
地図外の不正な矩形拒否は本体側の入力検査で、原41290の一般範囲検査とは呼ばない。

原作での表示料金・名称・既存許可維持・不足時復元に基づき、
スマホ画面で複数選択→合計確認→申請とした。行高と確認窓はユーザーが許可した
可読性改善であり、PS画面の入力ループそのものの完全移植ではない。
選択中に代金やフラグを変えず、最後に全選択・資金・店舗UIDを再検証する。
不足や制限が1件でもあれば全件無変更。同じ許可の重複指定は一回分だけ。
返金・既存許可取消しは追加しない。改装全工程の一括ロールバックは今回の対象外。

取得後は地図の制限と本体の来店割当を更新する。後者は現行本体の接続方式で、
原作の全更新順序との完全一致は未検証。売却時は既存の制限再構築経路で解除される。
