## 本体の差分

旧本体は警備の代わりに接客を下げ、断念件数が127を超えた。会計は呼出し側の後処理に依存して買物額を消し、同じ客の再会計を訪問IDだけで拒否していた。退店で道を塞がれた客にも買物/レジ用の断念関数が呼ばれ、万引き前から残っていた商品が売上へ移る経路もあった。原退店 `80035770` はこの断念関数を呼ばない。

本体は共通の未精算単位で会計→即時消去を行う。原作同様に待機断念の買物額も売上へ加える。客IDと支払単位のキーを分け、既払い分の再計上を防ぎながら、同一人物が別に取得した商品は別会計として扱える。訪問中の支払合計と最後の取引IDを保持し、通常の試作シナリオの訪問ID重複防止は既定のまま残す。販売履歴の人物IDも維持する。

強制離脱を引数で明示し、退店中の移動から断念関数を呼ばない。買物/レジ待ちの断念とは区別する。既存の即時決済と調査用の取得時集計は変更しない。
