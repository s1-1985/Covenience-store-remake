# 初代PS/SS版ソース境界メモ 2026-09-05

初代PS/SS版調査では以下を採用ルールとする。

- 1997年PS/SS両対応攻略本: 第一優先。
- PS説明書/原作画面/PS実機/SS実機: 第一優先。
- 1996年Windows版攻略本: 共通仕様候補に限り補助資料。家庭用版数値へ直結させない。
- 1997年12月『完全研究 全機種対応』: 版差確認用。表の機種ラベルが取れた項目のみPS/SSへ昇格。
- 『ザ・コンビニ2』『3』『4』『200X/DS』: 比較・検索語生成のみ。数値流用禁止。

100%再現判定は、推測値で穴を埋めた時ではなく、家庭用版資料で主要マスターデータとUI/計算境界の証拠が揃った時にのみ行う。
