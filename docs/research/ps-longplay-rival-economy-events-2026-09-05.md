## 1. 中型改築価格のPS実プレイ裏取り

中級プレイ記録で、本店を小型から中型へ改築する際に **1,200万円** が必要と明記される。

```text
small_to_medium_remodel_cost = 12_000_000 yen
platform = PS
confidence = CONFIRMED-COMMUNITY / strong play record
```

既存の初代専用資料値と一致するため、Phase 1の暫定実装値としてかなり強い。

なお「最初から中型店舗建設は無理」とする文脈は資金不足の話であり、中型新築価格そのものは示していない。中型新築価格と解禁条件は引き続き未確定。

## 2. 販売許可は個別申請できる

中級プレイでは新店舗候補について `タバコ・酒・薬` の申請可否を確認し、資金節約のため **タバコだけ申請して小型店を開業**、酒・薬は中型改築時に回す運用が記録される。

ここから強く言えること:

- tobacco / alcohol / medicine は独立した許可対象として扱える。
- 全許可を同時取得する必要はない。
- 少なくとも新規出店時に一部許可だけ取得して営業開始できる。
- 後から追加申請できる。

未確定:
- 各申請費
- 申請成功率/距離閾値
- 改築時に許可判定を再度行うのか、任意メニューから随時申請できるのか

## 3. ライバル店調査 50万円をPSでも確認

中級記録では `調査` により **50万円でライバル店の売上などを調べられる** と明記。

既存SS長期記録の `rival_store_survey_cost = 500000` と一致するため、PS/SS共通値としての確度が上がる。

```text
rival_store_survey_cost = 500_000 yen
observed = PS + SS independent long-play records
confidence = B+
```

調査で閲覧できる完全項目一覧はまだ未確定。

## 4. ライバルAI: 撤退後の再出店

中級長期プレイで極めて明確に繰り返し観測される。

- プレイヤーが値下げしてライバル支店を赤字/撤退へ追い込む。
- 支店が消える。
- ライバルは **別の場所に新しい支店をすぐ出店する**。
- 同じ一つの支店枠が「あっちこっちに移動」し、`つぶれてはオープン` を繰り返す状態も観測。

したがってライバルAIは、単純に店舗を失って終わるのではなく、資金/店舗上限/土地条件を満たす限り **再出店行動を持つ** とモデル化すべき。

```ts
interface RivalAI {
  canReopenAfterClosure: true;
  prefersReplacementLocation: true; // exact strategy unknown
}
```

再出店までの待機時間・資金条件・立地評価式は未確定。

## 5. 店舗上限がライバルAIを直接制約

中級記録ではプレイヤー5店 + ライバル5店になった時点で「これ以上新店舗は造れない」と記録される。

Wikiの合計10店舗上限と独立一致。

また、ライバル撤退直後から再出店までの短い隙にプレイヤーが新店を建てて枠を奪うことが重要な攻略になっている。

これは単なるUI上限ではなく、**競争AIとプレイヤーが共有する希少リソースとしての店舗枠** と解釈できる。

## 6. ライバルへの価格攻勢は有効だが局所的

中級記録:

- 標的支店近くの自店を約15%値下げし、しばらくすると標的支店が撤退した事例。
- 別地点では自店を値下げしてもライバルへ十分な影響が出ず、自店だけ赤字化した事例。

上級記録:

- 5%値下げでは強いライバル支店を崩せない事例。
- 2店舗で挟み撃ちするように出店し、約3か月後に標的支店が閉店した事例。

結論:
- 価格は競争要因である。
- 効果は距離・周辺人口・複数店舗の商圏重複・品揃え等と組み合わさる。
- `-15%なら撤退` のような固定閾値にはしない。

## 7. ライバル本店/支店の非対称性

上級プレイ記録では、ライバル本店は支店よりしぶとく、攻略者は「支店がつぶれない限り本店は絶対につぶれない」と認識している。

Wikiでも本店は買収不可とされるため、少なくとも以下の非対称性を保持する価値が高い。

```ts
rivalHeadStore.acquirable = false
rivalBranch.acquirable = true
```

`本店撤退には支店ゼロが必須` かどうかは攻略者の推論を含むため `PROVISIONAL` とする。

## 8. ライバル買収価格は大幅に動く

序盤は別資料/Wikiで約4,500万円のライバル支店買収例がある一方、中級長期プレイ後半では:

- 買収価格が約2億円まで上昇
- 特定の支店で **2億1,200万円** の提示

が記録される。

したがって買収価格は固定ではなく、少なくとも時期/土地/店舗規模/業績等の何らかの値で大幅に変動する。

```ts
interface AcquisitionPriceModel {
  fixedPrice: false;
  factors: UNKNOWN;
}
```

具体式は未確定。

## 9. 土地・出店コストの長期インフレを再確認

中級後半では:

- 安い土地 + 小型店 + タバコのみ申請でも総額ざっと8,000万円という状況
- さらに後年、小型店オープンでも1億円以上が必要と記録

小型建物そのものの基準建設費600万円とは明らかに別で、土地価格が長期進行で支配的になることを示す。

実装では:

```text
store_building_cost != total_opening_cost

total_opening_cost = land_price + building + permits + interior + other
```

を分離する必要がある。

## 10. `コンビニコンテスト` イベント

初級・中級・上級の長期プレイに **「コンビニコンテスト」** が登場する。

確認できる挙動:

- プレイヤー側が選ばれると大きな賞金が入る。
- ライバル店が選ばれる場合もある。
- セーブ後ロードで結果が変わる/回避できたという記録があり、抽選イベントの可能性が高い。
- 中級では放置中に資金が「約1億の想定から2億超」へ増えており、賞金が非常に大きいことが示唆されるが、正確な賞金額は未確認。

実装候補:

```ts
interface ConvenienceContestEvent {
  id: "convenience_contest";
  eligibleStores: "player_and_rival";
  rewardYen: number | null;
  trigger: unknown;
  selectionMethod: unknown;
}
```

イベント存在は強いが、発生条件/周期/賞金/選考式は攻略本または実動画で回収する。

## 11. 中級クリア判定は10店舗目の開業直後

中級長期プレイでは、10店舗目の小型支店をオープンした **その直後** に達成メッセージが出てスタッフロールへ移行。

強い実装アンカー:

```text
IntermediateVictoryTrigger = player_store_count reaches 10
checkTiming = immediately after store opening completion
storeSizeRequirement = none observed (10th store was small)
```

つまり月末/年末評価待ちではない。

## 12. クリア後/隠しマップ

総合プレイ記録は初級・中級・上級をクリアした後に `極上マップ` が遊べると記述。

既存資料と整合するため、隠しマップ名称/解禁の確度を補強する。ただし正確な解禁UIと開始条件は実画面で最終確認する。

## 13. 火災・強盗の長期プレイ実例

初級プレイでは放置中に:

- 火災で店舗が空になる
- 消防署誘致前に再度火災
- 強盗被害

を連続して経験。

イベントが単なる攻略Wiki上の注意書きではなく、通常プレイで実際に経営を破壊するレベルのリスクとして発生することを補強する。

## 14. 町施設はライバル/自店の商圏を動的に変える

中級/上級では、プレイ途中に:

- 駅
- 大学
- 遊園地
- 中学校
- 高校

が新しく出現し、既存店舗の客入りが大きく変化する実例がある。

したがって TownSimulation は単なる勝利条件用人口カウンタではなく、**施設出現 -> 周辺需要変化 -> 店舗競争再計算** のフィードバックを持つ必要がある。
