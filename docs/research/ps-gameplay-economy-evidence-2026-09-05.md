# PS版 実機系レビューによる営業時間・許可・価格設定・地価挙動の追加証拠 2026-09-05

対象: 1997年PlayStation版『ザ・コンビニ ～あの町を独占せよ～』。

方針: 攻略本準拠を最優先としつつ、攻略本本文未回収部分は初代PS版を明示した後年の実機プレイ記録で補強する。キャラクター名の漢字揺れ等、ゲーム性に影響しない差異は低優先とする。

証拠レベル: CONFIRMED-COMMUNITY / PS-SPECIFIC / DIRECT-PLAY-STYLE-REVIEW

攻略本本文や説明書そのものではないため、数式・完全表の唯一ソースにはしない。一方、UI選択肢やゲーム進行上の明示仕様は補助証拠として採用可能。

## 2. 営業時間は6プリセット

レビューでは営業時間の選択肢として以下6種類が明記される。

- 24時間
- 07:00-23:00
- 10:00-18:00
- 10:00-翌02:00
- 12:00-翌04:00
- 19:00-翌11:00

判定: CONFIRMED-COMMUNITY / PS-SPECIFIC

実装候補:
```text
business_hours_presets = [
  24h,
  07:00-23:00,
  10:00-18:00,
  10:00-02:00_next_day,
  12:00-04:00_next_day,
  19:00-11:00_next_day,
]
```

既存研究の営業時間候補と一致する場合、PS baselineの証拠を一段強化できる。

## 3. 販売許可はタバコ・酒・医薬品の3種類、各有料

新規出店時の流れとして、販売許可が必要な商品を申請するか決めるとされ、対象は:

- たばこ
- 酒
- 医薬品

の3種類。レビューは「それぞれ有料」と明記する。

判定:
- permit types = tobacco / alcohol / medicine: CONFIRMED-COMMUNITY / PS-SPECIFIC
- each permit requires a fee: CONFIRMED-COMMUNITY / PS-SPECIFIC
- exact fee amount: UNKNOWN

既存のSS版無料取得バグとは分離し、PS baselineでは通常ルートが有料であることを保持する。

## 4. 1店舗の初期雇用は店長1名＋従業員2名 = 計3名

新規店舗設定時、「店長と従業員2名の計3名を雇う」と記録されている。

判定: CONFIRMED-COMMUNITY / PS-SPECIFIC

既存の1店舗最大3名という初代専用Wiki情報をPS側から補強する。

## 5. 商品価格は品目ごとの利益率調整と全品一括設定の両方がある

レビューでは:
- 商品は品目ごとに利益率を調整可能
- 全品目一括設定も可能

と明記される。

判定: CONFIRMED-COMMUNITY / PS-SPECIFIC

実装上は「販売価格そのものを直接円入力」ではなく、少なくともUI上は利益率操作の概念を持つ設計が必要。

```text
ProductPricingUI
- set_margin_for_item(product_id, margin)
- set_margin_for_all(margin)
```

未確定:
- 利益率の選択刻み
- 最小/最大利益率
- 原価→売価への丸め式
- 一括設定後の個別上書き順序

## 6. 小型店では全商品を置けない

初期の小型店舗では、すべての商品を置くことが難しく、商品を取捨選択する必要があると記録される。

判定: CONFIRMED-COMMUNITY / GAMEPLAY-OBSERVATION

これは商品カテゴリ数と什器容量の双方が小型店容量を超えることを示すが、全商品数や必要棚数の完全値は未確定。

## 7. 専門店型の極端な品揃えも許容される

弁当のみ、パンのみなどの専門店的な構成も可能とされる。

判定: CONFIRMED-COMMUNITY

実装上、必須商品カテゴリをハードコードして開店不可にする設計は避ける。レジ/休憩室等の設備必須条件と商品カテゴリ必須条件は分ける。

## 8. 地価は都市化と年数経過の両方で上昇

レビューでは:
- 繁華街になるほど周辺地価が上がる
- 年数が経つほど全体の地価も上がる

とされる。

判定: CONFIRMED-COMMUNITY / PS-SPECIFIC

実装候補の概念モデル:
```text
land_price = base_price
           * local_development_factor
           * time_inflation_factor
```

ただし、これは構造候補であり式・係数は未確定。

未確定:
- 都市化の入力変数
- 買い物人口/建物密度/道路等との関係
- 年次上昇率
- タイル単位か地域単位か
- 上限/下限

## 9. 初級シナリオの人口目標を再確認

レビューは「都庁を誘致せよ」を街人口20,000人にするシナリオとして説明する。

判定: CONFIRMED-COMMUNITY / PS-SPECIFIC

既存の初級20,000人超→都庁出現/クリア情報を補強する。

## 10. 駐車容量不足とレジAIの偏りの観測

後半のゲームプレイ観測として:
- 駐車場を増やしても駐車できない客が出る
- 店員能力が上がると、多数の客がいてもレジを1人で回そうとして買えない客が出ることがある

と記録される。

判定: PROVISIONAL-DIRECT-PLAY / PS-SPECIFIC

重要な示唆:
- 駐車場容量を単純総台数だけで判定していない可能性
- 店員AIは混雑に応じて最適人数を必ずレジへ割り当てる設計ではない
- 店員役割切替に閾値/優先順位/能力依存ロジックがある可能性

数式・閾値が不明なため、現時点では挙動候補として保持する。

## 11. セーブ/ロード仕様

PS版では:
- セーブデータ: 14ブロック
- セーブ目安: 約90秒
- ロード目安: 約70秒

とレビューされる。

再現ゲーム本体の現代実装には不要だが、原作UI/仕様資料として記録する。証拠レベル: CONFIRMED-COMMUNITY / PS-SPECIFIC。

## 12. 今回の更新で実装へ昇格できるもの

高確度:
- 営業時間6プリセット

- 初級人口20,000人目標

- 店員AIのレジ割当閾値
