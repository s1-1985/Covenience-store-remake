## 実装

店舗+12E8の60履歴、会社800E3C28、店舗数800E43D0、平均800D6018に対応する
ネイティブ履歴を月次確定時に記録する。会社損益と同期間の店舗数から平均を計算し、
欠損値または店舗数0で停止。0円は有効。平均は0方向へ整数除算し、軸は絶対値の
最大を百万円単位で切り上げ、最小百万円。原の古い月からの順序、万円への切捨て、
高さ56の規則を使用し、枠外への描画は抑制する。
原80010A30のRGBを確認し、背景ffffac、黒字2020f6、赤字ff2020を使用した。
旧セーブに存在しない月次履歴や店舗別経費配分は生成しない。

売却は原80061CDC..8006215Cの本店禁止、営業中禁止、土地と資産の分離返金、
店員の所属解除、更地12への変更を接続した。建物は小中大を300/600/900万円、
什器は購入額、商品は仕入額、土地は現行の敷地価格を使用する。
競合への資金移動はない。確認時にも営業時間と店舗UIDを再検証する。
売却返金は資本取引であり営業利益へ加えない。売却済店舗の当月売上も会社決算まで
保持する。従業員の実装済み能力・賃金・体力を保存して再採用に接続した。

店舗配列を詰めても経費や保存の所属が変わらないよう安定UIDを追加した。
再出店時は新UIDと客ID接頭辞を発行し、前の利益履歴を引き継がない。
これはJSON保存用の識別子であり、原メモリカード構造と同一とは扱わない。
既存4経費分類の原8列への対応は従来の互換割当を継続。全経費生成元の完全移植を
主張しない。原C77の営業中判定は現行本体の営業状態へ対応させている。
