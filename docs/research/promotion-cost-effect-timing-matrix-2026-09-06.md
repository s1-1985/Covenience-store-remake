# 宣伝5種の費用・効果・発生日時（初代PS/SS版）

調査日: 2026-09-06
対象: 1997年 PS/SS版『ザ・コンビニ ～あの町を独占せよ～』

## 結論

初代専用攻略Wikiの「宣伝」ページから、`販促 → 宣伝` 配下の5方式について、費用・人気上昇量・月内発生日時が一式で確認できた。

| 宣伝方式 | 費用 | 人気上昇 | 発生日 | 発生時刻 | 証拠レベル |
|---|---:|---:|---:|---:|---|
| ダイレクトメール | 10万円 | +12 | 2日目 | 10:00 | B+ |
| 新聞広告 | 50万円 | +20 | 2日目 | 07:00 | B+ |
| 飛行船 | 100万円 | +30 | 3日目 | 15:00 | B+ |
| ラジオ | 300万円 | +50 | 1日目 | 17:00 | B+ |
| TV | 500万円 | +100 | 1日目 | 19:00 | B+ |

出典: 初代専用攻略Wiki「宣伝」
https://wikiwiki.jp/theconveni1/%E5%AE%A3%E4%BC%9D

## 共通挙動

同ページによれば、宣伝は出店中の全店舗の人気を上昇させる。店舗数が増えても宣伝費用は変わらず、各方式は月1回、方式ごとに固定された日時に発生する。人気上限は100である。

従って実装上は、宣伝を単一店舗対象の即時バフではなく、チェーン全店を対象とする予約イベントとして扱うのが安全である。

概念モデル:

```text
PromotionOrder {
  type
  cost
  popularity_delta
  scheduled_day
  scheduled_time
  max_once_per_month_per_type = true
  target = ALL_OWNED_STORES
}
```

ただし、注文時に即時課金されるか、実イベント発生時に課金されるか、資金不足時の挙動は今回の初代資料だけでは確定しない。

## アイドル1日オーナー

同じ初代専用ページでは、全店舗合計の来店者数が1万人に到達するごとに、無料の1日オーナーイベントが発生し、TVと同等の人気+100効果を持つとされる。また、来店者数到達通知の翌日0時にイベント開始と記載される。

- 発生閾値: 全店累計来店者 10,000人ごと
- 費用: 無料
- 人気効果: +100
- 開始: 到達通知の翌日 00:00
- 証拠レベル: B+

ここは通常宣伝と別イベントとして保持する。

## 続編混同防止

『ザ・コンビニ2』専用Wikiにも同名の宣伝方式があるが、数値が一致しない。特に、続編では飛行船+40、ラジオ+60、テレビ+90とされ、累計来客イベントも2万人ごとである。

続編資料:
https://wikiwiki.jp/convenie2/%E3%83%87%E3%83%BC%E3%82%BF/%E5%AE%A3%E4%BC%9D

したがって以下を明示的に禁止する。

- 『ザ・コンビニ2』の宣伝効果量を初代へ流用しない。
- 続編の「宣伝費用の5倍の資金がない場合キャンセル」仕様を初代仕様として採用しない。
- 続編のアイドル発生閾値2万人を初代へ流用しない。

同名メニューであっても初代と続編で数値が変わることが確認できるため、今後の調査でもシリーズ横断転記を禁止する根拠になる。

## 実装可能範囲

今回の表により、宣伝5種について以下は仮実装ではなく evidence-backed data としてデータ化可能である。

- 方式名
- 費用
- 人気上昇量
- 月内発生日
- 発生時刻
- 月1回/方式
- 全自店舗対象
- 人気上限100

一方で以下は未確定のまま残す。

- 課金タイミング
- 予約後キャンセル可否
- 資金不足時の処理
- 同一時刻に複数宣伝が重なった場合の処理順
- 月末スキップ時に予約イベントがどう処理されるか
- PS/SSで完全同一か

## 証拠評価

`B+ / FIRST-TITLE-DEDICATED-COMMUNITY-DATA`

初代専用のデータページで具体的な費用・効果・日時が整理されており、内部整合性も高い。一方、説明書・原作画面・実機動画による一次確認をまだ取れていないためAには上げない。

なお後続作資料との数値差が確認できることは、当ページが単純な続編転記ではないことを補強するが、それ自体は一次証拠ではない。
