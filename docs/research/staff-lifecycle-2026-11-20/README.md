## 再現

`probe_staff_lifecycle.py EXE OUTDIR` をUnicorn 2.1.4で実行。EXEハッシュ確認後、原関数と本物の休憩・什器検索・補助処理を使用する。置換calleeなし。合成人物レコードと休憩室で4取引（同一、交換、別人へ交代、解雇）を実行し、期待値を `game/tests/fixtures/source_staff_lifecycle.json` に保存した。自然進行、原UI、長期営業を実行した結果ではない。

本体の `staff_lifecycle_smoke.gd` は4取引を同じ条件で照合する。さらに再採用前後のJSON、賃金・習得能力・目標値、変更なしの作業状態、重複人物の拒否、同店交換と別店異動の差を検査。`staff_lifecycle_ui_smoke.gd` は指での解雇取消/確定、再採用、同店の配置変更を検査する。
