## 実装と画面

本体の見積りでゲーム終了、店舗の存在、営業中、資金不足を検査する。
確認には店舗UIDと元店舗種別を保持し、実行直前に再検査する。
アイコン選択だけでは配置・所持金を変えず、確認画面は戻るを初期選択とする。
営業中は既存の臨時休業確認からサイズ選択へ進み、完了/退出時は元営業時間へ戻す。
営業時間復元もUIDへ結び、途中で選択店舗が変わっても別店舗へ上書きしない。
この確認窓と行の配置はユーザー承諾済みのスマホ操作調整であり、原画面ループそのものではない。

旧来の什器自動再配置/倉庫送りは維持している。原改装親が内装中の現金増減を
復元して再記帳しない経路に合わせ、この自動再配置で収まらなかった商品の
旧試作の返金を原作モードでは発生させない。確定する支出はサイズ代1件。
旧試作専用シナリオの半額控除・返金は互換用に保持する。

店員の能力・体力は維持し、旧サイズの経路・仕事先を消して新控え室へ再配置する。
これは既存の原休憩再配置ヘルパーを本体の再構築後へ接続したもので、改装時の
全原人物更新順序を新しく確定したという意味ではない。
終了済み客の通し番号はリセットせず、過去の会計IDの再使用を防ぐ。
