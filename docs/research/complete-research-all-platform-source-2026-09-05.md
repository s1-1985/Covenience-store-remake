## 5. 本書の研究上の役割

既存の1997年PS/SS専用攻略本は「家庭用版の値を取る」には適している。

本書は `全機種対応` なので、特に:

1. PC版→PS/SS版で変更された仕様
2. PSとSSで異なる仕様/バグ
3. 全版共通の店員/商品/経済概念
4. 操作/UIだけ機種ごとに違う部分
5. 数値が共通か機種別か

を解決できる可能性が高い。

### 特に照合したい既存の矛盾

- 営業時間プリセット
- 販売許可申請フロー
- 日付境界の価格スナップショット挙動
- 店員名の表記揺れ
- 小型/中型/大型店舗寸法
- 一時停止/時間操作
- 什器/商品数値
- 初代PCとPS/SSのUI差

## 6. ただし「全機種対応」は採用時のリスクでもある

本書内のデータ表を発見しても:

```text
value = 100
```

とだけ書かれている場合、それが:
- 全機種共通値
- Windows値
- PS/SS値
- 特定版のみ

のどれかを確認する必要がある。

### baseline採用ルール

本書から数値をPS baselineへ昇格するには:

1. 表/章の機種ラベルを確認
2. `全機種共通` 等の明示を確認
3. PS実画面/PS専用攻略資料と可能ならクロスチェック
4. SS限定値ならPSへ流用しない
5. PC限定値ならPSへ流用しない

機種ラベルが読めないデータは `PROVISIONAL / PLATFORM-UNRESOLVED` とする。

```text
source_registry:
  complete_research_all_platform_1997:
    priority: A
    platform_scope: PC_MAC_PS_SS
    ps_numeric_adoption: REQUIRES_PLATFORM_CONTEXT
    interior_recovered: false
```
