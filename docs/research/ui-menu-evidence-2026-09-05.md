# UI / メニュー構造の証拠メモ 2026-09-05

対象: 1997年PS/SS版『ザ・コンビニ ～あの町を独占せよ～』

## 1. 直接確認できたトップレベル概念

現時点でPS/SS版のプレイ記録・攻略資料から直接確認できる主要操作群:

- 内装
- 店員雇用 / 店員異動
- 営業方針
- 販促
  - 宣伝
  - 誘致
- 調査
- 店舗新設 / 改築
- ライバル店調査
- 店舗買収
- 客を「つまみだす」個体操作

完全なトップレベルメニュー順序と全サブメニューは説明書スキャンから確定させる。

Sources:
- https://mimora.mimoza.jp/yao_game/retro/contents/ctg_main/memorandum/SS/detail/gmr_SS-0001.php
- https://wikiwiki.jp/theconveni1/
- https://www.gavas.jp/products/detail.php?product_id=9180

## 2. 内装

プレイ記録から確認:

- レイアウトは自由配置。
- レジは向きがあり、逆向きに置くと客列が意図と逆方向に伸びる。
- サンプルレイアウトが用意されている。
- サンプルを読み込むと元の状態へ簡単に戻せないという記録あり。
- レイアウト保存/読込が存在することを当時記事でも確認できる。

Sources:
- https://mimora.mimoza.jp/yao_game/retro/contents/ctg_main/memorandum/SS/detail/gmr_SS-0001.php
- https://pc.watch.impress.co.jp/docs/article/970321/weekend.htm

## 3. 販促

「販促」が上位コマンドで、その中に少なくとも次がある。

- 宣伝
- 誘致

宣伝は全店舗の人気へ影響。
誘致は町マップへ施設を配置して、周辺需要や店舗パラメータへ影響させる。

Sources:
- https://wikiwiki.jp/theconveni1/%E5%AE%A3%E4%BC%9D
- https://mimora.mimoza.jp/yao_game/retro/contents/ctg_main/memorandum/SS/detail/gmr_SS-0001.php

## 4. 調査

プレイ記録から「調査」で少なくとも次を確認できる。

- 各店舗の売上成績
- 売れ筋/アンケート
- 収支グラフ
- 顧客独占率
- 全店収支グラフ / オーナー総合評価
- ライバル情報

アンケートは「欲しかった商品」や品切れ/置き忘れ対策に使える情報を返す。

ライバル店調査は50万円というプレイ記録があり、営業時間・収益等の基本情報を確認できる一方、店内の詳細までは見られないとされる。金額は説明書/ゲーム画面で再検証する。

## 5. 店舗シミュレーション画面

原作スクリーンショットの特徴:

- トップダウン2D。
- 画面上部に年月日、天候、時刻、所持金。
- 店内をライブ表示したまま各種ウィンドウを重ねる。
- 商品選択はカテゴリをアイコンで並べたモーダル。
- 客・店員・什器が同時に見える。

Source:
- https://dengekionline.com/elem/000/000/722/722919/

## 6. 町マップ

建物へカーソルを合わせると建物名と買い物人口が表示される。実画像で「役所 / 買い物人口250人」を確認。

立地判断時にプレイヤーへ需要を直接見せるUIである。

Source:
- https://dengekionline.com/elem/000/000/722/722931/

## 7. Android版へ持ち込むべきUI原則

原作互換プロトタイプでは次を維持する。

1. 町/店を常に「観察する」画面が主役。
2. 操作は観察画面に重なるウィンドウ中心。
3. 数値表だけでなく、客/店員の挙動から問題原因を視覚的に読み取れる。
4. タッチ向けにボタン面積は拡大するが、情報構造は勝手に別ゲーム化しない。
5. 完全なメニュー順序は説明書から確定するまで仮決めしない。
