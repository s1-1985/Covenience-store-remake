# 公式スクリーンショット直接証拠 2026-09-05

対象: 1997年PS/SS版『ザ・コンビニ ～あの町を独占せよ～』。baselineはPS版を優先する。

## 証拠の扱い

2026年7月23日配信のハムスター公式「コンソールアーカイブス ザ・コンビニ ～あの町を独占せよ～」は、日本版ROMを忠実再現した現行公式復刻である。

公式タイトルページ:
- https://www.consolearchives.com/title/csa-0023/
- https://store.playstation.com/ja-jp/concept/10017477

このページに掲載されている原作ゲーム画面は、初代PS版仕様を確認する上で最優先の CONFIRMED-OFFICIAL / CONFIRMED-VISUAL 証拠として扱う。

---

## 1. 初級開始時の初期資産 2億円を公式画像で直接確認

公式スクリーンショット `ss01` では、ゲーム開始直後の本店位置決定画面に以下が表示される。

- `01年目01月01日`
- `[快晴]`
- `00:00`
- `¥200,000,000`
- `本店の位置を決定してください`
- `L1・・・サイズ変更`

画像:
- https://www.consolearchives.com/wp/wp-content/uploads/2026/07/csa-yr4uvxgg-ss01.png

証拠レベル: CONFIRMED-OFFICIAL / CONFIRMED-VISUAL

### 重要な確定事項

- 初級の開始資産2億円は攻略Wiki記録だけでなく公式原作画像でも一致したため、baseline値として採用可能。
- 出店位置決定中に `L1` で店舗サイズを切り替える操作が存在する。
- 町マップを見ながら位置とサイズを同時に検討するUIである。

### 実装上の意味

新規出店フローを全画面ウィザード化し過ぎない。原作では町を見ながら出店候補を動かし、その場でサイズ変更する。

---

## 2. 内装編集の正確なトップコマンドを公式画像で確認

公式スクリーンショット `ss02` の内装画面右側メニューから以下を直接読める。

1. `配置`
2. `移動`
3. `入れ替え`
4. `売却`
5. `終了`

画像:
- https://www.consolearchives.com/wp/wp-content/uploads/2026/07/csa-yr4uvxgg-ss02.png

証拠レベル: CONFIRMED-OFFICIAL / CONFIRMED-VISUAL

### 実装上の意味

baselineの内装編集モードは最低限この5操作を独立コマンドとして表現する。

`配置` と `入れ替え` が別コマンドであるため、内装編集を単一のドラッグ&ドロップだけへ単純化すると原作の情報構造から外れる。

Android向けの操作最適化は可能だが、仕様モデル上は以下を別アクションとして保持する。

```text
InteriorAction
- PLACE
- MOVE
- SWAP
- SELL
- EXIT
```

## 4. 宣伝画面の正確なUIを公式画像で確認

公式スクリーンショット `ss04` で以下を直接確認。

- `宣伝方法を選択して下さい(複数選択可)`
- `ダイレクトメール ¥100,000/月`
- `費用合計 ¥9,600,000/月`
- 宣伝方法が5アイコン表示
- `終了・・・START`

画像:
- https://www.consolearchives.com/wp/wp-content/uploads/2026/07/csa-yr4uvxgg-ss04.png

証拠レベル: CONFIRMED-OFFICIAL / CONFIRMED-VISUAL

### 既知の5宣伝との照合

初代専用Wikiの5種類:

| 宣伝 | 費用 |
|---|---:|
| ダイレクトメール | 100,000円 |
| 新聞広告 | 500,000円 |
| 飛行船 | 1,000,000円 |
| ラジオ | 3,000,000円 |
| TV | 5,000,000円 |

合計は `9,600,000円` で公式画面の費用合計と完全一致する。

Source:
- https://wikiwiki.jp/theconveni1/%E5%AE%A3%E4%BC%9D

### 新たに強く示されたこと

- 宣伝は複数同時選択できる。
- 画面表記では費用が `/月` 単位。
- 5種全選択時の月額合計9,600,000円がUI上で計算表示される。

### 未確定

`/月` 表記が「一度設定すると毎月自動継続」なのか、「その月に発生する宣伝費の合計」なのかは、画面だけでは確定しない。

この点は実機/動画で設定翌月の挙動を追跡する。

## 7. PS版の営業時間6プリセット — 証拠強化

初代PS版を明示したレビューが営業時間を「全6種類」として具体的に列挙している。

1. 24時間
2. 07:00–23:00
3. 10:00–18:00
4. 10:00–翌02:00
5. 12:00–翌04:00
6. 19:00–翌11:00

Source:
- https://codevis.nobody.jp/review-ps/the_convini.html

同レビューはハードをPlayStation、発売日1997-03-28として明記している。

証拠レベル: STRONG-PROVISIONAL / CONFIRMED-COMMUNITY-SINGLE-SOURCE

### 注意

初代Wiki FAQに `0時4時営業` の記述があり、上記6種と衝突する。

このため営業時間完全表はまだ最終確定しない。PS実機メニューまたは説明書本文で再確認する。

## 8. 新規出店フローを初代PSレビューで再確認

同レビューはPS版の開始フローを次の順で説明する。

1. 出店場所を決める
2. タバコ・酒・医薬品の販売許可申請を選ぶ
3. 店舗サイズを選ぶ
4. 店長1名 + 従業員2名を雇う
5. レジ・休憩室・棚を配置
6. 商品を配置
7. 営業時間・価格等を設定し開店

Source:
- https://codevis.nobody.jp/review-ps/the_convini.html

今回、公式 `ss01` の `L1・・・サイズ変更` により「位置決定中にサイズ変更可能」という操作関係まで補強された。

PS版レビューでは以下が記録される。

- セーブにメモリーカード14ブロック
- セーブ約90秒
- ロード約70秒
- 3店舗程度から町マップでも処理落ちが目立つ

Source:
- https://codevis.nobody.jp/review-ps/the_convini.html

証拠レベル: CONFIRMED-COMMUNITY-SINGLE-SOURCE

### 実装判断

これは1997年ハード由来の制約であり、baselineのゲームルールではない。

Android版で再現しない。

ただし「客が大量に同時存在すること」「店舗数増加でシミュレーション負荷が増えること」の性能テスト目標を設定する参考資料にはする。

## 12. 10店舗上限の意味を再整理

初代専用Wikiでは、自社+ライバルを合わせ町全体でコンビニは最大10店舗。

中級で自社10店舗を達成するにはライバル店を撤退させる必要がある。

Source:
- https://wikiwiki.jp/theconveni1/%E3%82%B2%E3%83%BC%E3%83%A0%E3%83%A2%E3%83%BC%E3%83%89%E6%94%BB%E7%95%A5

baseline world stateに単純な `player_store_limit=10` とするのではなく、

```text
max_total_convenience_stores_in_town = 10
```

という町全体制約として実装候補化する。

## 15. 今回の調査で baseline へ昇格できる項目

実装データとしてかなり強く採用可能:

- 初級初期資産 = 200,000,000円
- 出店位置決定中に店舗サイズ切替がある
- 内装編集トップ操作 = 配置 / 移動 / 入れ替え / 売却 / 終了
- 宣伝 = 5方式を複数選択可
- 5宣伝全選択費 = 9,600,000円/月表示
- 店舗はトップダウン2Dグリッド
- 店外設備も店舗レイアウト空間に含む
- 初期人気 = 20
- 人気上限 = 100
- 町全体のコンビニ総数上限 = 10

まだ保留:

- 営業時間6プリセット完全確定
- 宣伝設定が翌月以降も自動継続するか
- 小型/中型の正確なグリッド寸法
- 各棚/什器の価格・収容量・注目度完全表
- 全商品価格/原価
- 35店員完全表
- 顧客独占率の式
- 各町施設の初代専用完全データ
