### 5.3 時間帯分類 (書籍頁95) — NEW

```
朝  = 7時から11時
昼  = 12時から15時
夕  = 16時から19時
夜  = 20時から23時
深夜 = 24時から3時
早朝 = 4時から6時
```
出典コメント(原文): 「時間帯によって客の現れる頻度を数値化したもの。もちろん、
数値は大きければ大きいほど客が多い。実際に現れる時間は細かく設定されている
