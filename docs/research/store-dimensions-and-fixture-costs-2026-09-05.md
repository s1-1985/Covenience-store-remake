# 初代PS/SS 店舗寸法・什器定量データ追加調査 2026-09-05

対象: 1997年PS/SS版『ザ・コンビニ ～あの町を独占せよ～』。

目的:
- 店舗サイズの正確なマス寸法を可能な範囲で復元する。
- 初代専用資料から、什器のサイズ・サービス効果・維持費・駐車収容数を定量データとして固定する。
- 続編由来の数値は混入させない。

主要ソース:
- 初代PS/SS専用攻略Wiki「内装」 https://wikiwiki.jp/theconveni1/%E5%86%85%E8%A3%85
- 初代PS実機プレイ記録（中級） https://pinkblue.sakura.ne.jp/contents/kansou/game/psgame/ps-simulation/ps-ai/ai-the-conbini-tyukyu.html
- 初代PS実機プレイ記録（上級） https://pinkblue.sakura.ne.jp/contents/kansou/game/psgame/ps-simulation/ps-ai/ai-the-conbini-jokyu.html

## 1. 大型店は縦13×横14の非正方形グリッド

初代専用Wiki「内装」には、大型店について以下の攻略観測がある。

- 大型店のみ縦13×横14で、縦横のマス数が異なる。
- 建設時のリストで上に表示される「縦型」の方が店内スペースが広い。
- 縦型大型店では店内画面の最下段までカーソルが届かず、通常の内装編集ができない不具合がある。
- この場合は「レイアウトの読み込み」以外で最下段を編集できないとされる。

証拠レベル: CONFIRMED-COMMUNITY / FIRST-TITLE-SPECIFIC

### 実装上の意味

大型店を単一の `14 x 14` や単純な回転同型として扱わない。

少なくともデータモデルには:

```text
StoreSizeDefinition
- nominal_size: LARGE
- orientation_variant
- grid_width
- grid_height
- editable_cell_mask
- known_ui_bug_flags[]
```

を持てるようにする。

現時点で確定している大型店の寸法は「13×14」。ただし、Wikiの「縦型の方が店内スペースが広い」という記述は、単なる13×14を90度回転しただけでは説明できない可能性がある。壁・入口・使用不可セル等を含む実使用面積に差がある可能性が高いため、**13×14という外形と、実際に什器を置けるセル数を分離**して扱う。

### 未確定

- 横型大型店の実使用可能セル総数
- 縦型大型店の実使用可能セル総数
- 入口、壁、休憩室等を除いた売場セル数
- 小型店・中型店の正確な縦横マス数

## 2. サービス設備の定量値

初代専用Wiki「内装」から以下を直接確認。

| 設備 | サイズ | サービス上昇 | 維持費/日 | 証拠レベル |
|---|---:|---:|---:|---|
| 観葉植物 | 1×1 | +2 | 120円 | CONFIRMED-COMMUNITY |
| ベンチ | 1×1 | +3 | 168円 | CONFIRMED-COMMUNITY |
| 噴水 | 2×2 | +25 | 2,400円 | CONFIRMED-COMMUNITY |

同ページでは、噴水1個をベンチ4個に置き換えるとサービス上昇は25→12に下がるが、維持費は2,400円→672円になるという比較も示されている。

### 実装上の意味

サービスは店員接客だけでなく、設備の静的加算を持つ。

```text
FixtureDefinition
- footprint
- daily_maintenance_cost
- service_bonus
```

をbaselineデータとして持つ。

サービス値は最大100という初代専用「顧客独占率」資料と整合するため、設備ボーナスは店舗サービス計算に加算される構造が必要。

## 3. 駐車場3種の収容量・サイズ・維持費

初代専用Wiki「内装」から以下を確認。

| 駐車場 | 収容台数 | サイズ | 維持費/日 | 証拠レベル |
|---|---:|---:|---:|---|
| 白線のみの駐車場 | 2台 | 1×2 | 0円 | CONFIRMED-COMMUNITY |
| 2階建駐車場 | 4台 | 1×2 | 240円 | CONFIRMED-COMMUNITY |
| タワー駐車場 | 20台 | 2×3 | 4,800円 | CONFIRMED-COMMUNITY |

同ページでは:
- タワー駐車場2×3の面積に、2階建駐車場を3個置けば12台収容・維持費720円となる。
- 駐車場は配置位置によらず車が駐車する。
- 白線のみの駐車場でも人は上を歩けない。

という挙動も記録される。

### 実装上の意味

駐車場は「店入口への物理的な駐車経路」を完全再現するより、店舗の車来店受入容量を増やす設備として扱う可能性が高い。

ただし駐車場セルは歩行不可なので、店外pathing上は obstacle として扱う。

```text
ParkingFixture
- footprint
- capacity_cars
- daily_maintenance_cost
- blocks_pedestrian: true
- requires_vehicle_path_to_slot: UNKNOWN
```

「どこに置いても駐車する」はプレイヤー観測なので、車が個別スロットまで物理経路探索していると決め打ちしない。

## 4. 什器には利用方向がある

同ページでは:
- 棚やキャッシュディスペンサー等は商品/サービスを利用できる方向が決まっている。
- 4方向回転可能な設備は、ベンチを除き方向性を持つ。
- 配置選択直後は上側が利用方向になる。
- 0.5マス分でも利用面に触れられれば客が商品を取れる。

とされる。

証拠レベル: CONFIRMED-COMMUNITY / FIRST-TITLE-SPECIFIC

このため `interaction_sides[]` は原作再現上必須。

```text
FixtureInstance
- rotation
- interaction_sides[]
- footprint_mask
```

単なる占有矩形だけでは再現しない。

## 5. 通路幅の定量観測

同初代専用資料では:
- 0.5マスの隙間だけでは高確率で詰まる。
- 最低1マスの通路が推奨。
- レジ前は最低2マス確保が推奨。
- 出入口前も2マス程度が望ましい。
- 店員のレジ能力が低い場合、3マス空けても渋滞することがある。
- 複数ルートがあると詰まり時に迂回することがある。

証拠レベル: CONFIRMED-COMMUNITY / BEHAVIORAL

これは以前のレイアウト比較実験資料と整合する。

### 実装上の意味

原作グリッドは少なくとも0.5マス単位の配置/衝突を表現している可能性が高い。

ただし「1セル=0.5マス」と断定するには原作画面・説明書側の確認が必要。

安全な内部表現としては最小配置単位をハーフセル相当まで持てるようにする。

## 6. 中型改築費1,200万円を別PS実機記録で再確認

初代PS版の中級実機プレイ記録では、小型店等を中型店へ改築する際に「中型店舗に改築するには1200万が必要」と明記されている。

同記録では:
- 資金2,000万円の時点で中型改築に1,200万円必要。
- 新店舗は資金不足のためまず小型で出し、後から中型へ改築する運用。
- タバコ・酒・薬の申請可否を土地購入時点で確認し、資金不足時はタバコのみ申請して小型開店する。

Source:
- https://pinkblue.sakura.ne.jp/contents/kansou/game/psgame/ps-simulation/ps-ai/ai-the-conbini-tyukyu.html

証拠レベル: CONFIRMED-COMMUNITY / PS-FIRST-TITLE-PLAYLOG

### 注意

1,200万円が:
- すべての小型→中型で固定
- 向きや土地条件に依存
- 「中型の建物価格」なのか「差額改築費」なのか

まではこのプレイ記録単独では完全確定できない。

したがって現時点では `medium_upgrade_observed_cost = 12,000,000 JPY` と観測値として保持する。

## 7. 販売許可について今回再確認した範囲

初代PS実機プレイ記録では、土地選定時点でタバコ・酒・薬の申請可否を確認でき、資金不足時には「タバコだけ申請して小型店を開く」という運用が行われている。

これは販売許可が:
- 商品カテゴリごとに独立している
- 店舗建設時に複数を個別選択できる
- 許可には費用があり、資金都合で一部だけ先に取る判断が成立する

ことを強く示す。

証拠レベル: CONFIRMED-COMMUNITY / PS-FIRST-TITLE-PLAYLOG

初代専用FAQの「近隣コンビニがあると許可が下りづらい」と併せ、実装モデルは最低限:

```text
SalesLicenseType = TOBACCO | ALCOHOL | MEDICINE
LicenseApplication
- store_site
- type
- available_at_site
- fee: UNKNOWN
- exclusion_from_nearby_convenience: YES / exact_distance UNKNOWN
```

を持つ。

今回も初代の正確な申請料は発見できなかった。続編値は使用しない。

## 8. 確定度更新

### CONFIRMED-COMMUNITY / 実装候補へ昇格

- 大型店外形: 13×14
- 大型店に方向バリエーションがあり、実使用面積差がある
- 縦型大型店の最下段カーソル到達不能バグ
- 観葉植物: 1×1 / サービス+2 / 120円日
- ベンチ: 1×1 / サービス+3 / 168円日
- 噴水: 2×2 / サービス+25 / 2,400円日
- 白線駐車場: 1×2 / 2台 / 0円日
- 2階建駐車場: 1×2 / 4台 / 240円日
- タワー駐車場: 2×3 / 20台 / 4,800円日
- 駐車場セルは歩行不可
- 什器に利用方向がある
- 0.5マス隙間は通れる/利用できる場合があるが詰まりやすい
- 中型への改築費1,200万円というPS実機観測

### 未確定

- 小型店の正確な外形寸法
- 中型店の正確な外形寸法
- 大型店2方向の実使用セル差
- 全什器の購入価格
- 棚/ワゴン/冷蔵/冷凍/専用設備の全footprint
- 全什器の維持費
- 販売許可3種の正確な申請料
- 販売許可の排他距離/判定式

## 9. 次の調査優先順位

1. 攻略本「内装レイアウトKit」または原作画面から小型/中型のマス数を数える。
2. 初代説明書/原作建設画面から大型店の2方向を視覚確認する。
3. 初代攻略本の設備データ表から棚・ワゴン・冷蔵・冷凍・レジ・ATM等のサイズ/価格/維持費を回収する。
4. 販売許可申請画面からタバコ・酒・薬の申請料を直接取得する。
5. 0.5マス単位がゲーム内部の正式グリッドなのか、攻略上の呼称なのかを原作画面で検証する。

著作権保護のため、原作画像そのものはリポジトリへ保存しない。数値、観測、出典URLのみ保存する。
