# PS小型店舗グリッド実画面復元・攻略本ソース/店員表記衝突監査 2026-09-05

対象: 1997年PlayStation版『ザ・コンビニ ～あの町を独占せよ～』。

目的:
- 原作PS画面の連続スクリーンショットから、小型店舗の編集床グリッドを直接復元する。
- 新規出店画面の価格表示をPS実画面で再確認する。
- 1997年攻略本のうち、PS/SS直接資料とplatform未解決資料を分ける。
- 店員氏名の表記衝突と、長期プレイ由来の特殊挙動を推測で確定しない形で記録する。

## 証拠レベル

- CONFIRMED-VISUAL / PS-SPECIFIC: 1997年PS版の原作画面から直接読める。
- VISUAL-RECONSTRUCTION / PS-SPECIFIC: 原作画面のグリッド線を数えて復元。画面切り抜きそのものはrepoへ保存しない。
- CONFIRMED-BIBLIOGRAPHIC: 国会図書館/図書館/書店等の書誌。
- PLATFORM-UNRESOLVED: 初代タイトル本だが、PS/SS版専用かPC版共通かを本文/表紙で未確定。
- PROVISIONAL-DIRECT-PLAY: PS版を長期プレイした単一レビューの具体的観測。再現試験待ち。

## 2. 小型店舗（上段左アイコン）の建設価格は600万円

店舗選択画面 `9180_2.jpg` では、6つの店舗アイコンが2行x3列で表示され、カーソルは左上アイコンに置かれている。

その状態で画面に:

- `店舗を選んで下さい`
- `¥6,000,000`

が直接表示されている。

Evidence:
- CONFIRMED-VISUAL / PS-SPECIFIC

既存研究で左列を小型2方向と解釈しているため、少なくとも「左上アイコン = 小型候補A」の価格600万円は原作画面で固定できる。

注意:
- 右上/中央/右列など他5タイプの価格はこの画面1枚からは読めない。
- 左下も同額であると勝手に仮定しない。

## 3. 小型店舗の編集床は8 x 13マスと視覚復元できる

`9180_3.jpg` は、上記店舗選択の直後に表示されるPS版店内画面である。

明るい青灰色の編集床には規則的なグリッド線が残っており、什器に隠れていない線を外周まで追うと:

- 横方向: 8セル
- 縦方向: 13セル

を数えられる。

判定:
- `small_store_variant_A_edit_floor = 8 x 13`
- Evidence: VISUAL-RECONSTRUCTION / PS-SPECIFIC

### 重要な境界

これは画面上で見える「店内の編集床」のセル数として採用する。

次を同一視しない:
- 建物外形
- 店外設備配置域
- 壁厚を含む総footprint
- 0.5マス内部単位の換算値

既存の大型 `13 x 14` は初代専用Wikiの表現と測定対象が同一かをまだ再確認する必要があるため、現段階では:

```text
StoreGeometryEvidence
small_A.visible_edit_floor = 8x13   # PS visual reconstruction
large.reported_dimension = 13x14    # first-title community source
```

として別フィールドで保持する。

### 方向違いについて

店舗選択画面には左上/左下の2つの小型候補が見えるが、今回店内を確認できるのは左上選択後の1方向のみ。

したがって:
- 小型A: 8x13 = strong visual reconstruction
- 小型B: UNKNOWN

`13x8` と単純回転で決め打ちしない。大型店では方向による実使用域差/カーソル不具合が既に報告されているためである。

## 4. 画面シーケンスから得られる追加事実

店舗選択画面では時刻00:00、資金 `¥180,000,000`。

店内画面では時刻01:52、資金 `¥173,997,900`。

差額は6,002,100円であり、表示建設価格600万円との差に2,100円がある。

この2,100円の意味は現在不明。

候補例:
- 時間経過中の費用
- 設備/維持費
- 何らかの初期支出

ただし画面間で操作が省略されている可能性があるため、**「小型店建設時に追加2,100円かかる」とは確定しない。**

Evidence:
- 金額表示そのもの: CONFIRMED-VISUAL
- 2,100円の意味: UNKNOWN

また、180,000,000円をシナリオ開始資金そのものとは扱わない。土地取得等の前工程後の残高である可能性があるため、既存のシナリオ開始資産データとは分離する。

同じPS1商品ページの2022年レビューでは、使いやすい店員として次の氏名が挙げられる。

- 里中涼子
- 福本孝仁
- 金田哲也
- 竹中小百合
- 杉村真智子
- 菅原文夫
- 中山光次

Source:
- https://www.gavas.jp/products/detail.php?product_id=9180

既存researchには以下の異表記が混在している:
- 福本考仁 vs 福本孝仁
- 竹中百合子 vs 竹中小百合
- 菅原丈夫 vs 菅原文夫

したがって35人マスターへ氏名を確定入力する前に、原作採用画面または1997年PS/SS攻略本の名簿表で決着させる。

判定:
- これらの人物がPS版店員候補として言及されること: CONFIRMED-COMMUNITY / PS-SPECIFIC
- 正式漢字表記: CONFLICTING / NOT-LOCKED

### 実装ルール

```text
StaffNameEvidence
- candidate_id?
- spelling
- source
- platform
- confidence
```

を持ち、名前だけで別人レコードを作らない。

## 8. 80歳以降の店員特殊挙動は面白いが未確定

同PSレビューでは非常に具体的な長期観測として:
- 店員は80歳以降、年ごとにランダムで全能力100になることがある
- 127歳まで存在を確認した
- 死亡/強制退職を確認できなかった

と報告されている。

これは初代の長期プレイ/年齢処理に関する重要候補だが、単一ユーザー観測であり、乱数条件も未検証。

判定:
- PROVISIONAL-DIRECT-PLAY / PS-SPECIFIC

まだ実装してはいけない:
```text
if age >= 80: random_all_stats_100()
```

必要な検証:
1. 79→80歳の年越し前後の連続画面
2. 複数店員で再現
3. 発生確率
4. 100化が全能力か実務能力だけか
5. 年齢上限/退職/死亡処理の有無
