## 3. 店舗配置・道路・競合

追加で実装価値が高い記述:

- 店舗は **道路に隣接していなくても出店可能** とWiki攻略記録。
- 店舗同士を近づけ過ぎると顧客の奪い合いが強くなる。
- 本店は支店より競争に弱いように見えるという繰り返し観測があり、Wikiは「謎の本店補正」と表現している。
- 周囲にライバルがいない好立地では定価でも顧客独占率50%超が狙える一方、近隣競合がある状態で値上げすると0%まで落ちる場合がある。

実装候補:

```ts
interface StoreAttractionContext {
  nearbyCompetitors: number;
  isHeadStore: boolean;
  roadAdjacencyRequired: false;
}
```

`isHeadStore` の競争ペナルティは数値未確定なので `HYPOTHESIS` として保持し、固定係数にはしない。

## 4. 販売許可対象の明示

Wikiの顧客独占率ページは、品揃えの文脈で **タバコ・酒・薬** の販売許可を明示している。

よって販売許可マスターの対象候補は少なくとも:

```text
alcohol
tobacco
medicine
```

FAQでは近隣コンビニが存在すると酒・タバコ等の許可が下りにくくなること、敵味方を問わないことを明記。

実装境界:

```ts
interface SalesPermitDefinition {
  id: "alcohol" | "tobacco" | "medicine";
  fee: number | null;              // 未回収
  exclusionDistance: number | null; // 未回収
  checksFriendlyStores: true;
  checksRivalStores: true;
}
```

費用と距離は引き続き攻略本優先で回収する。

### ついで買いされない可能性 [HYPOTHESIS]

### イベント商品
- 主購買層が低年齢層とされ、価格を上げると売れにくい。

これらは全て疑問形/攻略観測なので、原作確定式としては扱わない。ただし `ProductDefinition` に以下のフィールドを設ける根拠として有用。

```ts
interface ProductDefinition {
  canBePrimaryTripPurpose: boolean | null;
  canBeIncidentalPurchase: boolean | null;
  buyerAgeBias: string | null;
}
```

攻略本データが得られるまで `null + evidence note` とする。

## 6. 店舗拡大と評価

Wiki攻略記録からの追加境界:

- 小型店でも上級の星5到達は可能とされる。
- 大型化は品揃えを増やすが、清掃等の要求負荷も上がる。
- Wiki攻略者の観測では改築による売上増は「せいぜい約1.5倍程度」。これは式ではなく攻略評価。
- 上級では月初に総合評価が上がるというWiki記録がある一方、別の長期プレイ記録では年次/1月評価が示唆されているため、両者を統合せず二層評価仮説を維持する。

実装上、店舗サイズを上級評価の必須条件にはしない。

## 7. ライバル店舗の追加挙動

ゲームモード攻略から以下を追加回収。

- ライバル **支店** は買収可能。
- ライバル **本店は買収できない** と明記。
- 開始直後のライバル支店買収価格は約4,500万円という攻略観測。
- 近隣に低価格/赤字支店を置いて顧客を奪うと、ライバル本店を撤退させられる場合がある。
- 価格を約-20%にした支店でも出店ペースを遅らせられるという攻略観測。
- 最短で半年程度で本店撤退という例が記載されるが、確率/式ではない。
- プレイヤー+ライバル合計10店舗上限のため、プレイヤーが枠を占有するとライバル新規出店を阻害できる。

実装候補:

```ts
interface RivalStoreState {
  role: "head" | "branch";
  acquirable: boolean; // head=false, branch=true provisional
}
```

撤退条件と再出店条件は攻略本/長期プレイでさらに検証する。

## 8. 町・土地の観測値

追加の攻略観測値として保持:

- 序盤約2,000万円で買えた土地が2年後に1億円超になる例。
- 町人口5,000超で線路上に駅が出現する記録。
- 駅の人口表示値2,240。
- 駅候補は左右各1か所という攻略記述。
- 誘致なしでは町人口15,000付近から増えにくいという観測。
- 大学は誘致コストパフォーマンスが高いという攻略評価。

土地価格のインフレは明確にゲーム性として存在するが、成長式は未確定。

## 9. レイアウト/歩行の追加ヒント

既存抽出を補足:

- 出入口前も2マス空けるのが望ましいという攻略推奨。
- 人気商品（弁当・パン）を入口から遠くへ置き、店内を回遊させてレジへ向かわせることで入口渋滞を軽減できる。
- 商品への複数経路があると、詰まり時に迂回する場合がある。
- 自販機を向かい合わせに配置すると往路/復路の客が衝突しやすい。
- 駐車場は店からの距離/位置を問わず利用される一方、白線駐車場セルも歩行不可。

これらは `Pathfinding/FixtureAccess` のテストケースとして採用価値が高い。
