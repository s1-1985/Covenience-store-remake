# 初代PS/SS 内装変更による床汚れリセット調査 2026-09-06

対象は1997年PS/SS版『ザ・コンビニ ～あの町を独占せよ～』のみ。後続作・PC版の仕様は混同しない。

## 新規確認事項

初代PS/SS専用攻略Wiki「裏技」には、営業時間外または臨時休業中に内装変更画面を開くと、店舗内に存在する床の汚れがすべて消えるという観測が記録されている。

Source:
- https://wikiwiki.jp/theconveni1/%E8%A3%8F%E6%8A%80

該当ページはPS/SS初代専用Wiki配下であり、トップページでもPC版ではないことが明示されている。

## 証拠レベル

- **B+ / FIRST-TITLE-DEDICATED-COMMUNITY-OBSERVATION**
- 理由: 初代PS/SS専用資料で明示された再現手順付き観測である。
- ただし一次説明書・原作画面の直接比較、PS版/SS版双方での個別再現確認は未実施のためAにはしない。

## 再現仕様への含意

床汚れは単なる表示ではなく、通常は店員の清掃作業によって処理される店舗状態である。一方で内装編集の開始時には、営業時間外/臨時休業という前提条件付きで、床汚れ集合が一括クリアされる挙動を持つ可能性が高い。

実装時は少なくとも以下を分離しておくべきである。

- `StoreFloorDirt` : 店内セルまたは汚れオブジェクトの集合
- `CleaningTask` : 店員AIによる通常清掃
- `InteriorEditEntered` : 内装変更画面への遷移イベント
- `isClosedForBusiness` : 営業時間外または臨時休業中か

暫定互換ルール:

```text
if InteriorEditEntered && isClosedForBusiness:
    clear_all_floor_dirt()
```

ただしこれは現時点では観測再現ルールであり、内部原因が「内装画面を開いた瞬間の明示クリア」なのか、「内装データ再構築時に汚れオブジェクトが保存されず消える」なのかは不明である。

## 未確定事項

以下はまだ固定しない。

1. 営業中に内装変更へ入れる経路が存在する場合、その時も汚れが消えるか。
2. PS版とSS版の双方で同一挙動か。
3. 汚れ消去が店舗の「清掃」パラメーター自体を直接上昇させるか、それとも床汚れオブジェクトだけを消すか。
4. 内装画面を開くだけで発火するか、配置確定・終了時に発火するか。
5. 改築画面、レイアウト読み込み、店舗売却等でも同様の汚れリセットが起きるか。
6. リセット後の清掃値・顧客独占率再計算タイミング。

## 実装開始可否

床汚れ状態と内装編集イベントを別レイヤーに持ち、互換モードで上記リセットフックを差し込める構造は実装開始可能である。

ただし、清掃パラメーターへの数値効果や発火タイミングを固定するのは早い。原作実画面で「汚れあり → 内装画面を開く → 復帰」の前後を比較し、床汚れ・清掃値・顧客独占率の3点を同時観測するのが次の優先検証である。
