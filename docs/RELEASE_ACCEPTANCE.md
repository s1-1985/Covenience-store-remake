これらの未確認を解消するまでは「完成」としない。自動テストの成功だけで実機確認済みにしない。通常プレイを妨げる不具合→継続/保存→残る原作差の順で対応する。元のPS再現要件は維持し、調査済みの細部や原作互換を黙って削除しない。
