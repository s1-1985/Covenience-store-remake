## 2. コントローラマッピング（説明書 p.2「コントローラ」）

### 2.1 基本割当（確定）

| 入力 | 役割 |
|---|---|
| ○ボタン | 決定 |
| ×ボタン | キャンセル |

### 2.2 文脈ごとの操作（説明書の他ページ＋従来証拠との一致）

- 出店位置の選択: カーソルで位置を決め、L1 で店舗サイズ変更（従来、公式スクリーンショットの文言「L1・・・サイズ変更」CONFIRMED-VISUAL で確認済みだったものと一致）。
- 店内レイアウト（p.6-7）: 商品棚は L1／R1 で向きを変え、カーソルで配置。棚の種類ごとに置ける商品が決まる。
- 名前入力（p.4-5）: L1／R1 で ひらがな・カタカナ・記号の切替、× で文字訂正、スタートで入力決定。
- 宣伝選択画面の終了は START（従来スクリーンショットの「終了・・START」CONFIRMED-VISUAL と、説明書 p.2 の「モードの終了」と一致）。

### 2.3 説明書内部の食い違い（未解消として記録）

メニューを開くボタンについて、p.2 は □（セーブ手順も「マップ画面上で□ボタンを押し、メニューの中の『システム』を選択」と □ で一貫）、一方 p.10 の導入文は「○ボタンでメニュー表示」と読める。拡大して再確認したが両ページで表記が異なるため、説明書側の表記ゆれ／誤記の可能性として記録し、どちらか一方を正として固定しない。解消には実機・プレイ動画での確認が必要（ChatGPT 側または実機確認の対象）。

## 3. メニューコマンド（説明書 p.10「メニューコマンド」）

トップレベルは次の4コマンド＋システム。

| コマンド | 説明書の要約 |
|---|---|
| 店舗 | 一覧画面で各チェーン店の客の流れ・商品の売れ行きをリアルタイムに把握。各店をカーソルで選ぶと店内も見られる |
| 不動産 | チェーン店の追加や店舗の売却。手順は新規開店時と同じ |
| 販売促進 | 店の宣伝と、各建造物や施設の誘致 |
| 調査 | 店の統計（店舗別詳細、店舗別収支グラフ、全店収支グラフ）とアンケート（客のニーズを知る手がかり） |
| システム | p.10 の4項目には並ばないが、p.2 のセーブ手順でメニュー内項目として明記。セーブはここから行う |

読み取れる含意:

- 従来 STRONG-CANDIDATE 止まりだった「販促 → 宣伝／誘致」の階層は、トップレベル名が **販売促進** で、その内容が宣伝と誘致であることが説明書で裏付けられた（ゲーム内表記が「販促」か「販売促進」かは画面側の表記確認が別途必要）。
- 調査の子項目ラベルは **店舗別詳細／店舗別収支グラフ／全店収支グラフ／アンケート** と確定した。従来「機能は確定・ラベル UNKNOWN」だった店舗売上成績系・アンケート系に対応する。
- 人事系（雇用・異動・解雇）と店舗管理系（内装・改築・営業時間・価格）はトップレベルに無い。従来証拠の店内サイドパネル（店舗名／営業時間／評価／内装／方針／店員／改築、CONFIRMED-VISUAL）と合わせると、これらは店舗を選んだ先の店舗別コマンドである構造が強く示唆される。ただし説明書 p.10 は店舗別コマンドの一覧を載せていないため、店舗別コマンドの完全な一覧と正式ラベルは引き続き画面証拠側の確定待ちとする。

## 4. セーブ／ロード（説明書 p.2、U-A1 への接続情報）

- メモリーカードは **14ブロック** 使用、差込口1のみ。
- 保存できるのは、1マップ分のゲーム途中データと、店内レイアウト6種類（6種類の店舗に各1種類ずつ）。
- セーブ手順: マップ画面でメニューを開き「システム」からセーブ。その際、店内レイアウトも保存するか確認される。
- ロード手順の記載は、説明書の全ページを確認しても見当たらなかった（版2で確認）。ロードはゲーム内の画面側で完結するものとみられ、手順の根拠は画面証拠側に求める。
- これは利用者レベルの仕様確定であり、原カード形式のバイナリ仕様（U-A1）そのものは依然として原作データ解析側の対象。

## 5.5 残りページの抽出結果（版2で追加）

### p.3「ゲームの目的」

- 3マップの目標が公式に明記されている: 初級=都庁を誘致する、中級=10店舗経営する、上級=オーナー評価を★★★★★にする。これは QR part2 §3.9、shopkeeper-manual part2 §3.3、既存の `SCENARIOS` の記録と一致し、上級クリア条件は「オーナー評価★★★★★」であることを公式説明書の側からも裏付ける（§21.3 の数値セットへの反証の追加。`2026-11-21-section213-source-hunt.md` §2 参照）。
- ロード手順や、追加のセーブ／メモリーカード仕様の記載は無い。

### p.8「すぐにゲームを始めたい！」手順11〜12

- 手順11: 商品の価格率の設定（全体一括、または商品ごと個別。画面例に「全商品平均利益率 40%」「全体に設定」「個別に設定」等が見える）。
- 手順12: 店員の雇用（店長を含めて3人まで。候補者画面の例示あり）。
- 店舗別コマンドの一覧・ラベルは無い。

### p.9「画面の見方」

- マップ画面: 赤い■=自分のお店、青い■=ライバル店、「本」=本店、数字=何号店か。対象を選ぶと情報画面が現れる。ライバル店の詳しい情報を知るには調査費用が必要で、資金が許せば本店以外のライバル店を買収できる。建造物を選んでも情報画面が現れる。施設の誘致には援助金を提供する。
- 基本画面: 店員・客・商品棚などをカーソルで選択すると情報が表示される。月日や時間の流れと客層の変化を見比べる、という趣旨の説明。
- 画面図は2枚のみで、番号付きの引き出し線による HUD 要素の呼称一覧は無い。画面図の上部バーには日付・時刻・金額らしい数字が見えるのみで、「人口」「資金」等を HUD のラベル名として説明する記述は無い。HUD ラベルの確定は引き続き画面証拠側の担当とする。

### p.11〜12「キーワード索引」（攻略のヒント）

ページ参照を持たない用語集で、見出し語は全て判読できた（36語程度）。実装・解析に関わる主な確認事項:

- **「つまみだす」は原作のコマンド名である**（索引「エヘヘ！」の項: 万引した者を「つまみだす」のコマンドで店から追い出す）。ただしボタン操作の手順は説明書に無い。
- 買物人口の定義: 対象となる建物の中にいる、お客さん候補の人数。
- オーナー評価: 経営手腕の総合評価で、店舗数・来客数・年商などがある一定のレベルに達することが評価を上げるポイント、という定性的な説明のみ（数値条件は無い）。
- 隠しマップの項の本文は「？？？」とだけあり、形状等の情報は無い（隠しマップ形状差の出典が攻略本側にあることと矛盾しない。`2026-11-21-section213-source-hunt.md` §3 参照）。
- その他: 調査のグラフは3種類。レジは4タイプ（宅配便を扱えるもの、2人体制のもの等）。店員控室は2種類。月次報告は毎月末に表示。販売許可（たばこ・酒・薬品）は認可制で、地区によっては販売できない。一覧画面は各チェーン店のリアルタイム情報を把握する基本画面。人事の項は店長選び・店舗間の異動・リストラに言及。
- p.12 下部には「ポイント」欄（店内画面・統計グラフ・情報ウィンドウ・一覧画面に店の現状と問題が全て表れる、という総括）。裏表紙内側は使用上・健康上の注意のみで、ゲーム内容の記載は無い。
