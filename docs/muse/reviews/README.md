# docs/muse/reviews/ — 実装レビュー結果

Codex の実装報告（実装ブランチの `docs/implementation/CSRM-NNN.md`）に対する Muse のレビューを、指示書と同じ ID でここへ保存する。

## 現在の状態

- レビュー済み: なし（2026-11-21 初回棚卸し時点。ready には CSRM-001、CSRM-002 が発行済みで、いずれも実装待ち）

## レビューの形式

各レビューファイルには以下を含める。

- 対象の指示書IDと版番号、実装報告のコミット・PR・ブランチ
- Critical / Major / Minor の指摘（各指摘は指示書の完了条件に対応付ける）
- 受け入れ可否（受け入れ可 / 修正後に受け入れ可 / 受け入れ不可）
- 必要な修正内容
- 新しい要求は、既存実装への指摘と分けて、指示書の改訂または新規指示書として扱う（レビュー内で新規要求を混ぜない）

Codex は次回作業時にここのレビューも読み、未対応の指摘を処理する。
