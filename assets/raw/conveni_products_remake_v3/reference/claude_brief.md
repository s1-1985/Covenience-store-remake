用途: このファイルの内容をそのままChatGPTに貼り付けて、店内什器(什器本体・空の状態)と商品オーバーレイ(什器の中身)のスプライトを再発注するための仕様書。前回(`assets/raw/konbini_PS1_fixtures_ONLY/`・`konbini_product_assets_for_claude/`、v1)に不具合があったため、v2で作り直す。
データ出典: `reference_sim/conveni_sim/baseline_data.py`(`FIXTURES` + `STRATEGY_GUIDE_FIXTURES`、`PRODUCT_CATEGORY_PRICING`。いずれも攻略本表からのCONFIRMED_OFFICIAL転記)。
footprint(タイル数)・商品カテゴリ名は原資料からの確定データ。ピクセルサイズ換算・見た目の方向性は本ドキュメントで新規に定義した提案値であり、原作の再現ではない。

## 0. 前回(v1)からの修正点

前回渡された`assets/raw/konbini_PS1_fixtures_ONLY/`・`konbini_product_assets_for_claude/`(および同時期の客・店員パッケージ)には**カットアウトの縁に白いフチが残るアーティファクト**があり、v2(白フチ除去版)で一度差し替え済み。什器・商品を**再度作り直す**にあたっては、最初からこの問題が起きないよう、第1節の透過要件を必ず守ること。

## 1. 共通スタイル指定(ChatGPTへのプロンプト冒頭に毎回貼り付けること)

```
あなたは架空のコンビニ経営シミュレーションゲーム(特定の実在タイトルを参照しない、完全オリジナルの新規タイトル)向けに、
店内什器(棚・ワゴン・什器本体)と、その什器に並ぶ商品オーバーレイのドット絵アイコンを作成するイラストレーターです。

【視点・様式】
- 真上から見た「見下ろし型」(トップダウン)のアイコン。等角投影(アイソメトリック)ではなく、平面的な什器アイコンとして描く。
- 1990年代後半の家庭用ゲーム機で見られたような、粗すぎない中解像度ドット絵(擬似ドット絵/pixel-art風)。
- 什器本体アイコンと、商品オーバーレイアイコンは**別レイヤーとして重ねられる前提**で作ること(什器の上に商品を後から合成する)。
- 線画はやや太めの輪郭線、彩度はやや高めのポップな配色(コミカルな経営シムのトーン)。

【透過要件(最重要、前回の不具合の再発防止)】
- 背景は完全な透過(アルファチャンネルあり、RGBA PNG)で出力すること。
- クロマキー(単色背景を後から抜く方式)は使わないこと。抜いた後の縁に薄い白または背景色のフチが残る不具合が前回発生した。
- カットアウトの輪郭は**ソフトなアンチエイリアスの滲みを残さず**、輪郭線のすぐ外側で完全に透明(アルファ0)になるようにすること。
- ドロップシャドウやグロー効果を輪郭の外側ににじませないこと(必要なら図形内部の陰影のみで表現する)。
- 出力後、目視でアイコンを暗い背景・明るい背景の両方に置いてみて、縁に色の残留がないか確認すること。

【禁止事項】
- 特定の既存ゲーム・アニメ・キャラクターのロゴ、看板文字、意匠を模倣しないこと。
- 実在の企業ロゴ・商標を描かないこと。

【出力形式】
- 各アイテムは指定されたキャンバスサイズ(px)の正確な比率で出力すること(後述の表を参照)。
- 複数アイテムをまとめて発注する場合は、1枚の画像内にグリッド状に並べ、各セルの直下にアイテムの英語ID(例: small_ambient_shelf)をラベルとして明記すること。
```

## 2. ピクセル換算ルール(本ドキュメントで新規に定義、原作の値ではない)

`docs/assets/chatgpt-building-sprite-brief-2026-09-22.md`と同じ基準(1タイル=64px)を使う。素材一式でスケールを揃えるため。

- 什器キャンバスサイズ(px) = footprint(幅タイル数 × 高さタイル数) × 64
- 商品(中身)は什器の基本単位である1x1(64×64px)を基準に作る。什器側が2x1・3x1などの場合は、1x1素材を並べて敷き詰める前提(前回パッケージと同じ方針)。

以下の表の「footprint」列は`(幅, 高さ)`の順。

## 5. 発注の進め方(推奨ワークフロー)

1. 什器は第3節のカテゴリ単位(3.1〜3.9)でバッチに分けて発注する。
2. 商品(中身)は第4節を数カテゴリずつのバッチに分けて発注する(在庫量3段階があるため、1バッチのアイテム数は少なめにする)。
3. 各バッチのプロンプトは「第1節の共通スタイル指定」+「該当する表(ID・footprint・キャンバスpx・外観の方向性)」をそのまま貼り付ける。
4. 出力を受け取ったら、そのままこのセッションに投げてください。私の方で:
   - 各セルが対応する`ID`/`category_id`に対応しているか
   - footprintの比率(幅×高さ)が仕様通りか
   - 透過の縁に白フチ等の残留がないか(第1節の再発防止項目)
   を確認します。
