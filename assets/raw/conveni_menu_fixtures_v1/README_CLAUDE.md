# ザ・コンビニ メニュー用アイコン — fixtures

収録数: 45。攻略本の掲載アイコンを切り出し、枠外の紙面を除去してサイズを統一した素材です。新規描き起こしではありません。スキャン由来のぼけ・色むらが残ります。128px版も原画の情報量を増やしたものではありません。

## Claudeへの実装指示
- メニュー表示専用。店内・町マップのスプライトを置き換えないでください。
- 什器は資料の斜め視点の設備図、商品はカテゴリの代表商品、店員は顔アイコンです。
- icons_32 / icons_48 / icons_64 / icons_128 に各サイズの個別PNG。表示サイズに合う画像を選んでください。
- atlas_64.png と atlas_64.json は64px版のアトラス。座標原点は左上、各画像の外側に2px余白。
- manifest.json の id で既存データと対応します。店員は staff_001〜staff_035 の既存番号を維持。
- extra=true は既存リメーク一式にない資料上の追加アイコンです。必要に応じてデータ定義を追加してください。
- 透明度は0/255の二値。青・紫の枠と内部背景はアイコンの一部として残しています。人物・商品そのものを透過抽出した素材ではありません。
- 商品アイコンは在庫量によらず固定。empty / half / full のワールド表示と分けて使ってください。

## 出典対応
- 提供攻略本 downloadfile(1)(7).PDF のPDF19〜23、25〜30ページ。個別ページ・掲載順はmanifest.json。
- 提供の1時間プレイ動画も確認。ゲーム内配置が真上視点であることを確認し、メニューの構図との用途を分離。
- source_pdf_page はPDF先頭を1としたページ番号。
