# 初代『ザ・コンビニ』PlayStation版 ディスク解析・第1報

対象は提供された `SLPS_00782.BIN` と `SLPS_00782.CUE`。原本を変更せず静的解析した。画像34枚、街4マップ、メッセージ502件とスタッフロール102件を復号・可視化した。実機・エミュレータでの動作解析、経営計算の完全解読はまだ行っていない。

## 確認できた構成

|---|---|

|ISOボリューム名|SLPS_00782|
|ファイル数|77|
|画像|TIM 34ファイル。全ファイルのブロック長と画素数が一致|
|街|TOWN0001 / TOWN0002 / TOWN0003 / TOWNPS、各76,707バイト|
|メッセージ|MSG00.OBJ 502件、STAFF.OBJ 102件|

全セクタの同期パターンとXAサブヘッダの二重記録は整合していた。Form1は35,924、Form2は2,412セクタ。EDC/ECCの完全検証と外部の正規ダンプ照合は未実施であり、「原盤と完全一致」とは断定しない。

## 原作画像を取り出した

`images/`には34枚のPNG、`tim-index.json`には元ファイル・寸法・色深度・ハッシュを記録した。以下の用途は画像を目視確認した分類である。

|原ファイル群|内容|
|---|---|
|MAN0.TIM|客・店員などの人物アニメーション用画像|
|CASE_T00 / CASE_T01|棚・冷蔵設備・レジなどの選択用アイコン|
|SHOP_T00 / SHOP_T01|商品を載せた棚の選択用画像|
|SYOP_S00～03|店内の床・壁・設備・商品などの描画部品|
|TOWN_PR1 / TOWN_YU1|街の地形・道路・建物などのタイル。YU1は雪景色を含む|
|BUILDIN1 / SHOPTYP1|街の建物、店舗外観の選択用画像|
|PSMOJI0 / PSMOJI1|日本語を含む独自フォント|
|KAO01 / KAO02|人物の顔画像|
|KYOU / PS_CM1|カーソル・枠・看板などの画面部品|

PNGは原データの色を復号したもので、生成画像ではない。PS1の半透明描画は背景とGPU設定に依存するため、閲覧用PNGでは色値0のみ透明、それ以外は不透明としている。元のTIMは保持している。画像部品の境界すべてとアニメーションの速度・順序は未確定である。

## 街の配置を復元した

4ファイル共通で、先頭17バイトの直後から3,000件の8バイトレコードが並ぶ。先頭2バイトはリトルエンディアンのタイルIDで、640件のCEL定義に対応する。残る6バイトの意味は未確定としてそのままJSONに保存した。

- 画面の並びは **横60×縦50**。1区画8×8ピクセルの基礎タイルとして配置画像を再構成した。
- 実行プログラムのRAM `0x8002C040` に50行、`0x8002C060` に60列のループ上限がある。
- 同じ処理の `0x8002C080～0x8002C0A8` は `y×480 + x×8` とマップ配列アドレス `0x801398F0` を使う。幅とレコードサイズがデータの復元結果に一致する。
- CELのUV座標には縦96ピクセルの配置差がある。TIMの原点へ戻す際にこれを差し引くと、道路・区画・建物が連続した街として復元できる。
- `maps/` に4枚の配置画像と、各3,000件の元オフセット付きJSONを収録した。

これは原作の基礎タイル配置の再構成であり、ゲーム中のUI・時刻変化・追加描画を含むスクリーンショットではない。

先頭ヘッダの未命名32bit値（オフセット1、5、9、13）は次のとおり。金額等に見える値もあるが、用途はまだ断定しない。

|TOWN0001|0|200000000|100000000|3750|110000|

## メッセージと操作の手掛かり

OBJは通常のShift-JIS文書ではない。先頭に32bitオフセット表、その後に16bitの独自文字番号が並ぶ。PSMOJIの12×16ピクセルの字形を横21・縦16、1ページ336字として対応させることで、原作の文章を読めるようになった。全604件の字形番号は2ページの範囲内に収まる。

`MSG00-messages.json` / `STAFF-messages.json` は全レコードの位置・コード列を収録。`messages/` はその字形を並べた閲覧画像である。MSG00のID185・186・238・240・247は次のオフセットまでの範囲に終端0x40FFがない。連結等の実行時の扱いは未確定のため、閲覧画像はオフセット表の境界を保持した。日本語のUnicode文字列への全面変換は未実施。制御コード（0x4002等）は画像では省略しており、数値差し込みや改行、原画面と同じ組版はまだ再現していない。したがって画像中の数字をそのまま確定値と扱ってはいけない。

## 実行プログラムと音声

起動設定は `BOOT = cdrom:SLPS_007.82;1`。EXEヘッダのロード先は `0x80010000`、初期PCは `0x8007E3A0`、ロード長は `0xBD800`。ファイルオフセットからRAMへの対応は `RAM = 0x80010000 + offset - 0x800`。

MIPS逆アセンブルで街配列の処理を確認した。`map-grid-disassembly.txt` に根拠となる命令を収録。`executable-reference-hits.txt` は定数3000の参照候補であり、すべてを街処理と認定したものではない。`executable-summary.json` の関数アドレス候補も、データ混在の線形解析なので未検証を含む。

`executable-paths.json` にはプログラム内のファイル名を元オフセット付きで収録した。DAT1/DAT2のレイアウト名など、今回のISO一覧には存在しない参照文字列もある。未使用データや別構成向けの名残の可能性があり、これだけでディスク欠損とは判断できない。

音色バンクは9組。サイズ表の合計は9組すべてVB実サイズと一致した。ヘッダ上のサンプル数はBGM計129、CON_KOE 12、CON_SE 14である。7本のSEQの初期テンポ等は `audio-index.json` に記録した。曲名・場面との対応、SPUのピッチやループ、XAの内容は未確認で、音楽全曲の復元済みという意味ではない。

## 再実行と同梱範囲

必要環境：Python 3、Pillow。実行プログラム解析のみCapstoneを追加する。

```sh
python tools/analyze_disc.py --bin /path/to/SLPS_00782.BIN
python tools/decode_tim.py
python tools/decode_messages.py
python tools/decode_maps.py
python tools/analyze_executable.py
python tools/analyze_structure.py --bin /path/to/SLPS_00782.BIN
```

解析一式ZIPにはスクリプト、JSON/CSV、PNG、EXEおよび小さい原ファイルを含む。元ディスク全体、全0の3MIN.BIN、SOUND.XA、MPLOGO.STRは同梱しない。これらも元BINから再抽出できる。Form2を含む2ファイルは、データ欠落を避けるため2048バイトへの切り詰めをせず、`.raw2352` として生セクタを保持する。

一次資料はユーザー提供のBIN/CUEそのもの。TIM、CEL、SEQ、VAB、PS-X EXEの形式確認には [PSX-SPX CDROM File Formats](https://psx-spx.consoledev.net/cdromfileformats/) を参照した。ゲーム固有の配置・件数・メッセージは、このディスクの実測と画像確認による。
