# 初代『ザ・コンビニ』 店員アセット暫定版（Claude向け）

本パッケージは、初代『ザ・コンビニ ～あの町を独占せよ～』の攻略本から抽出した店員顔アイコン35人分を参照し、
店内で使用するトップダウン歩行スプライトとして再構成した暫定版である。

## 収録内容
- sprite_sheets/ : 店員35人分の一覧シート 4枚
- row_strips/ : 各店員ごとの横並び8コマ画像（ID付き） 35枚
- sprites/ : 各店員ごとの個別フレームPNG 280枚
- reference_faces/ : 攻略本由来の店員顔アセット参照資料
- previews/ : 俯瞰確認用のプレビュー一式
- manifest.csv / manifest.json : 店員IDと画像ファイルの対応表
- frames_manifest.csv : 各コマ単位の画像対応表

## 方向・コマ順
- down_A / down_B
- left_A / left_B
- right_A / right_B
- up_A / up_B

## 採用方針
- ユーザー承認済みの暫定版をベースとする。
- 攻略本の顔アイコンの見た目を、店内スプライトの頭部・髪型・顔立ちへ可能な限り反映した。
- 動きはプレイ動画と攻略本を参考にしたトップダウン歩行2コマ想定で整理した。

## 注意
- これは原作ROMから直接抽出したスプライトではなく、参照資料に基づく再構成の暫定版である。
- 以後の改修では、このパッケージを店員アセットの基準版として扱う。
