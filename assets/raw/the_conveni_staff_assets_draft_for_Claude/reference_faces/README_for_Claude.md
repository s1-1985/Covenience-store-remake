# ザ・コンビニ 店員 顔画像アセット (スキャン抽出版)

## 内容
- `portraits/staff_001.png` ～ `staff_035.png`: 店員データ欄から顔アイコンだけを切り出し、256×256 px に配置した35人分の画像。
- `source_cards/`: 同一人物の「店員データ」カードを切り出した参照画像。氏名・能力などは**画像原本で確認**すること。
- `contact_sheet.jpg`: 全35人の対応確認用。
- `index.json`, `index.csv`: 顔画像と参照カード・掲載箇所の対応。

## Claudeへの実装指示の例
`index.json` の `asset_id` を店員の一意キーとして、`avatar_file` を店員選択・従業員情報画面の顔画像に使う。各店員の名前や能力値を採用する場合は、必ず対応する `data_reference_file` を参照し、判読できない数値や表記は推測で補完しない。画像だけから推測して個性や挙動を設定しない。
