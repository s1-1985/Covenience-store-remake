# 建物＋地形・インフラ スプライトパッケージ v2

建物52種に、提供された10枚から選別した地形・インフラ121種を追加。合計173種。画像の再生成・描き足し・回転による水増しは行っていません。

## Claudeへの入口

- `map_assets_manifest.json`: 建物と追加素材をまとめた全173 IDの一覧。
- `PACKAGE_INDEX.json`: 各セットの索引。
- `terrain/source_crops/`: 原寸切り出しPNG。こちらが追加素材の正本です。元の配色・画素を維持し、個々の外枠2pxを除去。
- `terrain/tiles_64/`: 実装確認用64×64px版。Nearestで縦横を別々に縮小した派生画像です。原寸画像とは別アセットとして数えません。
- `terrain/manifest.json` / CSV: 全追加ID、分類、元シート、行列、切り出し座標、原寸、64px版への倍率、ハッシュ。
- `terrain/atlas.png` / JSON: 追加素材用アトラス。矩形座標は左上基準、64×64px、回転なし。周囲2pxの色押し出し。
- `terrain/previews/`: 分類ごとのID付き一覧。
- `terrain/selection_report.csv`: 全685候補の採否と理由。近似重複の選別は見た目・用途に基づき、画素の完全一致だけではありません。
- `terrain/provenance/`: 入力画像のハッシュ、検出矩形、採用リスト。元シート全体は重複・除外画像を再収録しないため同梱しません。
- `validation_v2.json`: 件数・PNG・切り出し一致・既存52枚維持・アトラス・完全重複の検査結果。

## 選別方針

黒背景の01～03を基準とし、簡略化された輪郭、丸い樹冠、鮮やかな色を優先しました。04・08の水場は岩肌や水面の描き込みが強く、09の樹木も葉の描写が異なるため不採用。05は材質見本、06は構造物・広場等、07はホーム等、10は広い道路・歩道等の不足する機能を補っています。補完素材には地面の明度や線の細かさの差が残り、完全に同一の絵柄ではありません。

同じ接続用途とほぼ同じ構図の候補は代表だけ採用。方向、車止め側、ホーム側、地形形状、材質、構造が異なるものは別用途として残しています。不明瞭な線路交差の一部は除外しました。

## 取り込み上の制約

追加素材は地面を含む不透明なタイルです。白・黒のシート余白を除去し、草・水・道路の地面自体は透明化していません。地形→建物の順に重ねてください。

64px版は仮の1セル表示用です。元ゲームの占有マス数や縮尺を復元したものではありません。素材ごとの縦横比は原寸PNGと`native_size`に保存しています。外形を変えずに使う場合は原寸PNGを採用してください。

道路・線路・川の幅と端点、岸の色、光源はシート間・タイル間で揃っていません。自動接続・オートタイル・継ぎ目のない連続配置は未検証です。表示素材として読み込んだ後、使用する組み合わせを決めて端点・幅・色を調整する工程が必要です。名称の方角は画面上の上=N、右=E、下=S、左=Wで、通行グラフの定義ではありません。

## 既存建物との互換性

`sprites/`の52枚、既存`manifest.json`/CSV、建物用`atlas.png`/JSONは前回版から変更していません。既存`README_JA.md`と`CLAUDE_HANDOFF.md`は建物52種の説明であり、今回の全体件数は本書を参照してください。既存建物の厳密な真上視点に関する未達事項も継続します。
