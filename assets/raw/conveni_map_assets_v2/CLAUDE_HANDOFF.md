# Claudeへの引き継ぎ

1. `reference/claude_brief.md` と `manifest.json` を照合する。英語IDと占有マス数は元ブリーフを保持。
2. `validation.json` の件数・ID集合・寸法・透過検査を確認する。
3. `sprites/{id}.png` をそのまま使用するか、`atlas.json` のフレームを読み込む。
4. 描画位置は占有領域左上。占有寸法は `footprint`、表示倍率は全画像共通のタイルサイズ/64。
5. `previews/` で実寸比を確認する。透明部分を自動トリミングして各画像を同じ幅・高さへ拡大する実装は避ける。

## 未達事項を隠さず引き継ぐ

- 一部建物は正面壁面が見えるため、厳密な真上視点ではない。現在の画像を「全美術仕様に合格」とは扱わない。
- PNGキャンバスの比率は厳密に指定どおりだが、不透明な敷地の輪郭は生成画像由来であり、追加の透過余白を持つものがある。
- 樹木・車・窓等の内部ディテールは生成による意匠であり、実物寸法や原作ピクセルを復元したものではない。
- 原作の実ピクセル寸法、地形との継ぎ目、ゲーム内での美術的適合は、このパッケージだけで確認済みにはできない。

このZIPは52種の画像と取り込み情報を一括でレビューできる納品物である。元データのマス数を変えて画像に合わせないこと。
