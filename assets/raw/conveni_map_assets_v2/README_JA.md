# ザ・コンビニ Remake 建物スプライト52種

Claudeへの引き継ぎ用パッケージ。2026-09-22付の建物アセット生成ブリーフの52 IDを対象とする。

## 内容

- `sprites/`: ゲーム取り込み用の個別RGBA PNG。ファイル名はブリーフの英語ID。
- `manifest.json` / `manifest.csv`: ID・日本語名・占有マス数・キャンバス寸法の対応表。
- `atlas.png` / `atlas.json`: 個別PNGを無回転・無トリミングで収納した2048×2048のアトラスと左上基準の矩形座標。
- `previews/`: カテゴリ別の英語ID付き一覧。全画像を64px/マスの同一縮尺で表示。背景の市松は64×64px。一覧の背景・文字は個別PNGには含まない。
- `validation.json`: ファイル数、ID集合、画像寸法、RGBA、透明画素、画像重複の検査結果。
- `generation_prompts.json`: 採用画像の生成・修正指示。内蔵画像生成で制作。
- `reference/claude_brief.md`: 提供された仕様書のコピー。
- `CLAUDE_HANDOFF.md`: 取り込み時の注意点と未達事項。

## 寸法と配置

1タイルは縦横とも64px。PNGキャンバスは厳密に `footprint[0] * 64` × `footprint[1] * 64`。
たとえば動物園は384×384px、住宅(小D)は64×128px、駅(大)は256×128px。

占有領域は画像の不透明部分ではなく、PNGキャンバス全体で判定する。`alpha_bbox`は描画範囲の参考情報であり、衝突判定やマス数の算出に使わない。
画像は余白整理のあと、縦横共通倍率で縮小し、指定キャンバスの中央へ配置した。縦横を別々に引き伸ばして形状を合わせる処理は行っていない。
輪郭の切れを避けるため外周に最低1pxの透過余白を確保し、元画像の比率差に応じて追加の透過余白がある。

ゲーム側ではキャンバス左上を占有領域左上へ合わせる。タイル表示サイズがTpxなら、全画像を共通倍率T/64で描画する。
補間はNearest/Pointを推奨する。アトラスの矩形はトリミングされていないため、追加の原点補正は不要。
アトラスには透明な間隔を設けているが色の押し出し処理はない。線形補間・ミップマップ使用時は別途縁処理が必要。

## 仕様との一致と限界

数値・ファイル仕様は `validation.json` で確認できる。原作画像の抽出や模写ではなく、提供ブリーフの外観指示から新規生成した絵である。
書籍・動画から新たに建物仕様やアルゴリズムを復元したものではない。元ブリーフも外観と64px換算を新規提案と明記している。

**視点は未達事項がある。** 一部画像には正面壁面・窓・入口が見える高い位置からの見下ろし表現が残る。ブリーフの「真上から見た平面的な建築アイコン」を厳密な90度俯瞰と解釈した場合、完全準拠とは言えない。数値検査の合格は視点の合格を意味しない。
最終的な美術承認済みデータではなく、全52種を取り込んで比較できるレビュー用パッケージとして扱う。

## 対象外

道路・空き地・自店/敵店のロット等7種はブリーフに従い対象外。地形タイル、夜間差分、回転差分、建設中差分は含まない。
