# 初代ザ・コンビニ 商品アセット（Claude向けパッケージ）

## 概要
初代『ザ・コンビニ ～あの町を独占せよ～』再現用の商品オーバーレイ素材である。
本パッケージは **什器本体を含まない**。商品の「中身」だけを、1x1 を基本単位として整理している。

## 収録内容
- `previews/ambient_service_1x1.png`
  - 常温・サービス系カテゴリの 1x1 商品アセット一覧
- `previews/chilled_fresh_1x1.png`
  - 冷蔵・生鮮系カテゴリの 1x1 商品アセット一覧
- `previews/frozen_hot_1x1.png`
  - 冷凍・保温系カテゴリの 1x1 商品アセット一覧
- `category_manifest.csv`
  - category_id と和名、属するシート、備考の対応表
- `category_manifest.json`
  - 上記の JSON 版

## 制作ルール
- 視点は真上 90° の2D俯瞰を前提とする。
- 什器本体は含めず、商品オーバーレイのみを扱う。
- 基本単位は 1x1 マスである。
- 各カテゴリについて、在庫量を `多` `中` `少` の3段階で用意している。
- 1x2、1x3、2x2 などの大型什器へ展開する場合は、1x1素材を横・縦に組み合わせる前提で使う。
- パン類は「コンビニの商品らしく、袋入り」で表現している。

## 重要な扱い
- `copy_paper` は独立の商品棚カテゴリではなく、コピー機側の扱いとする。
- `cash` は商品オーバーレイ対象外とする。
- 本パッケージは原版完全一致の ROM 抽出ではなく、原作再現向けの整理済み商品素材である。

## 想定される次工程
1. 1x1 商品オーバーレイをカテゴリ別に管理
2. 対応する什器サイズ（1x2, 1x3, 2x2）へ配置ルールで展開
3. 在庫量ロジックと連動させて「多 / 中 / 少」を切り替える

## 参考カテゴリ
含まれるカテゴリは以下の 25 種。
冷たい飲料、温かい飲料、酒類、弁当類、パン類、インスタント類、菓子類、本類、たばこ、アイスクリーム、文房具、レトルト類、電機製品類、調味料類、野菜類、冷凍食品類、魚類、おでん、日用品、宅急便申込書、薬品、下着類、イベント商品、中華まん、肉類。
