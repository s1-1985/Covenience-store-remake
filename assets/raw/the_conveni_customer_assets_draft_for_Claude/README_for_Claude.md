# 初代『ザ・コンビニ ～あの町を独占せよ～』店内用・客アセット【暫定版】

## 目的と取り扱い
Claude実装用の **店内客21種・4方向・各方向2コマ** の画像パッケージ。
提供済みの「客アセット暫定版 1/3〜3/3」から、キャラクターのセルのみを切り出したものである。**今回、新しい人物・客種・動作・画像は生成していない。**

これは原作プレイ動画・攻略本を参考に制作された「再構成の暫定版」であり、原作ROMから抽出したゲーム内スプライトではない。
このパッケージ化の段階で、原作の各モーションと1コマずつ一致する検証は行っていない。

## 収録物
- `source_sheets/`: 元となる3枚の一覧シート（加工せず保存）
- `sprites/customer_01/` 〜 `sprites/customer_21/`: 各8コマの **背景透過PNG**。各ファイル160×160pxで元の見た目のサイズは拡大・縮小していない。
- `manifest.csv`, `manifest.json`: 客種、向き、歩行位相A/B、対応元・個別パス。
- `previews/`: 3枚の透過確認用プレビュー。
- `docs/customer_types.csv`: 客種一覧、表示名。

## ファイル名・向き
1客種につき `down_A.png`, `down_B.png`, `left_A.png`, `left_B.png`, `right_A.png`, `right_B.png`, `up_A.png`, `up_B.png` の8枚。
ここで down は画面手前に向く正面姿、up は背中、left/right は画像上の左右に向く横姿。
A/Bは **元シートの2コマ** を保持する識別である。全客種でA/Bの差が十分かどうかは未評価であり、自然な歩行動画として完成したことを意味しない。

## 配置・再生について
- 1コマの透明キャンバスは160×160px。足元の基準点（anchor）は座標 (80,154)。
- 画面内のキャラクター表示サイズは、元シートの解像度に合わせた仮置きであり、ゲーム内の0.5マス・1マスとの対応は要調整。
- 方向切替・歩行周期・停止状態・子連れの複数人占有範囲・車椅子と松葉杖の移動挙動はClaude側のゲーム実装で扱う。**これらを原作の挙動として本パッケージが確定するものではない。**
- 原作と一致しない見た目や動作を発見した場合は、元シートを根拠として修正すること。別プロジェクトのキャラクターや架空の客種を追加しない。
