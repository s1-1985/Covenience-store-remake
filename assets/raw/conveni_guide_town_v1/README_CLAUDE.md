# 攻略本の町マップ画面写真 v1

攻略本(第三の攻略本 PDF3、印刷頁11「マップ」)に載っている初級マップの開始時の画面写真を、
スキャンの元解像度で切り出したもの。`tools/build_guide_town_map.py`がこの画像を1マスずつ
読み取り、`game/data/vertical_slice.json`の`guide_town_map`を作る。

- 新規描き起こしではない。印刷の網点・にじみが残る。
- 切り出し位置・元PDFのSHA-256は`manifest.json`。
- 画像の右端約1/4は画面右のサイドバーで、町ではない(読み取りは左側だけを使う)。
