# 初代『ザ・コンビニ ～あの町を独占せよ～』 店舗配置用什器のみ（修正版）

## 制作範囲
- 提供攻略本 DATA2「商品棚」印刷86～89頁にある **45種類だけ** を収録。ゴミ箱、コーヒーコーナー等の別プロジェクト由来の設備は含めない。
- `sprites/empty/fixture_001.png`～`fixture_045.png`：**空の什器本体のみ**（真上90°正投影の2Dドット絵、透過PNG）。
- `sprites/rotations/`：0°以外の3方向。方向付きの商品グラフィック・商品レイヤー・人物・車両は収録しない。
- `sprites/empty/*_logical24.png`：縮小論理ピクセル原画。48pxは論理24pxをNEARESTで2倍にしたもの。
- `metadata/fixture_manifest.json`：元資料の掲載名・マス数、画像パス、向きの対応。
- `metadata/visual_qa.csv`：各アセットの寸法・画角・資料による確認範囲と未確定箇所。
- `previews/`：全45種の見本一覧。実際の配置検証に使った原版画面との比較画像は、ZIPに商品画像を混入させないため **別ファイル** `konbini_PS1_fixture_original_comparison.png` として提出する。

## 原版との比較と直した点
原版の画面で読み取れる白と灰の輪郭、青がかった棚底、カウンター等の質感と店内の床セルの相対サイズを照合し、前稿v2の大きな単色区画と平板な枠線を変更した。店内画面（PS5動画 00:15:20）を同じ位置・縮尺で合成し、什器の基準寸法を 1マス48px・0.5マス24pxへ修正した。原画はROMスプライトではなく動画キャプチャであるため、画素の直接コピーではない。

## 実装上の制約・証拠の限界
- **元作品の「商品が入っていない状態」の設置画面は資料で確認できないため、棚の空の内面についての完全一致は証明できない。** 隠れていた細部は、輪郭と商品の入った什器の見え方に基づいて再構成した。
- 動画で各什器の購入前→購入後を一連で追えた例は全45種には及ばない。「一覧45種の原版実スプライトをそのまま取得」「全部に対して原版画素一致確認」とは述べない。
- 1マス48pxは今回参照した動画フレームにおける相対基準。ゲームROM内部の元ピクセル数だと断定しない。ゲーム側の描画尺度に応じて最近傍法で変換する。
- 数値パラメータ・各商品の互換性はこの画像ZIPを正本とせず、攻略本から抽出した別の数値台帳を利用する。
