# 攻略本の店舗図から切り出した店内スプライト v1

攻略本(第三の攻略本 PDF4、印刷頁48「未開の土地に開店するなら!」)の店舗レイアウト図には、
ゲーム内の真上視点の什器画像が格子どおりに印刷されている。そこから切り出した素材。

- 新規描き起こしではない。印刷のにじみ・網点が残る。
- `conveni_menu_fixtures_v1`(メニュー用の斜め視点アイコン)とは別物。こちらは店内表示用。
- 切り出し座標・拡大率・元PDFのSHA-256は`manifest.json`。
- 現在の収録: 休憩室1点。休憩室1/2のどちらの絵かは図から判別できないため、ゲームでは
  両方に同じ絵を使っている(表示のみの流用)。

同じ図には棚・ワゴン・自販機・レジ・駐車場なども鮮明に載っており、什器ごとの対応づけ
(巻末DATA2の小さなグレースケール図と照合)ができれば、残りの什器の絵もここから置き換え
られる。
